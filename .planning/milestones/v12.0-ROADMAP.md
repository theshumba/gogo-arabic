# Roadmap: GoGo Arabic v12.0 — Learning Systems

## Overview

v12.0 transforms Gogo Arabic from a vocabulary-and-quest RPG into a structured Arabic course inside a game — 6 skill trees that gate and reward all learning activities, grammar expanded from 47 to 50 lessons with 12 exercise types, quizzes expanded from 12 to 18 types with an adaptive difficulty engine, a CEFR diagnostic placement test, 250+ achievements tiered by mastery, and CEFR progress reports with social sharing. Nine phases, dependency-ordered: bugs first, infrastructure before features, data before display.

## Phases

- [ ] **Phase 56: Bug Fixes & Redux Foundation** — Wire grammar achievements + migrate lesson IDs + scaffold new Redux slices
- [ ] **Phase 57: Skill Tree Infrastructure** — 6 skill trees with 30 nodes each, auto-initialization, RPG rewards, and SkillTreeView UI
- [ ] **Phase 58: Grammar A1-A2 + Lesson Wiring** — 20 new A1-A2 lessons with 12 exercise types, GrammarChecker, XP wiring
- [ ] **Phase 59: Adaptive Difficulty Engine** — FSRS-driven difficulty engine targeting 70-85% success rate across all quiz formats
- [ ] **Phase 60: Quiz Expansion (Core 3 Types)** — GrammarFill, WordOrder, ClozePassage + full 18-type registry with CEFR gates
- [ ] **Phase 61: CEFR Placement Test** — 15-20 CAT questions, skill tree and grammar pre-unlocks, retake from settings
- [ ] **Phase 62: Grammar B1-B2 + CEFR Gating** — 30 B1-B2 lessons completing 50 total, B1/B2 skill tree gates enforced
- [ ] **Phase 63: Achievement Expansion** — 206 new achievements, 4-tier system, dedicated Achievements panel
- [ ] **Phase 64: CEFR Reports + Social Sharing** — Radar chart progress report, Scholar's Scroll ink delivery, social share card

## Phase Details

### Phase 56: Bug Fixes & Redux Foundation
**Goal**: Two pre-existing bugs are fixed and every downstream v12.0 system has the Redux foundation it needs — no new feature can break because of missing middleware wiring or colliding lesson IDs
**Depends on**: Phase 55 (v11.0 complete)
**Requirements**: FIX-01, FIX-02
**Success Criteria** (what must be TRUE):
  1. Completing any grammar lesson fires achievement checks — a player who finishes lesson_verb_present and has the grammar achievement condition met sees the achievement toast appear in the same session
  2. All existing grammar lesson references in quests, ink dialogue, and FSRS sync use string slug IDs (e.g. lesson_verb_present) — no numeric index references remain anywhere in the codebase
  3. `placementSlice` and `cefrProgressSlice` are registered in store.js, persisted to IndexedDB with a bumped CURRENT_VERSION and migration function, and hydrate without error on a real v11.0 save snapshot
  4. `learningProgressMiddleware` is scaffolded and wired into the Redux middleware chain — it handles no actions yet but is present and importable

Plans:
- [ ] 56-01: achievementMiddleware grammar_lessons wiring + grammar lesson slug ID migration (FIX-01, FIX-02)
- [ ] 56-02: placementSlice + cefrProgressSlice registration + IndexedDB CURRENT_VERSION bump + learningProgressMiddleware scaffold

### Phase 57: Skill Tree Infrastructure
**Goal**: Six skill trees reflect everything the player has already learned and gate all future v12.0 content — existing players see their mastery represented, new players earn their first unlocks within minutes
**Depends on**: Phase 56 (learningProgressMiddleware scaffolded; grammar lesson slugs migrated so tree nodes can reference them without ID collisions)
**Requirements**: SKILL-01, SKILL-02, SKILL-03, SKILL-04
**Success Criteria** (what must be TRUE):
  1. Completing a quest, finishing a grammar lesson, passing a quiz session, completing a vocabulary review, tracing a calligraphy letter, or winning a poetry battle awards XP to the appropriate skill tree — the XP bar in SkillTreeView visibly advances
  2. A player who loads their v11.0 save sees their skill trees already populated — nodes are unlocked matching their current FSRS mastery count, quest completions, and grammar lessons finished; no content they already earned is retroactively locked
  3. Unlocking a skill tree node can reveal a new spell, companion dialogue option, zone access flag, or NPC branch — at least one node of each type exists across the 6 trees
  4. SkillTreeView displays XP progress bars per tree and shows the next 1-2 unlockable nodes highlighted; locked nodes beyond the visible frontier are collapsed

Plans:
- [ ] 57-01: skillTrees.js expanded to 30 nodes per tree + initializeSkillTree(existingPlayerState) auto-unlock function + learningProgressMiddleware XP routing (SKILL-01, SKILL-02)
- [ ] 57-02: Skill tree node reward types: unlock_spell, unlock_dialogue, unlock_zone, unlock_npc_branch + ActionSetExecutor skill_tree_level condition (SKILL-03)
- [ ] 57-03: SkillTreeView.jsx — one tree at a time, progressive disclosure, XP bars, next-node highlights, lazy-loaded (SKILL-04)

### Phase 58: Grammar A1-A2 + Lesson Wiring
**Goal**: Players who open the Grammar section encounter a meaningful A1-A2 curriculum — each lesson has real exercise variety beyond fill-in-blank, every completed lesson awards Grammar skill tree XP, and the next lesson auto-unlocks
**Depends on**: Phase 57 (Grammar skill tree exists and can receive XP from lesson completion)
**Requirements**: GRAM-02, GRAM-04
**Success Criteria** (what must be TRUE):
  1. Each grammar lesson presents at least 12 distinct exercise types — including conjugation drill, sentence transformation, word order, and error identification — not only fill-in-blank; a player completing any A1-A2 lesson encounters at least 4 different exercise formats before finishing
  2. Completing a grammar lesson immediately awards Grammar skill tree XP visible in SkillTreeView and auto-unlocks the next lesson in sequence — the player does not need to manually navigate back to find the next lesson

Plans:
- [ ] 58-01: 20 new A1-A2 grammar lessons in grammar.js with 12 exercise types + GrammarChecker.js rule-based utility + vocabulary_prerequisites build-time validation (GRAM-02)
- [ ] 58-02: learningProgressMiddleware grammar completion → Grammar skill tree XP + auto-unlock next lesson + lesson sequence gating in GrammarOverlay (GRAM-04)

### Phase 59: Adaptive Difficulty Engine
**Goal**: Quiz sessions target a 70-85% success rate for every player and adapt question format to player weaknesses — the engine is in place before any new quiz types ship, so all 18 types benefit from adaptive difficulty from day one
**Depends on**: Phase 57 (skill tree CEFR level data is needed for quiz type gating; QUIZ_TYPE_REGISTRY uses cefrMin gates that map to tree levels)
**Requirements**: QUIZ-02, QUIZ-03
**Success Criteria** (what must be TRUE):
  1. A player struggling with grammar questions (below 70% accuracy on grammar-type quizzes in the session) receives more grammar format questions in subsequent rounds — the format shift is observable within a single extended quiz session
  2. FSRS-due cards are always eligible for review regardless of difficulty tier — a player whose due cards span easy and hard items sees all of them presented, with adaptive engine controlling question format only, never filtering out scheduled cards
  3. A player consistently answering correctly (above 85%) sees distractor difficulty increase over the session — wrong answers become more plausible Arabic words rather than obvious distractors

Plans:
- [ ] 59-01: Rolling session accuracy tracker in useQuiz.js + per-content-cluster difficulty tracking + FSRS-due override flag (fsrs_override: true) (QUIZ-02)
- [ ] 59-02: QUIZ_TYPE_REGISTRY in quizTypes.js with 18 types, minLevel/cefrMin gates + format-selection logic routing grammar-weak players to grammar quiz types (QUIZ-03)

### Phase 60: Quiz Expansion (Core 3 Types)
**Goal**: Three new quiz types are playable and gated by CEFR level — GrammarFill, WordOrder, and ClozePassage give players fundamentally different practice modes compared to the existing 12 types
**Depends on**: Phase 59 (adaptive difficulty engine in place — new quiz types inherit adaptive format selection and FSRS-due override behavior on day one)
**Requirements**: QUIZ-01
**Success Criteria** (what must be TRUE):
  1. A player at A2 CEFR level or above can access GrammarFill quizzes in their quiz session — completing a fill-in-blank conjugation exercise where selecting the correct Arabic verb form is required to advance
  2. A player can complete a WordOrder exercise by arranging Arabic word tokens into the correct sentence order using drag-and-drop (reusing SentenceBuilder) — the exercise appears in the quiz rotation at B1+
  3. A player at A2+ can complete a ClozePassage quiz — reading a short Arabic paragraph with blanks and selecting the correct missing words from FSRS-sourced options
  4. All 18 quiz type definitions exist in QUIZ_TYPE_REGISTRY including the three deferred types (DialectIdentify, RootExpand, CulturalContext) marked with `cefrMin: 'B2'` — they are defined but locked until player reaches B2

Plans:
- [ ] 60-01: GrammarFill.jsx — conjugation fill-in-blank with Arabic verb paradigm display + QuizOverlay switch integration (QUIZ-01)
- [ ] 60-02: WordOrder.jsx — extends SentenceBuilder drag-and-drop for sentence arrangement at B1+ (QUIZ-01)
- [ ] 60-03: ClozePassage.jsx — paragraph with FSRS-sourced blank options at A2+ + QUIZ_TYPE_REGISTRY 18-type completion with deferred type stubs (QUIZ-01)

### Phase 61: CEFR Placement Test
**Goal**: New players start at the right CEFR level — the diagnostic test places them conservatively, pre-unlocks the skill tree nodes and grammar lessons they have already earned, and gives them an escape hatch if the placement feels wrong; existing players can retake from settings
**Depends on**: Phase 59 (adaptive difficulty engine provides CAT item selection logic) and Phase 58 (A1-A2 grammar content provides grammar section questions)
**Requirements**: CEFR-01, CEFR-02, CEFR-04
**Success Criteria** (what must be TRUE):
  1. A new player on first launch is offered the placement test before entering the main game; completing it assigns a CEFR level one tier below their raw score (e.g. a player who scores B1 is placed at A2) with a "Start Lower" button to drop one more tier
  2. After placement test completion, skill tree nodes and grammar lessons appropriate to the assigned CEFR level are pre-unlocked — a player placed at A2 can immediately access A2 grammar lessons without completing A1 prerequisites manually
  3. A player can navigate to Settings and retake the placement test; a warning explains that retaking resets CEFR tracking history; completing the retest updates their CEFR level and unlocks accordingly

Plans:
- [ ] 61-01: placementTest.js — 20-30 calibrated CAT questions spanning Pre-A1 through B1 across all 6 tree domains + placementEngine.js IRT binary search (CEFR-01)
- [ ] 61-02: PlacementTestOverlay.jsx — reuses existing quiz type components, one-level-lower default, "Start Lower" escape hatch, B1 cap, early-exit at 10 consecutive correct (CEFR-01)
- [ ] 61-03: Placement result fan-out via react-redux batch() in learningProgressMiddleware — pre-unlock skill tree nodes + grammar lessons + write CEFR level to cefrProgressSlice + settings retake UI (CEFR-02, CEFR-04)

### Phase 62: Grammar B1-B2 + CEFR Gating
**Goal**: The grammar curriculum is complete at 50 lessons covering A1 through B2, intermediate and advanced lessons are gated by skill tree progression, and the CEFR placement system has grammar content to work with at every level
**Depends on**: Phase 61 (placement test assigns B1/B2 levels that now need grammar content to unlock; Phase 58 established the lesson schema in production)
**Requirements**: GRAM-01, GRAM-03
**Success Criteria** (what must be TRUE):
  1. The grammar section contains 50 lessons total covering A1 through B2 — a player who has completed all A1 and A2 lessons can see B1 lessons listed (locked behind Grammar tree level 3), and B2 lessons listed (locked behind Grammar tree level 5)
  2. A player who reaches Grammar tree level 3 sees B1 grammar lessons unlock automatically; reaching level 5 unlocks B2 lessons — attempting to open a locked lesson shows a clear "Requires Grammar Tree Level X" message with the current level shown
  3. A "New content added" notification appears on first load after this phase ships for existing players whose grammar completion percentage has changed due to the expanded lesson count

Plans:
- [ ] 62-01: 30 new B1-B2 grammar lessons in grammar.js completing the 50-lesson curriculum (GRAM-01)
- [ ] 62-02: Skill tree gate enforcement in GrammarOverlay — B1 lessons locked until Grammar tree level 3, B2 until level 5 + "new content" toast for existing players (GRAM-03)

### Phase 63: Achievement Expansion
**Goal**: The achievement system recognizes mastery across every learning activity — 250+ achievements in 4 tiers give players concrete milestones to pursue, and a dedicated panel lets them track progress across all categories
**Depends on**: Phase 62 (all event sources — skill tree, grammar at 50 lessons, quiz expansion, placement — are complete; achievement conditions can be authored accurately against all trigger types)
**Requirements**: ACH-01, ACH-02, ACH-04
**Success Criteria** (what must be TRUE):
  1. The achievements data file contains 250+ entries across at least 15 categories — opening the Achievements panel shows achievements for vocabulary milestones, grammar completion, quiz streaks, skill tree progress, CEFR level reached, and placement test completion
  2. Every achievement has a tier label (Bronze, Silver, Gold, or Legendary) and the Achievements panel displays the tier badge visually — a player can see at a glance which achievements are entry-level versus mastery-level
  3. Achievement progress is visible before completion — a player can open the Achievements panel, filter by category (e.g. Grammar, Skill Trees, Quizzes), and see how close they are to each unearned achievement

Plans:
- [ ] 63-01: achievements.js expanded with 206 new entries in existing 20-category schema + Bronze/Silver/Gold/Legendary tier field on all achievements (ACH-01, ACH-02)
- [ ] 63-02: New isAchievementMet() requirement types: skill_tree_nodes, skill_tree_complete, quiz_type_streak, cefr_level_reached, placement_complete + quizTypeStats field in achievementSlice.stats (ACH-01)
- [ ] 63-03: AchievementsPanel.jsx — category filter tabs, tier badge display, progress bars on incomplete achievements, lazy-loaded (ACH-04)

### Phase 64: CEFR Reports + Social Sharing
**Goal**: Players can see their CEFR level progress over time as a visual report and share their Arabic learning milestone as a social card — the report is read-only, never pushes CEFR level backwards, and the share card works without external image dependencies
**Depends on**: Phase 63 (all upstream data — placement baseline in cefrProgressSlice, grammar completions, FSRS aggregation, skill tree state — is complete and stable)
**Requirements**: CEFR-03, ACH-03
**Success Criteria** (what must be TRUE):
  1. A player can open a CEFR Progress Report showing a radar chart of skill distribution across 6 skill trees and a line chart of CEFR level over time — both charts are visible on the first session after taking the placement test
  2. The CEFR level shown in the progress report never goes backwards — if a player's recent performance dips, the report still shows the highest CEFR level achieved; only upward level changes are recorded
  3. A player can generate a shareable card showing their Arabic learning milestone (e.g. "I've learned 500 Arabic words in Gogo Arabic") and either share it via the Web Share API or copy it to clipboard — the card is generated without any external image requests and works in production

Plans:
- [ ] 64-01: recharts install (v3.8.0) + CefrProgressReport.jsx — RadarChart (skill distribution) + LineChart (CEFR over time), lazy-loaded in charts-vendor chunk; write-once-per-session CEFR snapshot model in cefrProgressSlice (CEFR-03)
- [ ] 64-02: Scholar's Scroll ink dialogue — Amira delivers CEFR milestone moments (reuses inkjs v11.0 + Amira companion) wired to cefrProgressSlice level advancement (CEFR-03)
- [ ] 64-03: SocialShareCard.jsx — SVG-only design, Web Share API + clipboard fallback, "I learned X Arabic words in Gogo Arabic" with player stats; html-to-image v1.11.13 as conditional install if character art is included (ACH-03)
