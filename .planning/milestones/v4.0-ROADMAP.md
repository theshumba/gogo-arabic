# Milestone v4.0: Game Soul & Polish

**Status:** SHIPPED 2026-02-10

## Milestone Summary

**Key Decisions:**
- Bug fixes first (Phase 14) before adding features — prevents compound issues
- Audio second (Phase 15) — highest user impact, no dependencies
- Visual juice (16) and Progression (17) in parallel — Phaser vs React, independent
- World life last (18) — uses particles from Phase 16
- 15-02 absorbed 15-01 infrastructure inline — no separate execution needed
- Individual motion.div wrappers with explicit delay (no staggerChildren on parent)
- CSS keyframes for infinite animations — more performant than Framer Motion
- Timer-based NPC idle (scene.time.addEvent) over state machines — simplicity
- Zero new dependencies — all features built with existing stack (Howler.js, Phaser 3, Framer Motion)

**Issues Resolved:**
- Game freezes/stuck states (overlay locks, movement locks, zone transition freezes)
- Hidden learning path (alphabet was buried in menus, now step 2 of onboarding)
- Silent game (complete audio system with BGM, SFX, volume controls)
- Empty world feel (NPC idle animations, locked door feedback, smooth camera)
- Missing "game feel" (screen shake, particles, celebrations, polish)

**Issues Deferred:**
- Audio asset files (MP3s) not included — game plays silently until assets added
- Only 4 locked doors across 8 zones (partial coverage)
- No formal VERIFICATION.md for any phase (parallel execution skipped checkpoints)

**Technical Debt Incurred:**
- Phase summaries missing for 14-01, 15-01, 15-02, 17-01 (parallel execution artifact)
- Build verification was not run by some executor agents (sandbox restrictions)
