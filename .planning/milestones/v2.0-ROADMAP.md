# Milestone v2.0: Player Experience Overhaul

**Status:** SHIPPED 2026-02-08
**Phases:** 1-9
**Total Plans:** 14

## Overview

Transform GoGo Arabic from a feature-rich but hard-to-navigate experience into a polished, guided, feature-packed learning RPG. This milestone prioritized player-facing improvements: fixing critical bugs, adding guidance systems, surfacing hidden features, redesigning the HUD, then adding entirely new systems — a daily dashboard, upgraded world map, player profile, visual polish, and outfit customization. Infrastructure work (testing, architecture, backend) was deferred to v3.0.

## Milestone Summary

**Key Decisions:**
- CSS Modules for new components (consistency, responsive breakpoints)
- useFocusTrap for all overlays (WCAG AA compliance)
- Phaser DOMOverlay for NPC markers (existing system, minimal overhead)
- Custom Framer Motion tooltips instead of react-joyride (React 19 incompatibility)
- Deferred infrastructure (testing, architecture, backend) to v3.0
- 5-agent parallel execution for phases 5-9

**Issues Resolved:**
- Zero in-world player guidance (added quest markers, compass, tracker)
- Features hidden/undiscoverable (added Activities menu, NPC hints, boss nodes)
- 2.9MB unsplit bundle (reduced 91% to 264KB)
- Static onboarding overlay (replaced with contextual gameplay-driven tour)
- No startup dashboard (added daily dashboard with streak, goals, suggestions)

**Issues Deferred:**
- VPOL-01: Consistent pixel art style guide (requires artist)
- VPOL-02: Custom pixel-art HUD icons (requires artist)
- VPOL-04: Idle animations (requires sprite sheets)
- GameLayout god component refactoring (v3.0 ARCH-01)
- Test coverage improvement (v3.0 TEST-01 through TEST-05)

**Technical Debt Incurred:**
- Mixed styling (CSS Modules + inline) still present in some older components
- HUD tests required manual fixes after state shape changes
- Phases 5-9 lack formal PLAN.md/SUMMARY.md files (executed via parallel agents)
