## v6.0 Requirements

Requirements for v6.0 milestone. Each maps to roadmap phases.

### Storage & Infrastructure (3/3 = 100%)

- [x] **STOR-01**: Player can save games without localStorage overflow — FSRS cards and battle history migrated to IndexedDB
- [x] **STOR-02**: Player sees a warning when storage usage exceeds 80% of quota
- [x] **STOR-03**: Player's existing save data auto-migrates from localStorage to IndexedDB on first load after update

### Root Magic & Elemental Affinity (12/12 = 100%)

- [x] **MGIC-01**: Player can discover Arabic root-element mappings through NPC dialogue and exploration (50 roots across 10 elements)
- [x] **MGIC-02**: Player can cast spells by selecting a discovered root — spell effect and damage scale with root mastery and FSRS vocabulary accuracy
- [x] **MGIC-03**: Player has MP that depletes on spell cast and recovers between battles
- [x] **MGIC-04**: Player can equip up to 6 spells in a hotbar for quick access during battle
- [x] **MGIC-05**: Player can upgrade spells by learning higher verb forms (Form I-X) of the same root
- [x] **MGIC-06**: Player discovers primary and secondary elemental affinity through 50+ weighted gameplay choices (dialogue, quests, exploration)
- [x] **MGIC-07**: Player's primary affinity grants 2x spell power and secondary grants 1.5x for matching elements
- [x] **MGIC-08**: Player can combine roots from different elements for combo effects (data-driven, 20 initial combos)
- [x] **MGIC-09**: Player sees Arabic calligraphy particle VFX when casting spells (10 distinct element visuals)
- [x] **MGIC-10**: Player's root mastery syncs bidirectionally with FSRS — learning words increments root XP, root mastery suggests derived words for review
- [x] **MGIC-11**: Player can view a spell list UI with element filter, root letters, MP cost, and mastery level
- [x] **MGIC-12**: Player's grammar accuracy (conjugation, declension) modifies spell effectiveness as a damage multiplier

### Equipment, Inventory & Economy (12/12 = 100%)

- [x] **EQUP-01**: Player can equip items in 8 slots (head covering, robe, cloak, belt, boots, gloves, accessory 1, accessory 2)
- [x] **EQUP-02**: Player can view stat comparisons when inspecting equipment vs currently equipped items
- [x] **EQUP-03**: Player can manage a 200-item inventory with grid UI, sort by type/rarity/Arabic alphabetical order
- [x] **EQUP-04**: Player sees items in 5 rarity tiers with Arabic color names (common/uncommon/rare/epic/legendary)
- [x] **EQUP-05**: Player can buy and sell items at zone-specific shops with dynamic inventory based on player level and world state
- [x] **EQUP-06**: Player can haggle with shopkeepers using Arabic numerals (0-9999) in a negotiation mini-game
- [x] **EQUP-07**: Player's equipment bonuses only fully activate for Arabic affix words the player has learned (50% bonus if unlearned, 100% if learned)
- [x] **EQUP-08**: Player automatically learns new Arabic vocabulary when discovering items with unknown affix words
- [x] **EQUP-09**: Player can view item lore snippets with historical/cultural context for each equipment piece
- [x] **EQUP-10**: Player can benefit from equipment set bonuses when wearing matching themed sets (Scholar's Set, Merchant's Set, etc.)
- [x] **EQUP-11**: Player sees equipped items rendered on their character sprite in both WorldScene and BattleScene
- [x] **EQUP-12**: Player's equipment stats (HP, MP, damage, defense bonuses) apply in battle calculations

### Companion System (10/12 = 83%)

- [x] **COMP-01**: Player can recruit 12 companions across zones (at least 2 per major zone) through story/quest progression
- [x] **COMP-02**: Player can form a party with max 2 active companions (1 for battle, 1 for exploration)
- [x] **COMP-03**: Player's battle companion acts autonomously using role-based AI (healer, attacker, defender, support)
- [x] **COMP-04**: Player can track relationship level (0-100) with each companion, affecting dialogue options and battle performance
- [x] **COMP-05**: Player can give gifts to companions to increase relationship level
- [x] **COMP-06**: Player's exploration companion follows them in the world and makes contextual Arabic comments about zones, objects, and events
- [x] **COMP-07**: Each companion has a language teaching specialization (grammar, vocabulary, pronunciation, culture) that influences their dialogue — *PARTIAL: 151-166 lines per companion (need 200+, 573 lines missing)*
- [x] **COMP-08**: Companion dialogue complexity adapts to player's Arabic proficiency level (more Arabic at higher CEFR levels)
- [x] **COMP-09**: Player can swap active companions at any camp or rest point
- [x] **COMP-10**: Each companion has 200+ unique dialogue lines with distinct personality, speech patterns, and Arabic catchphrases — *PARTIAL: 1,827 total, need 2,400+*
- [ ] **COMP-11**: Companion sprites are faceless (Islamic art style) with distinctive silhouettes and flowing robes — *FAILED: No sprite assets, falls back to npc-default*
- [x] **COMP-12**: Player can view companion roster UI showing all recruited/unrecruited companions, relationship bars, and teaching specializations

### Integration & Architecture (4/6 = 67%)

- [x] **INTG-01**: All new EventBus events use strict namespacing with no collisions against existing events
- [x] **INTG-02**: All existing tests pass after each phase — no regressions in core game systems (1023/1023)
- [ ] **INTG-03**: Build remains under 500KB main bundle after all v6.0 features — *FAILED: 661KB (179KB gzipped)*
- [x] **INTG-04**: New features respect prefers-reduced-motion for spell VFX, companion animations, and equipment effects
- [x] **INTG-05**: All new overlays use CSS Modules, focus traps, and ARIA labels
- [x] **INTG-06**: Battle rewards (XP, gold, items) from Phase 27 engine wire into player progression and inventory systems
