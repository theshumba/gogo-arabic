## v2.0 Requirements

Player-facing UX overhaul with new features. Infrastructure work deferred to v3.0.

### Critical Fixes

- [x] **CRIT-01**: Pause menu renders above all other UI elements (z-index fix)
- [x] **CRIT-02**: Quest log and quiz overlay are usable on mobile screens < 450px
- [x] **CRIT-03**: All 9 overlays trap keyboard focus (useFocusTrap wired)
- [x] **CRIT-04**: Review badge in HUD is clickable and opens review session

### Player Guidance

- [x] **GUID-01**: NPCs with available quests show exclamation mark (!) above their head
- [x] **GUID-02**: NPCs with completable quests show question mark (?) above their head
- [x] **GUID-03**: HUD shows active quest name and current objective with progress
- [x] **GUID-04**: Player sees directional indicator pointing toward quest objective

### Feature Discoverability

- [x] **DISC-01**: Grammar, Roots, Reading, and Mini-Games are accessible from in-game menu
- [x] **DISC-02**: Word Duel bosses are accessible through zone NPCs or world map
- [x] **DISC-03**: Daily review sessions can be started from the game HUD
- [x] **DISC-04**: Hidden features are mentioned by NPCs through contextual dialogue hints

### Onboarding & HUD

- [x] **ONBD-01**: New players see contextual tooltips pointing at actual UI elements
- [x] **ONBD-02**: Onboarding progresses through gameplay actions, not button clicks
- [x] **ONBD-03**: First quest NPC is visually highlighted with guidance arrow
- [x] **HUD-01**: Primary HUD shows only Level/XP, active quest, and 3-4 action buttons
- [x] **HUD-02**: Secondary stats (words, dirhams, streak) are in collapsible panel
- [x] **HUD-03**: Z-index tokens are standardized in CSS variables
- [x] **PERF-01**: Main JavaScript bundle is under 500KB (code splitting configured)

### Daily Dashboard

- [x] **DASH-01**: Game shows a dashboard on startup with streak count, words due for review, and daily goals progress
- [x] **DASH-02**: Dashboard suggests next activity based on player state
- [x] **DASH-03**: Dashboard shows learning stats summary (words learned this week, accuracy trend)

### World Map Upgrade

- [x] **WMAP-01**: Players can fast-travel to any previously visited zone from the world map
- [x] **WMAP-02**: World map shows completion percentage for each zone
- [x] **WMAP-03**: Locked zones show teaser info (zone name, difficulty, what's needed to unlock)

### Player Profile & Stats

- [x] **PROF-01**: Player profile page shows total words learned, accuracy rate, and time played
- [x] **PROF-02**: Profile displays achievement showcase with pinned achievements
- [x] **PROF-03**: Profile shows learning streak history and best streak record
- [x] **PROF-04**: Profile is accessible from the game HUD or pause menu

### Visual Polish & Sprites

- [x] **VPOL-03**: Learned words progressively fade diacritics (tashkeel) as mastery increases
- [ ] **VPOL-01**: All NPC and player sprites follow a consistent pixel art style guide — *Deferred: requires pixel art assets*
- [ ] **VPOL-02**: HUD uses custom pixel-art icons instead of emoji/text — *Deferred: requires pixel art assets*
- [ ] **VPOL-04**: Idle animations added to player and key NPCs — *Deferred: requires sprite sheets*

### Outfit System

- [x] **OUTF-01**: Wardrobe UI accessible from pause menu showing available outfits
- [x] **OUTF-02**: Players can purchase outfits using in-game currency (dirhams) from shop
- [x] **OUTF-03**: Player sprite updates in real-time when outfit is changed
- [x] **OUTF-04**: At least 5 distinct outfit options available at launch (AI-generated pixel art)
