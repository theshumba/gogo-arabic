**IMPORTANT:** The `_createFoamAnimations()` method creates 3 animations from 3 rows (top, left, bottom) using `foamCols`. For volcano, the foam spritesheet is only 1 row (11 frames, 1 row). For dungeon, the water animation is 5 rows (56 cols). The current foam creation logic does `start: foamCols * 2, end: foamCols * 3 - 1` for the bottom row.

For volcano (11 cols x 1 row = 11 frames total), creating 3 separate row animations is invalid because rows 2 and 3 don't exist. Add a safety check in `_createFoamAnimations()`:

After the `const foamCols = cfg.foamCols;` line, add:
```javascript
// Get actual frame count to avoid creating animations for nonexistent rows
const foamTexture = this.scene.textures.get(foamKey);
const totalFrames = foamTexture.frameTotal - 1; // subtract __BASE frame
const foamRows = Math.floor(totalFrames / foamCols) || 1;
```

Then wrap the left and bottom animation creation in row count checks:
```javascript
// Row 0 always exists
this.scene.anims.create({
  key: topKey,
  frames: this.scene.anims.generateFrameNumbers(foamKey, { start: 0, end: Math.min(foamCols - 1, totalFrames - 1) }),
  frameRate: 6,
  repeat: -1,
});

if (foamRows >= 2) {
  this.scene.anims.create({
    key: leftKey,
    frames: this.scene.anims.generateFrameNumbers(foamKey, { start: foamCols, end: Math.min(foamCols * 2 - 1, totalFrames - 1) }),
    frameRate: 6,
    repeat: -1,
  });
}

if (foamRows >= 3) {
  this.scene.anims.create({
    key: bottomKey,
    frames: this.scene.anims.generateFrameNumbers(foamKey, { start: foamCols * 2, end: Math.min(foamCols * 3 - 1, totalFrames - 1) }),
    frameRate: 6,
    repeat: -1,
  });
}
```

Also update `_addFoamOverlay` to check existence before playing:
The existing `if (!animKey || !this.scene.anims.exists(animKey)) return;` line already handles this correctly. No change needed there.

**Do NOT modify** any other methods or constants. Only add the 3 BIOME_TILESETS entries and update the foam row safety check.
