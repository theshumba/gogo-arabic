# Phase 77 — NAR-02: Event Scheduler & UI

## Overview
Add a scheduler service that activates/deactivates the 12 existing faction events based on game time, plus a Redux slice to track active events and attendance, and React components (banner + overlay) to display them.

## Files Created
| File | Purpose |
|------|---------|
| `src/services/eventScheduler.js` | Pure-function module: `getActiveEvents`, `getNextEvent`, `getVocabBoostCategories`, `isEventActive` |
| `src/store/slices/eventSlice.js` | Redux Toolkit slice: active events, history, vocab boosts |
| `src/components/Events/EventBanner.jsx` | Compact 40px banner shown when an event is active (click opens overlay) |
| `src/components/Events/EventBanner.module.css` | CSS Module for EventBanner |
| `src/components/Events/EventOverlay.jsx` | Full overlay: active events, schedule, history, vocab boosts |
| `src/components/Events/EventOverlay.module.css` | CSS Module for EventOverlay |
| `src/services/__tests__/eventScheduler.test.js` | Vitest tests for scheduler functions |
| `src/store/slices/__tests__/eventSlice.test.js` | Vitest tests for event slice reducers/selectors |

## Data Dependencies
- `src/data/factionEvents.js` — 12 events (2 per faction), read-only
- `src/data/factions.js` — `FACTION_BY_ID` for icons/names
- `src/store/slices/timeSlice.js` — `selectGameTime`, `selectDayCount` for current game time
