Create NEW file `src/game/systems/ActionSetExecutor.js` with two named exports:

**1. `evaluateActionSets(actionSets, context)`**
- `actionSets`: array of `{ requirements: [...], actions: [...] }`
- `context`: `{ questStatuses, storyFlags, vocabMastery, playerLevel, inventory, currentHour, currentZone }`
- Iterates action sets in order, evaluates ALL requirements for each
- Returns the first action set where ALL requirements pass, or `null`

Requirement types (each is an object with `type` + params):
- `{ type: 'quest', questId, status }` — check `context.questStatuses[questId] === status`
- `{ type: 'flag', flagId, value }` — check `context.storyFlags[flagId] === value` (default value=true)
- `{ type: 'vocab', wordId, mastery }` — check `context.vocabMastery[wordId] >= mastery` (mastery 0-1)
- `{ type: 'level', min }` — check `context.playerLevel >= min`
- `{ type: 'item', itemId }` — check `context.inventory.includes(itemId)`
- `{ type: 'time', startHour, endHour }` — same midnight wrap logic as ScheduleEvaluator
- `{ type: 'zone', zone }` — check `context.currentZone === zone`

Empty requirements array = always matches (default/fallback action set).

**2. `executeActions(actions, emitter)`**
- `actions`: array of action objects
- `emitter`: EventBus instance (or object with `.emit()`)
- Executes each action sequentially by emitting the corresponding event

Action types → EventBus event mapping:
- `{ type: 'speech', npcId, dialogueKey }` → emit `ACTION_SPEECH` with payload
- `{ type: 'startQuest', questId }` → emit `ACTION_START_QUEST`
- `{ type: 'completeQuest', questId }` → emit `ACTION_COMPLETE_QUEST`
- `{ type: 'giveItem', itemId, quantity }` → emit `ACTION_GIVE_ITEM`
- `{ type: 'teachWord', wordId }` → emit `ACTION_TEACH_WORD`
- `{ type: 'setFlag', flagId, value }` → emit `ACTION_SET_FLAG`
- `{ type: 'battle', enemyId }` → emit `ACTION_BATTLE`
- `{ type: 'teleport', zone, x, y }` → emit `ACTION_TELEPORT`
- `{ type: 'playSound', soundId }` → emit `ACTION_PLAY_SOUND`

For now, just emit the events — consumers (DialogueEngine, questSlice, etc.) will be wired in future phases. This is the execution engine, not the consumer wiring.

Add the new ACTION_* event constants to `src/utils/eventBusTypes.js`.

Follow project conventions: ES module exports, JSDoc, camelCase.
