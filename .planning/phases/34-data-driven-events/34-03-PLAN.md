Add step trigger detection to WorldScene:

1. In `create()` or `loadZone()` (wherever zone data is loaded), store the current zone's step triggers:
```js
this._stepTriggers = zoneData.stepTriggers || [];
this._stepTriggerCooldowns = {};  // id → lastFireTime
this._stepTriggersFired = new Set();  // for oneShot tracking
```

2. In `update()`, after player position is available, add step trigger check:
```js
if (this._stepTriggers.length && this.player) {
  this._checkStepTriggers();
}
```

3. New method `_checkStepTriggers()`:
```js
_checkStepTriggers() {
  const px = Math.floor(this.player.x / TILE);
  const py = Math.floor(this.player.y / TILE);
  const now = this.time.now;

  for (const trigger of this._stepTriggers) {
    // Check if player is within trigger bounds
    if (px < trigger.x || px >= trigger.x + (trigger.width || 1)) continue;
    if (py < trigger.y || py >= trigger.y + (trigger.height || 1)) continue;

    // Check oneShot
    if (trigger.oneShot && this._stepTriggersFired.has(trigger.id)) continue;

    // Check cooldown
    const lastFire = this._stepTriggerCooldowns[trigger.id] || 0;
    if (trigger.cooldown && now - lastFire < trigger.cooldown) continue;

    // Evaluate actionSets
    const context = buildActionContext();  // same helper from NPCManager — extract to shared util or import
    const matched = evaluateActionSets(trigger.actionSets, context);
    if (!matched) continue;

    // Fire!
    executeActions(matched.actions, EventBus);
    this._stepTriggerCooldowns[trigger.id] = now;
    if (trigger.oneShot) this._stepTriggersFired.add(trigger.id);

    // If trigger sets a flag, also store in oneShot tracking
    if (trigger.flagOnFire) {
      this._stepTriggersFired.add(trigger.id);
    }
  }
}
```

4. Import `evaluateActionSets, executeActions` from ActionSetExecutor.js at top of file.

5. Extract `buildActionContext()` from NPCManager to a shared location (e.g. `src/game/systems/actionContext.js`) so both NPCManager and WorldScene can use it. Or duplicate it — it's small (10 lines). Prefer the shared util.

6. Reset triggers on zone change: in the zone loading code, reset `_stepTriggers`, `_stepTriggerCooldowns`, and `_stepTriggersFired`.
