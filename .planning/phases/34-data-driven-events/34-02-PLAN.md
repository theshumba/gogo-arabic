**Part A: EventScriptRunner.js**

Create NEW file. A class that runs a JSON command array sequentially with delays:

```js
export class EventScriptRunner {
  constructor(emitter) { this.emitter = emitter; this.running = false; }

  async run(commands) {
    this.running = true;
    for (const cmd of commands) {
      if (!this.running) break;
      await this._executeCommand(cmd);
    }
    this.running = false;
  }

  _executeCommand(cmd) {
    return new Promise(resolve => {
      // Emit the action event
      this.emitter.emit(`ACTION_${cmd.type.toUpperCase()}`, cmd);
      // Wait for specified delay or default 0
      setTimeout(resolve, cmd.delay || 0);
    });
  }

  stop() { this.running = false; }
}
```

This allows cutscene-like sequences: speech → wait → teleport → speech.
