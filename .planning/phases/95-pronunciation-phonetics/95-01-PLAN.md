## 1. Data Structure: `src/data/arabicPhonetics.js`

### 1.1 ARABIC_CONSONANTS (28 items)

Each consonant object:
```javascript
{
  id: 'ba',  // unique identifier (lowercase, no spaces)
  letter: 'ب',
  name: 'Ba',
  nameArabic: 'باء',
  ipaSymbol: '/b/',
  articulationPoint: 'bilabial' | 'dental' | 'alveolar' | 'palatal' | 'velar' | 'uvular' | 'pharyngeal' | 'glottal',
  articulationManner: 'stop' | 'fricative' | 'affricate' | 'nasal' | 'liquid' | 'glide',
  voicing: true | false,  // true = voiced, false = voiceless
  englishApproximation: 'b as in "bat"',
  description: 'Bilabial voiced stop formed by closing lips',
  category: 'basic' | 'emphatic' | 'pharyngeal' | 'uvular' | 'glottal',  // optional, used for grouping
}
```

All 28 consonants must be defined. Key groupings:
- **Emphatic (4)**: ص (sad), ض (dad), ط (tah), ظ (zah) — pronounced with tongue pulled back
- **Pharyngeal (2)**: ع (ayn), ح (hah) — produced deep in throat
- **Uvular (2)**: ق (qaf), غ (ghayn) — produced at throat
- **Glottal (2)**: ء (hamza), ه (hah) — produced at glottis
- **Basic (18)**: All others

### 1.2 ARABIC_VOWELS (6 items)

Each vowel object:
```javascript
{
  id: 'fatha',  // 'fatha', 'kasra', 'damma', 'alif', 'ya', 'waw'
  symbol: 'َ',  // diacritical mark for short vowels, letter for long
  letter: null | 'ا' | 'ي' | 'و',  // for long vowels
  name: 'Fatha',
  nameArabic: 'فتحة',
  ipaSymbol: '/a/',
  type: 'short' | 'long',
  englishApproximation: 'a as in "father"',
  description: 'Open front unrounded short vowel',
}
```

Six vowels:
- Short: fatha (a), kasra (i), damma (u)
- Long: alif (aa), ya (ii), waw (uu)

### 1.3 MINIMAL_PAIRS (15+ pairs)

Each minimal pair object:
```javascript
{
  id: 'ba-fa',  // IDs of two letters joined with hyphen
  soundA: {
    id: 'ba',
    letter: 'ب',
    name: 'Ba',
    ipaSymbol: '/b/',
    exampleWords: ['باب (door)', 'بيت (house)'],
  },
  soundB: {
    id: 'fa',
    letter: 'ف',
    name: 'Fa',
    ipaSymbol: '/f/',
    exampleWords: ['فار (mouse)', 'فم (mouth)'],
  },
  difficulty: 1 | 2 | 3,  // 1 = obvious, 3 = subtle
  explanation: 'Both are labial fricatives, but ba is a stop while fa is a fricative',
}
```

Minimal pairs to include:
1. ب/ف (ba/fa) — bilabial stop vs fricative
2. ج/خ (jim/kha) — palatal vs velar
3. ض/د (dad/dal) — emphatic vs plain
4. ص/س (sad/sin) — emphatic vs plain fricative
5. ط/ت (tah/ta) — emphatic vs plain
6. ع/غ (ayn/ghayn) — pharyngeal vs uvular
7. ق/ك (qaf/kaf) — uvular vs velar
8. ح/خ (hah/kha) — pharyngeal vs velar
9. ل/ر (lam/ra) — lateral vs tap
10. م/ن (meem/noon) — bilabial vs alveolar nasal
11. ز/س (zay/sin) — alveolar vs voiceless fricative
12. ذ/ز (dhal/zay) — interdental vs alveolar
13. ش/س (sheen/sin) — postalveolar vs alveolar fricative
14. ض/ظ (dad/zah) — emphatic stop vs emphatic fricative
15. ه/ح (hah/hah variant) — glottal vs pharyngeal
16+ Additional pairs targeting specific learner difficulty patterns

## 2. Redux Slice: `src/store/slices/phoneticsSlice.js`

### 2.1 Initial State

```javascript
const initialState = {
  practiceScores: {},      // { [letterId]: { bestScore: number, attempts: number, lastAttempt: number } }
  minimalPairScores: {},   // { [pairId]: { bestScore: number, attempts: number, correct: number } }
  completedCategories: [], // ['emphatic', 'pharyngeal', ...]
  totalPracticeTime: 0,    // seconds
};
```

### 2.2 Reducers

```javascript
recordPracticeAttempt(state, action) {
  // payload: { id (letterId), score (0-100), type: 'consonant' | 'vowel' }
  const existing = state.practiceScores[id];
  if (!existing) {
    state.practiceScores[id] = { bestScore: score, attempts: 1, lastAttempt: Date.now() };
  } else {
    existing.attempts += 1;
    existing.lastAttempt = Date.now();
    if (score > existing.bestScore) existing.bestScore = score;
  }
}

recordMinimalPairAttempt(state, action) {
  // payload: { pairId, correct (boolean) }
  const existing = state.minimalPairScores[pairId];
  if (!existing) {
    state.minimalPairScores[pairId] = { bestScore: correct ? 100 : 0, attempts: 1, correct: correct ? 1 : 0 };
  } else {
    existing.attempts += 1;
    if (correct) existing.correct += 1;
    existing.bestScore = Math.round((existing.correct / existing.attempts) * 100);
  }
}

markCategoryCompleted(state, action) {
  // payload: categoryId
  if (!state.completedCategories.includes(categoryId)) {
    state.completedCategories.push(categoryId);
  }
}

addPracticeTime(state, action) {
  // payload: seconds
  state.totalPracticeTime += action.payload;
}
```

### 2.3 Selectors

```javascript
export const selectPracticeScores = (state) => state.phonetics.practiceScores;
export const selectMinimalPairScores = (state) => state.phonetics.minimalPairScores;
export const selectCompletedCategories = (state) => state.phonetics.completedCategories;
export const selectTotalPracticeTime = (state) => state.phonetics.totalPracticeTime;

// Select practice score for a specific letter
export const selectLetterPracticeScore = (state, letterId) =>
  state.phonetics.practiceScores[letterId] || null;

// Select weakest sounds (lowest bestScore, with attempts > 0)
export const selectWeakestSounds = createSelector(
  [selectPracticeScores],
  (scores) => {
    const attempted = Object.entries(scores)
      .filter(([_, data]) => data.attempts > 0)
      .sort((a, b) => (a[1].bestScore || 0) - (b[1].bestScore || 0))
      .slice(0, 5);  // top 5 weakest
    return attempted.map(([id, data]) => ({ id, ...data }));
  }
);

// Select overall pronunciation accuracy (average bestScore across all attempted letters)
export const selectPronunciationAccuracy = createSelector(
  [selectPracticeScores],
  (scores) => {
    const attempted = Object.values(scores).filter(s => s.attempts > 0);
    if (attempted.length === 0) return 0;
    const sum = attempted.reduce((acc, s) => acc + (s.bestScore || 0), 0);
    return Math.round(sum / attempted.length);
  }
);

// Select minimal pair accuracy (average of all pair scores)
export const selectMinimalPairAccuracy = createSelector(
  [selectMinimalPairScores],
  (scores) => {
    const attempted = Object.values(scores).filter(s => s.attempts > 0);
    if (attempted.length === 0) return 0;
    const sum = attempted.reduce((acc, s) => acc + (s.bestScore || 0), 0);
    return Math.round(sum / attempted.length);
  }
);
```
