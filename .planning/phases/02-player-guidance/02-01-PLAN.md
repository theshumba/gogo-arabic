  <action>
Add the following to questSlice.js:

1. **New state field** in initialState:
   - `activeQuestId: null` — tracks which quest the player is actively following

2. **New reducer** `setActiveQuest`:
   - Payload: questId (string)
   - Only set if `state.quests[questId]?.status === 'active'`
   - If payload is `null`, clear activeQuestId

3. **Auto-set logic** in `initializeQuests` reducer:
   - After initializing quest entries, if `state.activeQuestId` is null OR the currently active quest is no longer 'active' status, auto-select the first quest with status 'active' (iterate Object.keys(state.quests))

4. **Auto-set logic** in `completeQuest` reducer:
   - After completing the quest, if `state.activeQuestId === questId` (the completed quest was the tracked one), auto-select the next active quest (first Object.keys with status 'active')

5. **New memoized selectors** (using createSelector from RTK):

   a. `selectNpcQuestMarkers` — derives `{ [npcId]: 'exclamation' | 'question' | null }` from quest state:
      - Import `questsData` from `../../data/quests.json` at the top of the file
      - For each quest definition in questsData:
        - If quest status is 'completed' AND `rewardClaimed` is false AND quest has `npcGiver`: set marker to 'question' for the npcGiver (map npcGiver role to NPC ID using a lookup — see below)
        - If quest status is 'locked': check if all prerequisites are 'completed'. If yes AND quest has `npcGiver`: set marker to 'exclamation'
      - **NPC ID mapping**: Quest data uses short role names (e.g., "scholar", "merchant", "student") as `npcGiver`, but NPC IDs in zones.js use full IDs (e.g., "scholar-yusuf", "merchant-fatima"). Build a mapping object at module level:
        ```javascript
        // Map quest npcGiver roles to full NPC IDs from zones data
        const NPC_GIVER_TO_ID = {};
        for (const qd of questsData) {
          if (qd.npcGiver && qd.zone) {
            const zone = ZONES[qd.zone];
            if (zone) {
              const npc = zone.npcs.find(n => n.id.startsWith(qd.npcGiver));
              if (npc) {
                NPC_GIVER_TO_ID[`${qd.npcGiver}_${qd.zone}`] = npc.id;
              }
            }
          }
        }
        ```
        Use `NPC_GIVER_TO_ID[quest.npcGiver + '_' + quest.zone]` to resolve the full NPC ID.
      - Priority: 'question' (turn-in) takes precedence over 'exclamation' (available) if same NPC has both.

   b. `selectActiveQuest` — returns the full active quest object or null:
      - Input selectors: `selectAllQuests`, `(state) => state.quests.activeQuestId`
      - If no activeQuestId or quest doesn't exist or quest.status !== 'active', return null
      - Look up quest definition from questsData to get title, description, target, zone, npcGiver, trackEvent
      - Return merged object: `{ id, status, progress, rewardClaimed, title, description, target, zone, npcGiver, trackEvent }`

   c. `selectActiveQuestObjectiveLocation` — returns `{ x, y }` or null:
      - Input selectors: `selectActiveQuest`
      - If no active quest, return null
      - Look up NPC location from ZONES data: find the zone, find the NPC matching npcGiver, return `{ x: npc.x * 64, y: npc.y * 64 }` (tile to pixel conversion)
      - If NPC not found (non-NPC quest like treasure_hunter), return null (compass will hide)

6. **Export** the new action and selectors:
   - Add `setActiveQuest` to the destructured actions export
   - Export `selectNpcQuestMarkers`, `selectActiveQuest`, `selectActiveQuestObjectiveLocation`

7. **Import** ZONES at the top: `import { ZONES } from '../../data/zones.js';`
   Also import questsData: `import questsData from '../../data/quests.json';`
