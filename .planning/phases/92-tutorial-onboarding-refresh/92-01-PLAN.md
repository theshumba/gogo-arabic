# Phase 92 — Tutorial & Onboarding Refresh

## Problem
Gogo Arabic has grown to 20+ quiz types, 6 skill trees, daily challenges, reading, writing, conversation, mini-games, lore codex, faction system, and more. The original onboarding (Phase 47, v10.0) only covers basic movement and meeting NPCs. New players are overwhelmed by unlocked features with no introduction.

## Solution
Progressive feature introduction system that gradually reveals game systems as the player levels up, plus contextual tips during gameplay and gentle feature suggestions for unexplored systems.

## Files Created

### Data
1. `src/data/featureIntroductions.js` — 20 progressive feature introductions keyed to player level
2. `src/data/onboardingTips.js` — 30 contextual tips for gameplay moments

### State
3. `src/store/slices/onboardingSlice.js` — Redux slice tracking seen intros/tips, feature usage, onboarding phase

### Components
4. `src/components/Onboarding/FeatureIntroduction.jsx` + `.module.css` — Step-through overlay for feature reveals
5. `src/components/Onboarding/ContextualTip.jsx` + `.module.css` — Non-blocking tooltip for contextual hints
6. `src/components/Onboarding/FeatureSuggestion.jsx` + `.module.css` — Gentle nudge for unexplored features

### Tests
7. `src/data/__tests__/featureIntroductions.test.js` — Data integrity tests
8. `src/data/__tests__/onboardingTips.test.js` — Data integrity tests
9. `src/store/slices/__tests__/onboardingSlice.test.js` — Reducer/selector tests

## Design Decisions
- **No edits to existing files** — all new files, integrated via lazy loading
- **CSS Modules** with dark theme (#1a1a2e background, #FFD700 gold accent, #D4A843 secondary gold)
- **Non-blocking** — tips and suggestions never interrupt active gameplay
- **No repeat** — introductions and tips track seen IDs in Redux state
- **Phase auto-advance** — onboarding phase progresses based on feature usage count, not just level
- **Bilingual** — all user-facing text includes Arabic alongside English
- **Default exports** on components for React.lazy() compatibility
