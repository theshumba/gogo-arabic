    **1. Create `src/data/placementTest.js`:**

    Export `PLACEMENT_ITEMS` — array of exactly 30 objects. Each item:
    ```
    {
      id: 'placement_001',           // sequential string IDs
      cefrLevel: 'Pre-A1',           // 'Pre-A1' | 'A1' | 'A2' | 'B1'
      domain: 'vocabulary',          // one of: 'vocabulary' | 'grammar' | 'reading' | 'roots' | 'speaking' | 'culture'
      type: 'ar-to-en',             // quiz type key — only simple choice types: 'ar-to-en', 'en-to-ar', 'fill-blank', 'GrammarFill', 'ClozePassage'
      prompt: 'What does كتاب mean?', // question text
      arabic: 'كتاب',               // Arabic word/phrase
      english: 'book',              // English meaning
      options: ['book', 'door', 'sun', 'water'],  // 4 choices
      correctAnswer: 'book',        // must match one option exactly
    }
    ```

    **Distribution rules (5 items per CEFR level per domain spread):**
    - Pre-A1: 5 items (basic letter/word recognition) — domains: vocabulary(2), reading(2), culture(1)
    - A1: 10 items — domains: vocabulary(2), grammar(2), reading(2), roots(1), speaking(1), culture(2)
    - A2: 10 items — domains: vocabulary(2), grammar(2), reading(2), roots(2), speaking(1), culture(1)
    - B1: 5 items — domains: grammar(2), reading(1), roots(1), culture(1)

    Total: 30 items. At least 5 of the 6 domains represented at each level (where feasible).

    Export `PLACEMENT_LEVELS = ['Pre-A1', 'A1', 'A2', 'B1']` — B1 is the cap. No B2/C1/C2 items.

    All items must use simple choice types (NOT WordOrder, SentenceBuilder, CategorySort, MatchPairs — those require tile/drag state). Allowed types: 'ar-to-en', 'en-to-ar', 'fill-blank', 'GrammarFill', 'ClozePassage'.

    Use real Arabic vocabulary and grammar content. Pre-A1 items test basic recognition (letters, common greetings). A1 items test simple vocabulary and basic grammar. A2 items test sentence-level comprehension. B1 items test paragraph-level reading and complex grammar.

    **2. Create `src/services/placementEngine.js`:**

    Define `PLACEMENT_CEFR_ORDER = { 'Pre-A1': 0, 'A1': 1, 'A2': 2, 'B1': 3 }` — do NOT import/modify `CEFR_ORDER` from quizTypes.js (that only has A1-B2, would break existing tests).

    Export these pure functions:

    **`selectNextItem(answeredIds, currentLevelEstimate, answers)`** — IRT binary search:
    - Start at A1 estimate
    - After each answer: if correct, move estimate UP one level; if wrong, move DOWN one level (clamped to Pre-A1..B1)
    - Select next item from PLACEMENT_ITEMS where item.cefrLevel === currentLevelEstimate AND item.id not in answeredIds
    - If no items at current level, try adjacent levels
    - Returns null when bank exhausted or answeredIds.length >= 20 (test cap)
    - Returns the selected item object

    **`computeRawScore(answers)`** — answers is `[{ itemId, correct: boolean }]`; returns count of correct answers.

    **`assignCefrLevel(rawScore, totalItems)`** — Maps score percentage to raw CEFR level:
    - pct < 0.25 → Pre-A1
    - pct < 0.50 → A1
    - pct < 0.75 → A2
    - pct >= 0.75 → B1 (cap)
    Then applies one-level-lower conservative placement: `assignedIdx = Math.max(0, rawLevelIdx - 1)`.
    Pre-A1 mapped to stored 'A1' for cefrProgressSlice (that slice only stores A1-B2).
    Returns `{ rawLevel, assignedLevel, storedLevel }`.

    **`dropOneTier(level)`** — "Start Lower" escape hatch. Drops one tier: B1→A2, A2→A1, A1→A1 (floor), Pre-A1→Pre-A1 (floor). Returns the lower level string.

    **`shouldEarlyExit(answers)`** — Returns true if last 10 answers are all correct (consecutive). Check `answers.length >= 10` AND last 10 entries all have `correct: true`.

    **`deriveGrammarUnlocks(assignedLevel)`** — Import `grammarLessons` from `../data/grammar.js`. Filter lessons where `PLACEMENT_CEFR_ORDER[lesson.cefrLevel] <= PLACEMENT_CEFR_ORDER[assignedLevel]`. Sort by `order` ascending. Return array of lesson IDs (strings). This produces a contiguous sequence from order 1 upward (per Pitfall 2 from RESEARCH.md).

    **`deriveSkillTreeUnlocks(assignedLevel)`** — Import `SKILL_TREES, SKILL_TREE_ORDER` from `../data/skillTrees.js`. For each tree, filter nodes where `PLACEMENT_CEFR_ORDER[node.cefrLevel] <= PLACEMENT_CEFR_ORDER[assignedLevel]`. Sort by xpCost ascending (same pattern as initializeSkillTree.js). Return `{ [treeId]: string[] }` mapping each tree to array of eligible node IDs. Only include trees with at least one eligible node.
