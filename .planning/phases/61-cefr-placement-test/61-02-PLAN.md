    - Title: "CEFR Placement Test" in FONTS.pixel style
    - Subtitle in Arabic: "اختبار تحديد المستوى"
    - Brief explanation: "Answer questions to find your Arabic level. The test adapts to your ability — answer correctly and questions get harder."

    - "Skip — Start at Beginner" button (secondary style) — calls onSkip()
    - Use useFocusTrap for accessibility
    - Wrap in framer-motion `motion.div` with fadeIn animation (same pattern as QuizOverlay)

    **Phase: testing**
    - Progress indicator: "Question {answeredIds.length + 1} / 20" (or "/ {total}" if fewer items remain)
    - Display current item:
      - If item.arabic: show Arabic text large (36px, FONTS.arabic, RTL, gold color — same as ArabicToEnglish prompt style)
      - Show item.prompt as the question text
      - Render 4 option buttons in a column (same choice button pattern as ArabicToEnglish.jsx — beige background, dark border, pixel font)
    - On option click:
      1. Set selectedOption
      2. Determine correct: `option === currentItem.correctAnswer`
      3. Show brief feedback (green border = correct, red border = wrong) for 800ms via showFeedback state
      4. After 800ms timeout: update answers array, answeredIds, adjust levelEstimate (up if correct, down if wrong)
      5. Check shouldEarlyExit(updatedAnswers) — if true, compute result and go to 'result' phase
      6. Check if answeredIds.length >= 20 — if true, compute result and go to 'result' phase
      7. Otherwise: call selectNextItem(updatedAnsweredIds, newLevelEstimate, updatedAnswers) for next question
      8. If selectNextItem returns null (bank exhausted), compute result and go to 'result' phase
    - "Quit Test" small link in corner — calls onSkip()
    - Disable option buttons while showFeedback is true (prevent double-clicks)

    **Phase: result**
    - Title: "Your Arabic Level"
    - Large CEFR level badge: result.assignedLevel displayed prominently (e.g., "A2" in large gold text)
    - Explanation text: "Based on your answers, we recommend starting at {assignedLevel}. This is one level below your test score ({rawLevel}) to ensure a comfortable learning experience."
    - Score display: "{rawScore} / {totalAnswered} correct"
    - "Start at {assignedLevel}" button (primary/gold) — calls onComplete(result.assignedLevel, rawScore, result.storedLevel)
    - "Start Lower ({dropOneTier(result.assignedLevel)})" button (secondary) — calls onComplete with the dropped tier level. If assignedLevel is already A1 or Pre-A1, hide this button (floor reached).
    - Use dropOneTier from placementEngine to compute the lower option
