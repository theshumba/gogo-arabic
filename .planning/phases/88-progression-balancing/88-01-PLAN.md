# Phase 88 — Progression Balancing

## Overview
Central progression balancing system that controls XP curves, vocabulary pacing, content unlock gates, session optimization, and XP reward standardization. All functions are pure (no Redux, no side effects) for easy testing and reuse across the codebase.

## Files Created

### Data
- `src/data/progressionConfig.js` — Central configuration for XP curve, vocab pacing, unlock gates, XP rewards, session optimization
- `src/data/__tests__/progressionConfig.test.js` — XP curve monotonicity, feature coverage, CEFR gate consistency

### Services
- `src/services/progressionService.js` — Pure functions: level calculation, XP progress, vocab pacing, feature unlocks, session planning, progress reports
- `src/services/__tests__/progressionService.test.js` — All service functions with edge cases

### Components
- `src/components/Progress/ProgressReport.jsx` + `.module.css` — Full progress dashboard (level, vocab, grammar, activity, streaks, next unlocks, CEFR estimate)
- `src/components/UI/FeatureUnlockToast.jsx` + `.module.css` — Toast notification for newly unlocked features with gold animation

### Tests
- `src/store/slices/__tests__/progressionHelpers.test.js` — Integration tests using mock Redux state

## Design Decisions
- XP curve uses `baseXp * level^exponent` formula (gentle early levels, gradual slowdown)
- Vocabulary pacing: 5-15 new words/day based on research (optimal retention window)
- Review-to-new ratio of 70/30 follows spaced repetition research
- Session warmup (3 easy review Qs) prevents frustration; cooldown (2 easy Qs) builds confidence
- Feature unlock gates create a steady drip of new content (never punitive, always rewarding)
- All progression functions are pure — no Redux imports, no side effects, easily testable
- Components use default exports for lazy loading compatibility
- CSS uses existing variables.css tokens (--color-xp-gold, --font-pixel, --color-panel, etc.)
- No edits to existing files — fully self-contained module

## Research Basis
- Spaced repetition: 70% review / 30% new content ratio (Pimsleur, Anki research)
- Vocabulary acquisition: 5-15 new items/day optimal for adult learners (Nation, 2001)
- Session duration: 20-25 minute focused sessions with breaks (Pomodoro technique)
- XP curve exponent 1.35 ensures early gratification without trivializing later progression
- Mastery threshold 65% prevents overwhelming learners with new content before consolidation
