    1. In learningProgressMiddleware.js, add a handler for the `cefrProgress/setCefrLevel` action type.

       After `const result = next(action);` (post-dispatch):
       - Check if action.type === 'cefrProgress/setCefrLevel'
       - Extract `level` from action.payload
       - Read worldState flags from store.getState().worldState.flags
       - Check if flag `cefr_milestone_{level.toLowerCase()}_shown` is already set — if yes, skip (milestone already celebrated)
       - If flag is NOT set, emit an EventBus event to trigger the Amira CEFR dialogue:
         ```js
         import { EventBus } from '../../utils/eventBus.js';
         import { EVENTS } from '../../utils/eventBusTypes.js';

         // After setCefrLevel dispatch:
         if (action.type === 'cefrProgress/setCefrLevel') {
           const level = action.payload.level;
           const flags = store.getState().worldState?.flags || {};
           const milestoneKey = `cefr_milestone_${level.toLowerCase()}_shown`;
           if (!flags[milestoneKey]) {
             EventBus.emit(EVENTS.NPC_DIALOGUE_START, {
               npcId: 'guide-amira-cefr',
               context: { cefr_level: level },
             });
           }
         }
         ```

       IMPORTANT: The EventBus.emit for NPC dialogue is a request — the game scene (if active) picks it up. If the player is in a menu overlay (not in the world), the event is simply not handled (no crash, no error). The dialogue will trigger next time Amira is interacted with in the world if the event was missed.
