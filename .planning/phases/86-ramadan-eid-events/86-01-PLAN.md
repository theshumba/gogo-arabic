# Phase 86 — Ramadan & Eid Seasonal Events

## Overview
Add seasonal event support for the three major Islamic holidays: Ramadan, Eid al-Fitr, and Eid al-Adha. These calendar-driven events provide themed vocabulary, quests, XP bonuses, and cultural immersion during their real-world dates.

## Files Created

### Utilities
- `src/utils/hijriCalendar.js` — Tabular Islamic calendar conversion (Type IIa civil epoch) with event detection functions
- `src/utils/__tests__/hijriCalendar.test.js` — Hijri conversion accuracy, event detection for known dates, edge cases

### Data
- `src/data/seasonalEvents.js` — Event definitions: 20 Ramadan vocab, 10 Eid al-Fitr vocab, 10 Eid al-Adha vocab, quests, themes
- `src/data/__tests__/seasonalEvents.test.js` — Data integrity: vocab fields, quest fields, required properties

### State
- `src/store/slices/seasonalEventSlice.js` — Redux slice: activeEvent, eventProgress, yearlyHistory, word/quest tracking
- `src/store/slices/__tests__/seasonalEventSlice.test.js` — All reducers and selectors

### Components
- `src/components/Seasonal/SeasonalEventOverlay.jsx` + `.module.css` — Full overlay with vocab list, quest progress, day counter
- `src/components/Seasonal/SeasonalEventBanner.jsx` + `.module.css` — 40px persistent top banner during active events

## Design Decisions
- Hijri calendar uses tabular algorithm (accurate to +/-1 day, sufficient for a game)
- Green (#006400) + gold (#FFD700) theme for Islamic events, matching traditional symbolism
- XP multipliers: 1.25x during Ramadan, 1.5x during Eid celebrations
- Overlay uses default export for lazy loading compatibility
- No edits to existing files — fully self-contained module

## Cultural Notes
- All Arabic vocabulary includes proper tashkeel (diacritics) where pedagogically useful
- Content is respectful and educational — focused on cultural vocabulary, not religious instruction
- Greetings use universally accepted Islamic phrases
