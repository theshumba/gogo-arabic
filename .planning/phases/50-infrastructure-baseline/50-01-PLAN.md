  <action>
1. Install rollup-plugin-visualizer as dev dependency:
   ```
   npm install --save-dev rollup-plugin-visualizer
   ```

2. In `vite.config.js`, add the import at the top:
   ```javascript
   import { visualizer } from 'rollup-plugin-visualizer';
   ```

3. Update the `plugins` array to include the visualizer CONDITIONALLY (gated behind ANALYZE=true):
   ```javascript
   plugins: [
     react({ jsxRuntime: 'automatic' }),
     validateDialoguePlugin(),
     process.env.ANALYZE === 'true' && visualizer({
       template: 'treemap',
       open: true,
       filename: 'dist/bundle-report.html',
       gzipSize: true,
       brotliSize: false,
     }),
   ].filter(Boolean),
   ```
   IMPORTANT: The `.filter(Boolean)` at the end removes the `false` value when ANALYZE is not set. Do NOT add visualizer() unconditionally -- it opens a browser on every build.

4. In `package.json` scripts, add:
   ```json
   "build:analyze": "ANALYZE=true vite build"
   ```
   Place it immediately after the existing `"build": "vite build"` line.

5. Run `npm run build` to verify the build still succeeds and no errors from the visualizer import.
