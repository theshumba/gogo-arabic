**Step 1: Install fake-indexeddb as dev dependency**
```bash
npm install --save-dev fake-indexeddb
```
This is a DEV dependency only — does NOT violate the "no new runtime dependencies" constraint. It provides IndexedDB polyfill for jsdom test environment.

**Step 2: Update `src/test/setup.js`**
Add IndexedDB polyfill at the top of the setup file (before any tests run):
```javascript
import 'fake-indexeddb/auto';
```
This makes `indexedDB`, `IDBDatabase`, `IDBTransaction` etc. available globally in jsdom. Place this BEFORE existing imports. Also add cleanup in afterEach to delete test databases:
```javascript
afterEach(async () => {
  // ... existing cleanup ...
  // Clean up IndexedDB between tests
  const dbs = await indexedDB.databases?.() || [];
  for (const db of dbs) {
    if (db.name) indexedDB.deleteDatabase(db.name);
  }
});
```
Note: `indexedDB.databases()` may not be available in fake-indexeddb. If not, use a simpler approach: just delete the known DB name `'gogo-arabic-idb'` in afterEach. Also, the adapter caches the DB connection in module scope — between tests, the cached connection may be stale after deleteDatabase. To handle this, the adapter should export a `_resetForTesting()` method that nullifies the cached dbInstance, OR the tests can dynamically import the adapter fresh per test using `vi.resetModules()`.

**Step 3: Write `src/services/storage/__tests__/indexedDBAdapter.test.js`** (~80 lines)

Use `vi.resetModules()` + dynamic import in beforeEach to get fresh adapter instances (avoids stale cached connections). Delete database `'gogo-arabic-idb'` in afterEach.
