**dialogueSchema.js — Extend the Zod schema for hub-and-spoke dialogue:**

Keep all existing schemas and exports. Add new sub-schemas and extend existing ones:

1. Add `conditionSchema` — validates dialogue conditions:
   ```javascript
   const conditionSchema = z.object({
     quest: z.object({
       id: z.string(),
       status: z.enum(['active', 'completed', 'not_started']).optional(),
     }).optional(),
     storyFlag: z.object({
       key: z.string(),
       value: z.union([z.string(), z.number(), z.boolean()]),
     }).optional(),
     relationship: z.object({
       min: z.number().min(0).max(5).optional(),
       max: z.number().min(0).max(5).optional(),
     }).optional(),
     vocabulary: z.object({
       wordId: z.string(),
       mastered: z.boolean().optional(),
     }).optional(),
     not: z.lazy(() => conditionSchema).optional(),
   }).passthrough();
   ```

2. Add `effectSchema` — validates dialogue effects:
   ```javascript
   const effectSchema = z.object({
     type: z.enum([
       'quest_start', 'quest_complete', 'relationship_change',
       'story_flag', 'teach_word', 'give_item', 'unlock_area',
       'change_npc_state', 'open_shop'
     ]),
     questId: z.string().optional(),
     amount: z.number().optional(),
     flag: z.string().optional(),
     value: z.union([z.string(), z.number(), z.boolean()]).optional(),
     wordId: z.string().optional(),
     itemId: z.string().optional(),
     quantity: z.number().optional(),
     area: z.string().optional(),
     npcId: z.string().optional(),
     state: z.string().optional(),
   }).passthrough();
   ```

3. Add `personalitySchema`:

   const personalitySchema = z.object({

     mood: z.string().optional(), // cheerful, serious, worried, excited

**DialogueEngine.js — Create Phaser system following NPCManager/SceneStackManager pattern:**

```javascript
import { EventBus } from '../../utils/eventBus.js';
import { EVENTS } from '../../utils/eventBusTypes.js';

import { showNotification } from '../../store/slices/uiSlice.js';
import questsData from '../../data/quests.json';
```

Class structure:

```javascript
export class DialogueEngine {
  constructor(scene) {
    this.scene = scene;
    this.currentNpcId = null;
  }
```

**Method 1: `evaluateCondition(condition)`**
- Returns boolean. If condition is null/undefined, returns true (no condition = always visible).
- Reads Redux state via `store.getState()`.
- Checks each condition field:
  - `condition.quest`: Check `state.quests.quests[condition.quest.id]?.status` matches `condition.quest.status`. If `condition.quest.status` is `'not_started'`, check that quest status is undefined or not 'active'/'completed'.
  - `condition.storyFlag`: Check `state.narrative.storyFlags[condition.storyFlag.key]` equals `condition.storyFlag.value`.
  - `condition.relationship`: Check `state.narrative.npcRelationships[this.currentNpcId] ?? 0` is >= min and <= max (if specified).
  - `condition.vocabulary`: Check `state.vocabulary.fsrsCards[condition.vocabulary.wordId]` exists (truthy = learned). If `condition.vocabulary.mastered` is true, check card exists.
  - `condition.not`: Recursively evaluate and negate result.
- All conditions are AND-combined (all must pass).

**Method 2: `getAvailableTopics(npc)`**
- Sets `this.currentNpcId = npc.id`.
- Filter `npc.dialogueTrees` to those with `topic` field (hub-and-spoke trees).
- For each, call `evaluateCondition(tree.condition)`.
- Return array of `{ treeId: tree.id, topic: tree.topic, label: tree.lines[0]?.english || tree.topic, priority: tree.priority ?? 99 }` sorted by priority ascending.

**Method 3: `getFilteredChoices(choices)`**
- For each choice in the array, evaluate `choice.condition`.
- Return only choices where condition passes (or has no condition).

**Method 4: `executeEffects(effects, npcId)`**
- Sets `this.currentNpcId = npcId` if provided.
- Iterates effects array. For each effect based on `effect.type`:
  - `'quest_start'`: Find quest in questsData by `effect.questId`, dispatch `updateQuestProgress({ questId: effect.questId, amount: 0 })` to activate it. Emit `EVENTS.SFX_QUEST`.
  - `'quest_complete'`: Dispatch `completeQuest(effect.questId)`, `showNotification(...)`, `checkPrerequisites(questsData)`. Emit `EVENTS.SFX_QUEST`.
  - `'relationship_change'`: Dispatch `incrementNpcRelationship({ npcId: this.currentNpcId, amount: effect.amount })`. Emit `EVENTS.DIALOGUE_RELATIONSHIP_CHANGED` with `{ npcId: this.currentNpcId, amount: effect.amount, newLevel }`.
  - `'story_flag'`: Dispatch `setStoryFlag({ flag: effect.flag, value: effect.value })`.
  - `'teach_word'`: Emit `EVENTS.DIALOGUE_EFFECT_EXECUTED` with `{ type: 'teach_word', wordId: effect.wordId }`. (Actual FSRS logic stays in useDialogue hook.)
  - `'give_item'`: Emit `EVENTS.DIALOGUE_EFFECT_EXECUTED` with `{ type: 'give_item', itemId: effect.itemId, quantity: effect.quantity }`.
  - `'unlock_area'`: Dispatch `setStoryFlag({ flag: 'area_unlocked_' + effect.area, value: true })`.
  - `'change_npc_state'`: Dispatch `setStoryFlag({ flag: 'npc_state_' + (effect.npcId || this.currentNpcId), value: effect.state })`.
  - `'open_shop'`: Emit `EVENTS.SHOP_OPEN` with `{ npcId: this.currentNpcId }`.
- After all effects, emit `EVENTS.DIALOGUE_EFFECT_EXECUTED` with summary `{ npcId: this.currentNpcId, effectCount: effects.length }`.

**Method 5: `recordPlayerChoice(npcId, choiceId)`**
- Dispatches `recordChoice({ npcId, choiceId })` to narrativeSlice.

**Method 6: `shouldReturnToHub(tree)`**
- Returns `tree.returnToHub === true`.

**Method 7: `destroy()`**
- Sets `this.currentNpcId = null`.
