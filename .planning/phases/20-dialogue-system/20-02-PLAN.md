  <action>
Rewrite useDialogue.js to support hub-and-spoke conversation flow while maintaining backward compatibility with existing NPC data that doesn't have topic fields.

**State machine phases:**
1. `greeting` — Playing the greeting/intro tree lines
2. `hub` — Showing topic selection menu (available topics from DialogueEngine.getAvailableTopics)
3. `topic` — Playing a selected topic tree's lines
4. `returning` — Topic tree ended with returnToHub=true, transitioning back to hub

**New state variables:**
```javascript
const [phase, setPhase] = useState('greeting'); // 'greeting' | 'hub' | 'topic' | 'returning'
const [availableTopics, setAvailableTopics] = useState([]);
const [currentTopicTreeId, setCurrentTopicTreeId] = useState(null);
const [topicsDiscussed, setTopicsDiscussed] = useState([]); // track discussed topics this session
const [quizReturnState, setQuizReturnState] = useState(null); // {treeId, lineIndex} for mid-quiz return
```

**Create a DialogueEngine instance:**
Import DialogueEngine. Create instance at hook level (not in effect):
```javascript
const engineRef = useRef(null);
if (!engineRef.current) {
  engineRef.current = new DialogueEngine(null); // no scene needed for condition/effect logic
}
```
Note: DialogueEngine doesn't actually need the Phaser scene for condition evaluation and effect execution — it only needs store access. Pass null for scene since useDialogue operates on the React side.

**Picking the initial tree:**
Keep the existing `pickDialogueTree` function for backward compatibility. When an NPC has no `topic` fields on any tree, fall back to the old linear flow (phase stays 'greeting', never enters 'hub').

When an NPC has topic trees: pick the `hub` tree (tree with `id: 'hub'` or `trigger: 'first_meeting'`), play its lines, then transition to 'hub' phase.

**`refreshTopics` function:**
```javascript
const refreshTopics = useCallback(() => {
  if (!npc || !engineRef.current) return [];
  engineRef.current.currentNpcId = npc.id;
  const topics = engineRef.current.getAvailableTopics(npc);
  setAvailableTopics(topics);
  return topics;
}, [npc]);
```

Call `refreshTopics` each time phase transitions to 'hub'. This re-evaluates conditions so new topics unlock dynamically (DLGE-06).

**`selectTopic` function (new):**
```javascript
const selectTopic = useCallback((topicTreeId) => {
  const tree = npc.dialogueTrees.find(t => t.id === topicTreeId);
  if (!tree) return;
  setCurrentTree(tree);
  setLineIndex(0);
  setCurrentTopicTreeId(topicTreeId);
  setPhase('topic');
  setTopicsDiscussed(prev => [...new Set([...prev, tree.topic || topicTreeId])]);
  EventBus.emit(EVENTS.DIALOGUE_TOPIC_SELECTED, { npcId: npc.id, topicId: topicTreeId, topic: tree.topic });
}, [npc]);
```

**Update `advance` function:**
When advancing past the last line:
- If phase is 'greeting' and NPC has topic trees: transition to 'hub', call `refreshTopics()`.
- If phase is 'topic' and `shouldReturnToHub(currentTree)`: transition to 'hub', call `refreshTopics()`.
- If phase is 'topic' and NOT returnToHub: call `close()`.
- If phase is 'greeting' and NPC has NO topic trees (legacy): call `close()` (same as before).

**Update `handleChoice` function:**
- Before processing choice, check for `choice.effects` array. If present, call `engineRef.current.executeEffects(choice.effects, npc.id)`.
- If choice has `choice.choiceId` (or generate one from choice text), call `engineRef.current.recordPlayerChoice(npc.id, choiceId)`.
- Keep all existing choice action handling (open_shop, open_alphabet, daily_quiz, cultural_dialogue, show_cultural_menu, hide_cultural_menu, choice.next navigation).
- Add new action: `'return_to_hub'` — transition to 'hub' phase, call `refreshTopics()`.
- Filter choices using `engineRef.current.getFilteredChoices(line.choices)` before rendering.

**Mid-dialogue quiz handling (DLGE-12):**
When a quiz action line is encountered:
- Save current state: `setQuizReturnState({ treeId: currentTree.id, lineIndex: lineIndex + 1 })`.
- Open quiz as before.
- Add a `useEffect` that watches for quiz close. When quiz overlay closes and `quizReturnState` is set:
  - Find the tree, set lineIndex to saved position.
  - If no more lines after quiz, return to hub or close.

The quiz close detection already exists via the quiz overlay — when dispatch(openQuiz) triggers, the dialogue pauses. The tricky part is resuming. Add a `resumeAfterQuiz` callback:
```javascript
const resumeAfterQuiz = useCallback(() => {
  if (!quizReturnState) return;
  const tree = npc.dialogueTrees.find(t => t.id === quizReturnState.treeId);
  if (tree && quizReturnState.lineIndex < tree.lines.length) {
    setCurrentTree(tree);
    setLineIndex(quizReturnState.lineIndex);
  } else {
    // Quiz was at end of tree, return to hub or close
    if (phase === 'topic' && engineRef.current.shouldReturnToHub(tree)) {
      setPhase('hub');
      refreshTopics();
    } else {
      close();
    }
  }
  setQuizReturnState(null);
}, [quizReturnState, npc, phase, refreshTopics, close]);
```

**Return API (expand to include new fields):**
```javascript
return {
  // Existing
  currentTree, lineIndex, close, advance, handleChoice,
  showCulturalMenu, setShowCulturalMenu,
  // New
  phase,                    // 'greeting' | 'hub' | 'topic' | 'returning'
  availableTopics,          // [{treeId, topic, label, priority}]
  selectTopic,              // (topicTreeId) => void
  topicsDiscussed,          // string[] of topic IDs discussed this session
  filteredChoices,          // choices filtered by conditions (computed from current line)
  resumeAfterQuiz,          // () => void — call when quiz overlay closes
  isHubAndSpoke,            // boolean — does this NPC support topic selection?
};
```

**Compute `filteredChoices` as a memoized value:**
```javascript
const filteredChoices = useMemo(() => {
  const line = currentTree?.lines[lineIndex];
  if (!line?.choices || !engineRef.current) return line?.choices || [];
  return engineRef.current.getFilteredChoices(line.choices);
}, [currentTree, lineIndex]);
```

**Compute `isHubAndSpoke`:**
```javascript
const isHubAndSpoke = useMemo(() => {
  if (!npc) return false;
  return npc.dialogueTrees.some(t => t.topic);
}, [npc]);
```
