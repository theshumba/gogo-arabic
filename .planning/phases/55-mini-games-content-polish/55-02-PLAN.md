**Create `src/utils/frechetDistance.js`** — pure utility module with two named exports:

1. `resamplePath(path, targetCount)`:
   - Takes array of `{x, y}` points and integer targetCount (default 64).
   - Returns a new array of `targetCount` evenly spaced points along the path using linear interpolation.
   - Handle edge cases: empty array returns [], single point returns array of targetCount copies of that point.
   - Compute cumulative arc lengths, then for each sample index k, find the position at `(k / (targetCount - 1)) * totalLength` along the path.

2. `discreteFrechetDistance(P, Q)`:
   - O(mn) dynamic programming discrete Frechet distance.
   - P and Q are arrays of `{x, y}`.
   - Returns a float (the max-min distance between corresponding point pairs).
   - Use `Float32Array(m * n)` for the memoization table, initialized to -1.
   - Use `Math.hypot(a.x - b.x, a.y - b.y)` for Euclidean distance.
   - If either array is empty, return Infinity.

- `letterId`: English identifier (e.g., "alif", "ba", "ta", etc.)

- `nameArabic`: Arabic name of the letter (e.g., "ألف")
- `nameEnglish`: English name (e.g., "Alif")
- `referencePath`: Array of `{x, y}` objects normalized to 0-1 unit square representing the canonical stroke direction for the isolated form. Each path should have 20-60 points.

The 28 letters in order: ا ب ت ث ج ح خ د ذ ر ز س ش ص ض ط ظ ع غ ف ق ك ل م ن ه و ي

Reference path guidelines (isolated forms only — per REQUIREMENTS.md Out of Scope, positional forms deferred to v12.0):

- **Tha (ث)**: Same body as Ba but three dots. Path: same baseline curve. ~30 points.
- **Jim (ج)**: Hook shape — right to left curve ending in a downward hook. ~40 points.

- **Kha (خ)**: Similar to Ha with dot above. ~35 points.
- **Dal (د)**: Short stroke — right diagonal then curve. ~20 points.
