3. **Generate choices on blank change**: useEffect triggered by `battle.currentBlankIndex`. Get the current blank from `battle.blanks[battle.currentBlankIndex]`. Call `getPoetryChoices(blank.wordId, blank.correctWord, blank.cefrLevel)` and dispatch `setChoices(choices)`.

4. **Render poem lines**: Map over `poem.lines`. For each line, render the text with blanks replaced by either:
   - A `<span className={styles.blank}>___</span>` if not yet answered
   - A `<span className={styles.blankFilled}>answered word</span>` if answered (green border if correct, red if wrong)
   - Highlight the CURRENT blank with a subtle gold glow.

5. **Render 4 choice buttons**: Below the poem, show a 2x2 grid of `battle.choices`. Each button shows the Arabic word. On click:
   - Determine if correct: `choice.isCorrect`
   - Dispatch `submitPlayerAnswer({ blankIndex: battle.currentBlankIndex, wordId: choice.wordId, isCorrect: choice.isCorrect })`
   - Brief visual feedback (green flash for correct, red for wrong)
   - After 600ms delay, dispatch `advanceBlank()`
   - If that was the last blank (status becomes 'scoring'), trigger scoring phase.

6. **Scoring phase** (when `battle.status === 'scoring'`):
   - Generate NPC answers: `const npcAnswers = generateNpcAnswers(battle.blanks, npcAccuracy)`. npcAccuracy comes from the NPC poet data (default 0.7).
   - Dispatch `setNpcAnswers(npcAnswers)`.
   - Calculate scores: `const { playerScore, npcScore, won } = calculatePoetryScore(battle.playerAnswers, npcAnswers)`.
   - Show results panel: "You: X/N" vs "Poet: Y/N", with winner banner.
   - If won: dispatch `gainXP({ amount: 50, source: 'poetry_battle' })`. For each correctly answered blank, dispatch `addFsrsCard` for that word if not already in FSRS (check `state.vocabulary.fsrsCards[wordId]`).
   - Dispatch `endPoetryBattle({ won, playerScore, npcScore })`.
   - Show "Close" button that emits `EventBus.emit(EVENTS.POETRY_BATTLE_END)` and dispatches to clear battle.

7. **CRITICAL: No timer anywhere** (POET-04). No countdown component, no time.setTimeout for auto-advance, no "time's up" logic. The player advances at their own pace by clicking choices.

8. **Score display**: Show running scores at top — "Your score: X" and "Poet's score: will be revealed" during play. After scoring, show both final scores.

Actually, the correct pattern: read state BEFORE calling next(action), because endPoetryBattle nulls activeBattle:

```javascript
export const poetryRewardsMiddleware = (storeAPI) => (next) => (action) => {
  if (action.type === 'poetry/endPoetryBattle' && action.payload.won) {
    // Read battle state BEFORE reducer nulls it
    const preState = storeAPI.getState();
    const battle = preState.poetry?.activeBattle;
    const fsrsCards = preState.vocabulary?.fsrsCards || {};

    const result = next(action);

    // XP reward
    storeAPI.dispatch(gainXP({ amount: 50, source: 'poetry_battle' }));

    // FSRS rewards for correctly answered words
    if (battle?.playerAnswers) {
      battle.playerAnswers.forEach((answer) => {
        if (answer?.isCorrect && answer.wordId && !fsrsCards[answer.wordId]) {
          storeAPI.dispatch(addFsrsCard({ wordId: answer.wordId }));
        }
      });
    }

    // Victory sound
    EventBus.emit(EVENTS.SFX_QUEST);

    return result;
  }

  return next(action);
};
```
