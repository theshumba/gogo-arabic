# Phase 79 — Lore Codex (NAR-04)

## Requirement
NAR-04: 300+ discoverable lore entries across 10 categories with discovery tracking and codex overlay UI.

## Deliverables

### Data
- `src/data/loreEntriesBatch1.js` — 150 entries (history, culture, language, geography, religion)
- `src/data/loreEntriesBatch2.js` — 150 entries (science, art, trade, warfare, mythology)
- `src/data/loreEntries.js` — Orchestrator combining both batches with lookup helpers

### Redux
- `src/store/slices/loreSlice.js` — Discovery tracking, read/unread state, selectors
- `src/store/middleware/loreMiddleware.js` — Auto-discovers entries on game events (quest complete, zone visit, NPC talk, word learn, faction tier, level up, battle win)

### UI Components
- `src/components/Lore/LoreCodex.jsx` + `.module.css` — Full overlay with category tabs, search, progress tracking
- `src/components/Lore/LoreEntryCard.jsx` + `.module.css` — Individual entry card with rarity border, Arabic/English content, key term display

### Tests
- `src/store/slices/__tests__/loreSlice.test.js` — Reducer + selector tests
- `src/store/middleware/__tests__/loreMiddleware.test.js` — Trigger matching tests
