# Plan 62-02: Skill Tree Gating for B1/B2 Grammar

## Objective

Add skill tree gating to grammar lessons: B1 lessons require Grammar tree level 3 (3+ unlocked nodes), B2 requires level 5 (5+ nodes). Update GrammarModule to show gating reason on locked lessons. Update unlockNextLesson to respect CEFR gates. Add a "New content added" toast for existing players.

## Tasks

<task id="62-02-01" type="auto">
<name>Add CEFR gating to selectLessonsByCategory + update unlockNextLesson</name>

<read_first>
- src/store/slices/grammarSlice.js (selectLessonsByCategory, unlockNextLesson)
- src/store/slices/skillTreeSlice.js (selectUnlockedNodesForTree)
- src/data/grammar.js (cefrLevel field on lessons)
</read_first>

<action>
**Part A: Add CEFR gate constants**

At top of `grammarSlice.js`, add:
```javascript
// Skill tree node count required to access each CEFR level's grammar lessons
const CEFR_GRAMMAR_GATES = {
  'A1': 0,  // always accessible
  'A2': 0,  // always accessible
  'B1': 3,  // Grammar tree level 3 (3+ unlocked nodes)
  'B2': 5,  // Grammar tree level 5 (5+ unlocked nodes)
};
```

**Part B: Update selectLessonsByCategory**

The selector currently takes `(completedLessons, lessonScores, unlockedLessons)`. It needs to also take the Grammar skill tree unlocked node count. Update:

1. Add a new input selector:
```javascript
(state) => state.skillTree?.unlockedNodes?.grammar?.length ?? 0
```

2. In the result function, add a 4th param `grammarTreeLevel`. For each lesson, compute:
```javascript
const cefrGate = CEFR_GRAMMAR_GATES[lesson.cefrLevel] ?? 0;
const cefrUnlocked = grammarTreeLevel >= cefrGate;
```

3. Annotate each lesson object with:
```javascript
{
  ...lesson,
  isCompleted: completedLessons.includes(lesson.id),
  isUnlocked: unlockedLessons.includes(lesson.id) && cefrUnlocked,
  isCefrLocked: !cefrUnlocked,
  cefrGateLevel: cefrGate,
  currentTreeLevel: grammarTreeLevel,
}
```

**Part C: Update unlockNextLesson**

Currently finds the next lesson by order and unlocks it unconditionally. It should skip lessons whose CEFR level the player can't access. Since `unlockNextLesson` is a reducer (no access to skillTree state), this requires a different approach:

Option: Keep unlockNextLesson as-is (it still adds to unlockedLessons array), but the UI gating via `isCefrLocked` in selectLessonsByCategory prevents access. The lesson is "unlocked" in state but visually locked by CEFR gate. This is the simplest approach and matches how the UI already works (isUnlocked && cefrUnlocked).

No change to unlockNextLesson needed — the CEFR gate is enforced at the selector level.

**Part D: Export CEFR_GRAMMAR_GATES for tests**
```javascript
export { CEFR_GRAMMAR_GATES };
```

**Part B: "New content added" toast for existing players**

Add a useEffect in GrammarModule that checks if the grammar lesson count has increased since the player last visited. Use a simple localStorage key:

```javascript
useEffect(() => {
  const GRAMMAR_COUNT_KEY = 'gogo_grammar_lesson_count';
  const storedCount = parseInt(localStorage.getItem(GRAMMAR_COUNT_KEY) || '0', 10);
  const currentCount = grammarLessons.length;

  if (storedCount > 0 && currentCount > storedCount) {
    // Show toast — use existing toast/notification pattern if available,
    // otherwise a simple 3-second overlay
    setNewContentToast(`${currentCount - storedCount} new grammar lessons added!`);
    setTimeout(() => setNewContentToast(null), 4000);
  }

  localStorage.setItem(GRAMMAR_COUNT_KEY, String(currentCount));
}, []);
```

Add the toast state and render:
```javascript
const [newContentToast, setNewContentToast] = useState(null);
```

Render the toast at the top of the body:
```javascript
{newContentToast && (
  <motion.div
    initial={{ opacity: 0, y: -20 }}
    animate={{ opacity: 1, y: 0 }}
    exit={{ opacity: 0 }}
    style={{
      background: COLORS.xpGold,
      color: COLORS.brown,
      fontFamily: FONTS.pixel,
      fontSize: '12px',
      padding: '12px 24px',
      textAlign: 'center',
      marginBottom: '20px',
      border: `3px solid ${COLORS.brown}`,
    }}
  >
    {newContentToast}
  </motion.div>
)}
```
