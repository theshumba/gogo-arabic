    Create `.github/workflows/bundle-size.yml`. Structure per RESEARCH "CI bundle-size gate" example, adapted with these specifics:

    - Trigger: `pull_request` to `main`. Do not trigger on push to PR branches alone (that double-runs).
    - Node version: 22 (matches CI default per RESEARCH "Environment Availability").
    - Install ffmpeg via apt: `sudo apt-get update && sudo apt-get install -y ffmpeg` BEFORE the build step (because the build may invoke `npm run pipe:encode-audio` transitively; even if it doesn't, the install is cheap insurance and matches the rest of Phase 104's CI assumptions).
    - Build head branch: `npm ci && npm run build:stats` → `cp dist/bundle-stats.json head-stats.json`
    - Checkout base branch in a subdirectory: `actions/checkout@v4` with `ref: ${{ github.base_ref }}` and `path: base`.
    - Build base branch: `cd base && npm ci && npm run build:stats` → `cp dist/bundle-stats.json ../base-stats.json`. NOTE: If the base branch is an older commit without `npm run build:stats`, fall back to `CI=true npm run build && cp dist/bundle-stats.json ../base-stats.json` or skip the base build with a clear comment in the workflow (action will skip the diff if base is missing).
    - Run the action with the inputs from RESEARCH.
    - Enforcement step (CRITICAL — the action does NOT enforce, we do):
      ```yaml
      - name: Enforce size budget
        run: |
          node -e "
          const head = require('./head-stats.json');
          const base = require('./base-stats.json');
          // visualizer raw-data shape: tree of nodes with .gzipSize
          // For total: sum top-level gzip sizes across all chunks
          const sumGzip = (data) => {
            // adapt to the actual visualizer raw-data schema; the visualizer emits an object with .tree or .nodes
            if (Array.isArray(data?.nodeParts)) return Object.values(data.nodeParts).reduce((s, n) => s + (n.gzipLength || 0), 0);
            if (data?.tree?.children) return data.tree.children.reduce((s, c) => s + (c.gzipSize || 0), 0);
            return 0;
          };
          const hSize = sumGzip(head);
          const bSize = sumGzip(base);
          if (!bSize) { console.log('Base has no stats; skipping enforcement.'); process.exit(0); }
          const delta = (hSize - bSize) / bSize;
          console.log('Head:', hSize, 'Base:', bSize, 'Delta:', (delta * 100).toFixed(2), '%');
          if (delta > 0.15) { console.error('FAIL: bundle grew >15%'); process.exit(1); }
          if (delta > 0.05) { console.warn('WARN: bundle grew >5%'); }
          "
      ```

    NOTE for executor: the visualizer raw-data schema has changed across versions. Read the actual `dist/bundle-stats.json` produced by Task 1 locally to confirm the right path to total gzip size. Adjust the `sumGzip` function in the enforcement step accordingly. Keep it defensive (returns 0 on shape mismatch) so a schema drift downgrades to "skip enforcement" rather than false-fail.
