<objective>
Generate the `content/zone-manifest.json` that declares per-zone asset bundles. This file is the contract Plan 06's `ZoneLoader` reads to decide which atlases to load on zone entry and which adjacent zones to pre-fetch.

Purpose: Per RESEARCH "Don't Hand-Roll" — adjacency is derived from existing `zones.js exits[].targetZone` (zones.js lines 211/485/735/1019/1232/1464/1730/2015 already define exits for all 8 zones). No hand-maintained dict, no drift risk. Atlas-pack membership is derived from KENMI_CATALOG's path structure (`/assets/kenmi/<pack>/...`). The manifest is generated, never hand-edited.

Output: A small JSON file (~5 KB) covering every zone in zones.js. Plan 06 reads it at runtime; Plan 09 verifies its schema in CI.
</objective>
