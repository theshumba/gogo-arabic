<objective>
Wire the real atlas packer for all 969 Kenmi sprites, producing the multi-page atlases that downstream PLAN-03 will load via `this.load.multiatlas(...)`.

Purpose: This is the single biggest determinism-sensitive step in the phase. PIPE-01 (deterministic packing) and PIPE-02 (multi-page atlases) are both delivered here. The verifier from Plan 01 is the safety net; this script is the actual production packer.

Output: A reproducible packer that emits ~10 pack atlases (base, desert, ..., volcano) plus a `kenmi-shared` atlas (player + UI assets always loaded by BootScene). Plan 03 consumes these.

Determinism strategy (all three levers from RESEARCH Pattern 1):
1. Sort input filenames alphabetically before passing to `packAsync`.
2. Set `allowRotation:false, allowTrim:false, detectIdentical:true`.
3. Attach `hash` (SHA256 of file contents) to each input image.
</objective>

       - Call `packAsync(images, { textureName: `kenmi-${packName}`, ...PACK_OPTS })` with the pinned options object frozen at top of file.
       - Sort the `result` array alphabetically by `name` before writing (deterministic file order).
       - Write each result file to `OUTPUT_DIR` via `fs.writeFile`.
       - Print: `kenmi-${packName}: ${imageCount} sprites → ${pageCount} pages`.

       - `await mkdir(OUTPUT_DIR, { recursive: true })`.

       - Print summary line: `Done. Packed N atlases across M PNG pages.`
       - Export `packAll` and `PACK_NAMES` as named exports so the test file can call them.

    5. **CLI entrypoint:**
       - At bottom: `if (import.meta.url === `file://${process.argv[1]}`) { await packAll(); }`.
