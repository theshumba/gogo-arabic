<objective>
Wire per-zone lazy loading + release-on-exit + adjacent pre-fetch. This delivers PIPE-05 — the runtime payoff for everything Plans 02-05 built.

Purpose: BootScene now loads only the shared atlas (Plan 03). On zone entry, ZoneLoader pulls in the zone's atlases (from `content/zone-manifest.json`); on zone exit, it releases atlases no longer needed (LRU cap = 3 zones in memory); on entry, it also prefetches adjacent zones to eliminate pop-in (RESEARCH Pitfall 4).

Output: A clean lifecycle module + integration into existing ZoneTransition (which already has a `loadZoneAssets` call from Phase 38). The existing `loadZoneAssets` function in `zoneAssetManifests.js` is preserved as a deprecated alias so any non-ZoneTransition callers (e.g., tests) don't break.

Critical sequencing (RESEARCH Pitfall 4): fade-out → load new → fade-in → release old. Releasing BEFORE new textures load causes mid-transition flicker.

Critical LRU cap (RESEARCH Pitfall 5): track at most 3 zones with loaded atlases. Without this cap, rapid traversal grows memory monotonically.
</objective>

    ```
    // src/game/systems/ZoneLoader.js
    import manifest from '../../../content/zone-manifest.json';

    const LRU_CAP = 3;
    const loadedAtlases = new Set(['kenmi-shared']);  // BootScene already loaded shared
    const zoneLru = [];  // recently-loaded zones, most-recent at front

    export async function loadZoneBundle(scene, zoneId) {
      const bundle = manifest[zoneId];
      if (!bundle) return;
      const toLoad = bundle.atlases.filter(a => !loadedAtlases.has(a));
      if (toLoad.length === 0) {
        // promote zoneId to front of LRU even if no new loads
        const existing = zoneLru.indexOf(zoneId);
        if (existing >= 0) zoneLru.splice(existing, 1);
        zoneLru.unshift(zoneId);
        return;
      }
      await new Promise((resolve) => {
        toLoad.forEach((atlasKey) => {
          scene.load.multiatlas(atlasKey, `/assets/atlases/${atlasKey}.json`);
        });
        scene.load.once('complete', resolve);
        scene.load.start();
      });
      toLoad.forEach(a => loadedAtlases.add(a));
      // Promote zoneId to LRU front
      const existing = zoneLru.indexOf(zoneId);
      if (existing >= 0) zoneLru.splice(existing, 1);
      zoneLru.unshift(zoneId);
      // Evict beyond cap
      while (zoneLru.length > LRU_CAP) {
        const evicted = zoneLru.pop();
        releaseZoneBundle(scene, evicted);
      }
    }

    export function releaseZoneBundle(scene, zoneId) {
      const bundle = manifest[zoneId];
      if (!bundle) return;
      for (const atlasKey of bundle.atlases) {
        if (atlasKey === 'kenmi-shared') continue;
        if (!loadedAtlases.has(atlasKey)) continue;
        const stillNeeded = zoneLru.some(z => manifest[z]?.atlases?.includes(atlasKey));
        if (stillNeeded) continue;
        if (scene.textures.exists(atlasKey)) {
          scene.textures.remove(atlasKey);
        }
        loadedAtlases.delete(atlasKey);
      }
    }

    export function prefetchAdjacent(scene, zoneId) {
      const bundle = manifest[zoneId];
      if (!bundle) return;
      for (const adj of bundle.adjacent) {
        loadZoneBundle(scene, adj).catch(() => { /* fire-and-forget */ });
      }
    }

    // Test-only resets (NOT exported in production usage; available via direct file import in tests)
    export function _resetForTest() {
      loadedAtlases.clear();
      loadedAtlases.add('kenmi-shared');
      zoneLru.length = 0;
    }
    ```

    Note for executor: The pseudocode above is illustrative — write clean code, do not paste comments like "RESEARCH says..." into production. Keep the file under 100 lines.

    Edge cases:
    - Manifest missing for a zoneId: bail silently (logged at warn level).
    - `scene.textures.exists(key)` is false when removing: skip.
    - Concurrent `loadZoneBundle` calls for the same zone (rapid transitions): the second call's `toLoad` is empty, returns immediately. The shared `loadedAtlases` set + LRU array are not thread-safe but JS is single-threaded — safe enough.
