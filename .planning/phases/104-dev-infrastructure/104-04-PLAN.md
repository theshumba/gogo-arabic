<objective>
Build the audio compression half of the asset pipeline. PIPE-03 demands two outputs (OGG primary + MP3 fallback) with a 30%-win threshold and preserved perceptual fidelity (OGG q≥5).

Purpose: Reduce audio payload for the lazy-loading per-zone strategy in Plan 06 without bloating the build with re-encoded files that don't actually shrink. Deterministic ffmpeg invocations (`-bitexact`) keep the audio outputs reproducible for the Plan 09 CI determinism gate.

Output: A reusable encoder script + content-addressed cache. The current audio inventory per RESEARCH is 25 MB across 33 MP3 + 19 OGG files; many of those MP3s should shrink going to OGG q5, and many OGGs will be no-ops (skipped). The summary table makes the policy auditable.
</objective>

<interfaces>
ffmpeg invocation pattern (RESEARCH Pattern 2):
```bash
ffmpeg -y -bitexact \
  -i <src.{wav,mp3,ogg}> \
  -c:a libvorbis -qscale:a 5 \
  -map_metadata -1 \
  <out.ogg>

ffmpeg -y -bitexact \
  -i <src> \
  -c:a libmp3lame -qscale:a 4 \
  -map_metadata -1 \
  <out.mp3>
```

Cache structure:
```
.cache/audio-encode/
  <sha256-of-source>.ogg
  <sha256-of-source>.mp3
```

Output mirror structure:

public/assets/audio/bgm/oasis.mp3      → dist/assets/audio/bgm/oasis.ogg + dist/assets/audio/bgm/oasis.mp3
                                          (or, if <30% win on ogg, keep dist/assets/audio/bgm/oasis.mp3 as the original byte-for-byte)
```

    Create `scripts/encode-audio.mjs` (ESM) per RESEARCH.md Pattern 2:

    1. **Imports + constants:**
       - `node:fs/promises`, `node:path`, `node:crypto`, `node:child_process` (`spawnSync`).
       - `const SRC_DIR = path.join(projectRoot, 'public/assets/audio')`.
       - `const OUT_DIR = path.join(projectRoot, 'dist/assets/audio')`.
       - `const CACHE_DIR = path.join(projectRoot, '.cache/audio-encode')`.
       - `const MIN_SIZE_WIN = 0.30`.
       - `const RECOMMENDED_FFMPEG = '6 or 7'` (printed at start; not enforced).

    2. **walkAudio(dir): async generator** that yields every `*.{wav,mp3,ogg,m4a,flac}` file under SRC_DIR, sorted alphabetically (for deterministic ordering of console output).

    3. **encodeOne(srcAbsPath): async function** that:
       - Reads source bytes, computes SHA256.
       - Computes relative path under SRC_DIR (e.g., `bgm/oasis.mp3`).
       - Output base: `path.join(OUT_DIR, relPathWithoutExt)` (e.g., `dist/assets/audio/bgm/oasis`).
       - Ensures parent dir exists.
       - **OGG path:** cache hit at `.cache/audio-encode/<hash>.ogg` → copy. Else spawn `ffmpeg -y -bitexact -i <src> -c:a libvorbis -qscale:a 5 -map_metadata -1 <cacheFile>` then copy from cache.
       - **MP3 path:** same shape with `-c:a libmp3lame -qscale:a 4`.
       - **30% threshold check:** stat the source and the emitted OGG. If `(srcSize - oggSize) / srcSize < MIN_SIZE_WIN`, then:
         - Delete the emitted OGG.
         - Copy the source file (byte-for-byte) to `<outBase>.<originalExt>` (preserving original extension).
         - Return decision `kept-original`.
       - Else return decision `replaced-with-ogg`.
       - Always emit MP3 fallback unless source is already MP3 (then copy source as the MP3 byte-for-byte to avoid quality loss from re-encoding lossy→lossy unless OGG won >30%).
       - Return `{ srcPath, origSize, oggSize, winRatio, decision }`.

    4. **encodeAll() async function:**
       - `await mkdir(OUT_DIR, { recursive: true }); await mkdir(CACHE_DIR, { recursive: true });`
       - Print ffmpeg version (`ffmpeg -version | head -1`) and the recommended pin.
       - Walk SRC_DIR, collect all sources sorted, await encodeOne for each.
       - Print summary table: `${relPath.padEnd(50)} ${origKB.toString().padStart(6)}KB → ${oggKB.toString().padStart(6)}KB (${(winRatio*100).toFixed(1).padStart(5)}%) — ${decision}`.

    5. **Injectable spawnFn for testability:** Top of file:

       export function createEncoder({ spawnFn = spawnSync } = {}) {
         // ... encodeOne uses spawnFn instead of imported spawnSync
       }
       ```
       Export both `encodeAll` (uses default) AND `createEncoder` (test-injectable). The test in Task 2 uses `createEncoder({ spawnFn: vi.fn() })`.

    6. **CLI entrypoint:**
       - `if (import.meta.url === \`file://${process.argv[1]}\`) { await encodeAll(); }`

| T-104-08 | Tampering | Audio determinism regression (ffmpeg version drift) | mitigate | `-bitexact -map_metadata -1` flags pinned; CI YAML pins ffmpeg version in Plan 09; script prints local ffmpeg version + recommended pin at start |

</threat_model>
