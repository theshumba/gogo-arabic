       - For `grep` gates: run command, capture stdout, assert empty (or whatever pass condition is documented).

    2. **Gate list** (mirror the interfaces table above; explicit map of req → check):

         { id: 'PIPE-01', label: 'Atlas determinism', kind: 'cmd',

           command: 'npx vitest run scripts/__tests__/encode-audio.test.mjs' },
         { id: 'PIPE-04-fresh', label: 'Zone manifest freshness (no uncommitted drift)', kind: 'cmd',
           command: 'node scripts/generate-zone-manifest.mjs && git diff --exit-code content/zone-manifest.json' },
         { id: 'PIPE-04-tests', label: 'Zone manifest tests', kind: 'cmd',
           command: 'npx vitest run scripts/__tests__/generate-zone-manifest.test.mjs' },

       - Iterate gates in order.
       - Print `[RUNNING] <id> — <label>`.
