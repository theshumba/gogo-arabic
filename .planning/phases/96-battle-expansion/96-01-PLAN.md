# Phase 96 — Battle System Expansion: Linguistic Arts Combat

## Goal

Expand the battle system with 30 new human opponents, 8 zone-specific boss encounters, and a comprehensive "Linguistic Arts" ability system that reframes the existing 50-spell "Root Magic" system as combat techniques derived from Arabic language mastery (eloquence, translation, vocabulary, grammar, proverbs, calligraphy). All enemies are human scholars, merchants, guards, and competitors—NO beasts, monsters, or supernatural creature visuals.

## Design Philosophy

**Linguistic Combat Over Magical Combat:**
- Replace "spellcasting" framing with "ability usage"
- Abilities power from real Arabic skills: vocabulary mastery, translation speed, grammar completion, idiom knowledge
- Boss encounters test specific Arabic skill areas (conjugation, pluralization, root recognition, etc.)
- No supernatural abilities; all combat represents verbal/intellectual contests

**Human-Only Enemies:**
- Rival scholars (test grammar and vocabulary)
- Desert bandits (opportunistic fighters)
- Merchant competitors (haggle/trade vocabulary)
- Palace guards (formal/military language)
- Traveling debaters (rhetorical skills)
- Dock workers (nautical terminology)
- Mountain hermits (philosophical language)
- Oasis elders (wisdom and proverbs)

### 2. Linguistic Abilities System
**File:** `src/data/linguisticAbilities.js`

15-20 combat abilities based on Arabic language mastery (replacing pure "spell" framing).

**Data Structure:**
```javascript
{
  id: 'eloquent_response',
  name: 'Eloquent Response',
  nameArabic: 'الرد البليغ',
  description: 'Channel vocabulary mastery into a powerful counterargument',
  descriptionArabic: 'استخدم إتقانك للكلمات في رد قوي',
  
  // Determines unlock trigger
  unlockedBy: {
    type: 'vocabulary_milestone',
    value: 500,                  // Unlock at 500 words learned
  },
  
  // Ability stats
  targetType: 'single',          // single, all_enemies, self
  baseDamage: 30,
  mpCost: 12,                    // Cost in MP (or "linguistic focus points")
  accuracy: 0.90,
  critChance: 0.25,
  
  // Powered by specific skill
  poweredBy: 'vocabulary_mastery', // vocabulary_mastery, translation_speed, grammar_completion, idiom_knowledge, calligraphy_practice
  
  // Scales with player progress
  scalingFormula: 'baseDamage * (vocabularyMastered / 100)',
  
  // Category for combo/synergy
  category: 'offense',           // offense, defense, utility, healing
  
  // Linguistic theme
  linguisticTheme: 'critical_insight',  // Using perfect word choice for maximum impact
  
  // Special mechanics
  statusEffect: null,
  comboBonus: { type: 'vocabulary_chain', multiplier: 1.5 },  // Bonus if previous ability used vocab chain
}
```

**Proposed 18 Abilities:**

**Offensive (7):**
1. `eloquent_response` — Critical hit via vocabulary mastery (30 dmg, 12 mp)
2. `proverb_strike` — Area damage via idioms learned (45 dmg, 20 mp, all enemies)
3. `grammar_strike` — Single target via grammar mastery (28 dmg, 10 mp)
4. `root_revelation` — Exploit enemy root weakness (35 dmg, 15 mp, single)
5. `tongue_lash` — Verbal assault via eloquence (25 dmg, 8 mp, single)
6. `linguistic_barrage` — Multiple quick strikes (20 dmg x 3, 18 mp, single)
7. `scholarly_refute` — Counter argument (32 dmg, 14 mp, single)

**Defensive (4):**
1. `grammar_shield` — Defense buff via grammar completion (reduce 40% damage, 10 mp, 3 turns)
2. `translation_dodge` — Evasion via translation speed (dodge next attack, 8 mp, 1 turn)
3. `calligraphy_focus` — Accuracy boost (increase crit chance 25%, 10 mp, 3 turns)
4. `eloquent_deflection` — Reduce all damage (30% reduction, 12 mp, 2 turns)

**Utility/Healing (4):**
1. `vocabulary_recovery` — Restore MP (restore 20 mp, 0 cost, 1 use per battle)
2. `proverb_wisdom` — Restore HP (restore 25 hp, 15 mp)
3. `translation_insight` — Debuff enemy (confuse opponent, reduce accuracy 20%, 12 mp, 2 turns)
4. `linguistic_focus` — Buff self (increase damage 25%, 10 mp, 2 turns)

**Ability Unlock Progression:**
- `eloquent_response` — Starting ability (can be chosen at level 1)
- `grammar_shield` — At 100 words mastered
- `translation_dodge` — At 250 words mastered
- `proverb_strike` — At 500 words mastered (and 50 idioms learned)
- `calligraphy_focus` — At 200 writing completions
- `scholarly_refute` — At 100 grammar completions
- Higher-tier abilities unlock at level 15+, 25+, 35+, etc.

### 4. Linguistic Combat State Slice
**File:** `src/store/slices/linguisticCombatSlice.js`

Redux slice tracking linguistic ability unlocks, usage, and upgrades.

**State Shape:**
```javascript
{
  // Discovered linguistic abilities
  unlockedAbilities: {
    'eloquent_response': {
      id: 'eloquent_response',
      unlockedAt: 1704067200000,  // Timestamp
      usageCount: 45,
      level: 2,                    // Ability can be leveled (1-5)
      upgrades: ['crit_boost', 'mp_reduction'],  // Purchased upgrades
    },
    // ... more abilities
  },
  
  // Ability hotbar (4-6 slots)
  equippedAbilities: [
    { abilityId: 'eloquent_response', slot: 0 },
    { abilityId: 'grammar_shield', slot: 1 },
    null,  // Empty slot
    null,
  ],
  
  // Active ability upgrades
  purchasedUpgrades: {
    'eloquent_response_crit_boost': { cost: 100, damageBoost: 0.15 },
    // ...
  },
  
  // Statistics
  statistics: {
    totalAbilitiesUsed: 320,
    mostUsedAbility: 'eloquent_response',
    bossesDefeatedWithAbility: { 'eloquent_response': 3 },
  },
}
```

**Reducers:**
- `unlockAbility(state, action)` — Unlock ability (checked against milestone)
- `equipAbility(state, action)` — Add ability to hotbar
- `unequipAbility(state, action)` — Remove from hotbar
- `recordAbilityUse(state, action)` — Track usage + XP
- `levelUpAbility(state, action)` — Advance ability level
- `purchaseAbilityUpgrade(state, action)` — Buy upgrade (costs in-game currency/points)
- `resetAbilityStats(state)` — Reset statistics

**Selectors:**
- `selectUnlockedAbilities(state)` — Get all unlocked abilities
- `selectEquippedAbilities(state)` — Get current hotbar
- `selectAbilityLevel(state, abilityId)` — Get ability level
- `selectAbilityStats(state, abilityId)` — Get usage stats

## Design Constraints

1. **Linguistic Framing Only:**
   - All abilities describe language skills: "Eloquent Response," "Grammar Shield," "Translation Dodge"
   - No magical or supernatural terminology
   - Flavor text connects to real Arabic learning

2. **Human Opponents Only:**
   - All 30 opponents are humans with professions/roles
   - No beasts, monsters, or supernatural creatures as visual enemies
   - Creatures can be mentioned in dialogue/backstory, never as enemies

3. **No File Modifications:**
   - Create only NEW files
   - Do not modify existing battle/magic slices
   - Do not edit spellData.js or rootMagic.js
   - These will coexist; legacy magic system preserved for backwards compatibility

4. **Test Coverage:**
   - 100% of data files tested (validation + edge cases)
   - 100% of slice reducers and selectors tested
   - All test files must pass before merge

5. **Vocabulary Teaching:**
   - Each opponent teaches 2-4 Arabic words
   - Each boss teaches 5+ words
   - Words must be real, commonly useful vocabulary
