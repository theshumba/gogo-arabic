  <action>
Create NEW file `src/game/systems/EconomyFlow.js`:

A system that tracks per-zone resource availability based on shop production chains. It should:

1. Import `SHOP_PRODUCTION` from shops.js
2. Import `ZONES` from zones.js to map shops to zones
3. Maintain a `resourcePool` object: `{ [zoneName]: { [resourceName]: quantity } }`

Key methods:
- `constructor()` — initialize resource pools for all zones with base amounts
- `tick(gameDays)` — called periodically (e.g., once per game day). For each shop:
  - Check if inputs are available in the zone's resource pool
  - If yes, consume inputs and produce outputs at the shop's rate
  - If no, production stalls (resource shortage)
- `getResourceAvailability(zone, resource)` — returns quantity available
- `addResources(zone, resources)` — manually add resources (from player actions, quests, etc.)
- `consumeResources(zone, resources)` — consume resources (for purchases, crafting, etc.)

Start each zone with 10 of each input resource so the economy has initial flow.

This is a standalone system — not wired to Redux yet. It'll be a singleton managed by WorldScene or a game manager. For now, just create the class with clean methods.

Export as named export: `export class EconomyFlow { ... }`
