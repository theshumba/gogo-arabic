# Plan 68-01: Component Tests for Quiz Final 3 Types

## Context

Phase 68's 3 quiz types (DialectIdentify, RootExpand, CulturalContext) were implemented in a prior session. Components are fully built and integrated into useQuiz.js, QuizOverlay, and QUIZ_TYPE_REGISTRY (minLevel:8, cefrMin:B2). The only remaining work is component tests.

## Pattern Reference

Follow GrammarFill.test.jsx pattern:
1. Mock useFormatArabic to return identity function
2. Create mock word/options/feedback data matching component props
3. Test: renders question/prompt and N choice buttons
4. Test: calls onAnswer with correct value on click
5. Test: shows green highlight on correct feedback
6. Test: shows red highlight on wrong feedback
7. Test: disables all buttons when feedback is present

## Test Plan

### DialectIdentify.test.jsx (5 tests)
- Renders phrase, transliteration, meaning, and 4 dialect choice buttons
- Calls onAnswer(dialectValue) when a choice is clicked
- Shows choiceCorrect class on correct answer with feedback
- Shows choiceWrong class on wrong selected choice with feedback
- Disables all buttons and shows explanation when feedback present

### RootExpand.test.jsx (7 tests)
- Renders root display, meaning, hint with correct count, and 6 word option buttons
- Toggle selection: clicking a button adds/removes from selected set (aria-pressed)
- Submit button sends JSON array of selected values via onAnswer
- Submit button disabled when 0 selected
- Shows choiceCorrect/choiceWrong/choiceMissed classes after feedback
- Resets selection when word changes (useEffect on word.id)
- Disables all buttons and hides submit when feedback present

### CulturalContext.test.jsx (5 tests)
- Renders expression, transliteration, and 4 context choice buttons
- Calls onAnswer(contextValue) when a choice is clicked
- Shows choiceCorrect class on correct answer with feedback
- Shows choiceWrong class on wrong selected choice with feedback
- Disables all buttons and shows explanation when feedback present
