**Step 3: Adapt _createAnims for Kenmi layout**

The current `_createAnims` assumes 4x4 grid (row 0=down, row 1=left, row 2=right, row 3=up) with 4 frames per direction.

When `_useKenmi` is true, create a separate method `_createKenmiAnims(scene, textureKey, prefix)` that uses the Kenmi 12-col layout:
- Walk down: frames [0, 1, 2] (row 0, first 3 cols)
- Walk up: frames [12, 13, 14] (row 1, first 3 cols)
- Walk left: frames [24, 25, 26] (row 2, first 3 cols)
- Walk right: frames [36, 37, 38] (row 3, first 3 cols)

```js
_createKenmiAnims(scene, textureKey, prefix) {
  const dirs = [
    { key: `${prefix}-walk-down`, frames: [0, 1, 2] },
    { key: `${prefix}-walk-up`, frames: [12, 13, 14] },
    { key: `${prefix}-walk-left`, frames: [24, 25, 26] },
    { key: `${prefix}-walk-right`, frames: [36, 37, 38] },
  ];

  dirs.forEach(({ key, frames }) => {
    if (!scene.anims.exists(key)) {
      scene.anims.create({
        key,
        frames: scene.anims.generateFrameNumbers(textureKey, { frames }),
        frameRate: 8,
        repeat: -1,
      });
    }
  });

  // Idle: first frame of each direction's walk row
  const idleDirs = [
    { key: `${prefix}-idle-down`, frame: 0 },
    { key: `${prefix}-idle-up`, frame: 12 },
    { key: `${prefix}-idle-left`, frame: 24 },
    { key: `${prefix}-idle-right`, frame: 36 },
  ];

  idleDirs.forEach(({ key, frame }) => {
    if (!scene.anims.exists(key)) {
      scene.anims.create({
        key,
        frames: [{ key: textureKey, frame }],
        frameRate: 1,
      });
    }
  });
}
```

In the constructor, call `_createKenmiAnims` instead of `_createAnims` when `_useKenmi`:
```js
if (this._useKenmi) {
  this._createKenmiAnims(scene, PLAYER_KENMI_KEY, 'body');
} else {
  this._createAnims(scene, this.bodyKey, 'body');
}
```
