# Phase 81: Daily Challenge System (DAILY-01 + DAILY-02)

## Objective
Add a daily challenge system with 4 rotating challenge types, streak tracking, and reward tiers to drive player retention.

## Design Decisions
- **Deterministic date hashing** (djb2 variant): all players get the same daily challenge. Hash `dateString + salt` to pick items from arrays.
- **4 challenge types rotate daily**: word_of_the_day, grammar_challenge, speed_quiz, cultural_trivia
- **Streak logic**: completing today extends streak if `lastCompletedDate` was yesterday; breaks if gap > 1 day
- **History capped at 30 entries**: oldest entries shifted off when cap exceeded
- **Default export** for overlay component (lazy loading compatible)
- **CSS Modules + dark theme**: #1a1a2e background, #FFD700 gold accents, consistent with codebase
- **No existing files modified**: all new files, integration left as a wiring step

## Challenge Types
| Type | Key | Base XP | Mini-game |
|------|-----|---------|-----------|
| Word of the Day | `word_of_the_day` | 50 | Show word, then 3 exercises (match meaning, match Arabic, recall) |
| Grammar Challenge | `grammar_challenge` | 75 | 5 grammar fill-in-the-blank with 2-minute countdown |
| Speed Quiz | `speed_quiz` | 60 | 10 Arabic>English vocab questions, 8s per question, speed scoring |
| Cultural Trivia | `cultural_trivia` | 40 | 5 multiple-choice questions from lore entries |

## XP Calculation
- Base XP from challenge type
- Streak multiplier: +5% per streak day, capped at +150% (30 days)
- Accuracy bonus: XP scaled by 50% + (score * 50%)
- Speed quiz: partial credit for slow but correct answers (100/75/50/25 points based on response time)

## Overlay States
1. **Preview**: Challenge type info, streak display, next reward progress bar, Start button
2. **Active**: Routes to challenge-specific mini-game component
3. **Complete**: Score card (score %, time, XP), streak update, unclaimed rewards, Done button
