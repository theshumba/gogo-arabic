  <action>
Create `StatsPanel.jsx` — a collapsible panel that displays secondary stats moved from HUD:

**Component behavior:**
- Collapsed by default (`useState(false)`)
- Toggle button labeled "Stats" with arrow indicator (collapsed: right-pointing triangle `>`, expanded: down-pointing triangle `v`)
- When expanded, shows: Words Learned count, Dirhams count, Streak count, SyncIndicator
- Smooth CSS transition using max-height (0 -> 200px)
- Proper accessibility: `aria-expanded` on toggle button, `aria-hidden` on panel content, `aria-controls` linking button to panel
- `pointer-events: none` on hidden panel content to prevent tab-through

**Redux data:** Import `selectPlayerStats` from playerSlice.js. Destructure `{ wordsLearned, dirhams, streak }`.

**Rendering structure:**
```jsx
<div className={styles.container}>
  <button className={styles.toggleBtn} onClick={toggle} aria-expanded={isOpen} aria-controls="stats-panel" aria-label={isOpen ? 'Hide stats' : 'Show stats'}>
    <span className={styles.toggleArrow}>{isOpen ? 'v' : '>'}</span> Stats
  </button>
  <div id="stats-panel" className={`${styles.panel} ${isOpen ? styles.panelOpen : ''}`} aria-hidden={!isOpen}>
    <div className={styles.stat}>
      <span className={styles.statLabel}>Words:</span>
      <span className={styles.statValue}>{wordsLearned}</span>
    </div>
    <div className={styles.stat}>
      <span className={styles.statLabel}>Dirhams:</span>
      <span className={styles.statValue}>{dirhams} D</span>
    </div>
    <div className={styles.stat}>
      <span className={styles.statLabel}>Streak:</span>
      <span className={styles.statValue}>{streak} days</span>
    </div>
    <SyncIndicator />
  </div>
</div>
```

**CSS (StatsPanel.module.css):**
- Import variables.css
- `.container`: position relative, pointer-events auto
- `.toggleBtn`: pixel font (var(--font-pixel)), 10px font-size, padding 4px 8px, background var(--color-gray), color var(--color-white), border 2px solid var(--color-dark), cursor pointer, pointer-events auto. Same button style as HUD buttons (box-shadow pattern). Add `:focus-visible` with `outline: var(--focus-ring)`.
- `.toggleArrow`: display inline-block, width 10px, font-size 8px, transition transform 0.2s
- `.panel`: position absolute, top 100%, right 0, background rgba(43,41,44,0.95), border 2px solid var(--color-light), padding 0, min-width 160px, max-height 0, overflow hidden, transition max-height 0.3s ease-out + padding 0.3s ease-out, margin-top 4px, z-index 1 (internal)
- `.panelOpen`: max-height 200px, padding 8px
- `.stat`: display flex, justify-content space-between, font-family var(--font-pixel), font-size 10px, color var(--color-white), margin-bottom 6px
- `.statLabel`: color var(--color-light)
- `.statValue`: color var(--color-xp-gold), font-weight bold
- `.panel:not(.panelOpen) *`: pointer-events none (prevent tab into hidden content)

**Mobile responsive (480px):**
- `.toggleBtn`: min-height 44px, min-width 44px (WCAG touch target)
- `.stat`: font-size 8px

**Wrap component with React.memo** for performance (parent HUD re-renders frequently).
