
    2. Create `eslint.config.js` in project root using ESM (the project has `"type": "module"` in package.json):
       - Import @eslint/js, globals, eslint-plugin-react, eslint-plugin-react-hooks, eslint-config-prettier
       - Export default array of config objects
       - First entry: js.configs.recommended
       - Second entry: files `['**/*.{js,jsx}']` with:
         - languageOptions: ecmaVersion 2024, sourceType 'module', globals (browser + es2021), parserOptions with jsx: true
         - plugins: react, react-hooks
         - rules: spread reactPlugin.configs.recommended.rules, spread reactPlugin.configs['jsx-runtime'].rules (React 19 automatic JSX), spread reactHooks.configs.recommended.rules, then override 'react/prop-types': 'off' (no PropTypes in this project), 'no-unused-vars': ['warn', { argsIgnorePattern: '^_' }]
         - settings: react.version: 'detect'
       - Third entry: server-specific config for files `['server/**/*.js']` with node globals
       - Fourth entry (LAST): prettier config (eslint-config-prettier to disable conflicting rules)
       - Add ignores for: node_modules, dist, coverage, build, public

    3. Create `.prettierrc` (JSON):
       ```json
       {
         "semi": true,
         "singleQuote": true,
         "trailingComma": "es5",
         "tabWidth": 2,
         "printWidth": 100,
         "arrowParens": "(always)"
       }
       ```
       NOTE: Use `"arrowParens": "always"` (not the parenthesized form above — that's the value string "always").

    4. Create `.prettierignore`:
       ```
       node_modules/
       dist/
       build/
       coverage/
       *.min.js
       package-lock.json
       ```

    5. Add npm scripts to package.json (insert after "test:e2e" script):
       ```json
       "lint": "eslint .",
       "lint:fix": "eslint . --fix",
       "format": "prettier --write \"src/**/*.{js,jsx,json,css}\" \"server/**/*.{js,json}\"",
       "format:check": "prettier --check \"src/**/*.{js,jsx,json,css}\" \"server/**/*.{js,json}\""
       ```

    IMPORTANT: Do NOT run `npm run format` to auto-format the entire codebase — that would create massive diffs. Just install and configure. The scripts should work when invoked manually.
