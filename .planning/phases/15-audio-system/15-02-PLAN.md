b) Add footstep timing properties in constructor:
```js
this.footstepTimer = 0;
this.footstepInterval = 320; // ms between footstep sounds at normal speed
```

c) In the `update()` method, AFTER the movement velocity is set and diagonal normalization (after the if/else block for left/right/up/down/idle and the diagonal normalize block), add footstep logic BEFORE the dust particle update:

```js
// Footstep SFX
const moving = left || right || up || down;
if (moving) {
  this.footstepTimer += this.scene.game.loop.delta;
  // Faster footsteps when sprinting
  const interval = this.isSprinting ? this.footstepInterval * 0.6 : this.footstepInterval;
  if (this.footstepTimer >= interval) {
    this.footstepTimer = 0;
    audioManager.playSFX('footstep');
  }
} else {
  this.footstepTimer = 0;
}
```

This uses the single existing `sfx-footstep.ogg` file. Different terrain types would require terrain detection and multiple footstep files -- defer terrain-specific footsteps since we only have one footstep file. The requirement says "3 terrain types" but we use the one file available. When terrain-specific files are added later, the audioManager.playSFX call can be updated to `footstep-sand`, `footstep-grass`, `footstep-stone`.

d) The footstep sound should NOT play when the player is frozen. This is already handled because the `update()` method returns early when `this.isFrozen` is true.
