**2. Enhance `src/services/audio.js`** — add BGM system alongside existing ambient system:

The existing audioManager already has `ambient` (zone ambience), `sfx`, and `pronunciation` channels. Add a NEW `bgm` channel for background music that is separate from ambient. The key changes:

a) Add `masterVolume` property (0-1, default 0.7). All channel volumes are scaled by masterVolume before applying to Howl instances. The effective volume formula is: `channelVolume * masterVolume`.

b) Add `bgm` property (Howl|null) and `bgmTrack` (string|null) for dedup. Add `bgmVolume` property (0-1, default 0.7).

c) Add `setMasterVolume(vol)` method (accepts 0-100, converts to 0-1). When master changes, immediately update all playing Howl volumes:
   - `this.ambient?.volume(this.ambientVolume * this.masterVolume)`
   - `this.bgm?.volume(this.bgmVolume * this.masterVolume)`
   - (SFX and pronunciation apply master at play time, not retroactively)

d) Add `setBgmVolume(vol)` method (accepts 0-100, converts to 0-1). If bgm is playing, update its volume immediately.

e) Add `playBGM(trackName)` method:
   - If `this.bgmTrack === trackName && this.bgm?.playing()` return (dedup)
   - Fade out current BGM over 800ms (longer crossfade for music vs 500ms for ambient)
   - Create new Howl: `src: ['/assets/audio/bgm/bgm-${trackName}.mp3']`, `loop: true`, `volume: 0`
   - On load: play and fade in over 800ms to `this.bgmVolume * this.masterVolume`
   - On loaderror: silently skip (placeholder files may not exist yet), set bgm = null

f) Add `stopBGM()` method: fade out over 800ms then unload.

g) Add `pauseBGM()` method: if bgm playing, fade to 0 over 300ms then pause. Store `this.bgmWasPaused = true`.

h) Add `resumeBGM()` method: if bgmWasPaused, resume and fade in over 300ms.

i) Update `setSfxVolume` to store as `this.sfxVolume` — apply `sfxVolume * masterVolume` in `playSFX()`.

j) Update `playSFX(name)` to use `this.sfxVolume * this.masterVolume` when setting volume.

k) Update `playWord(wordId)` and `playLetter(letter)` to use `this.pronunciationVolume * this.masterVolume`.

l) Update `cleanup()` to also unload bgm.

m) Add `isMuted` property (boolean, default false). Add `mute()` and `unmute()` methods that use Howler.mute(true/false) for global mute. Add `toggleMute()` convenience method.

IMPORTANT: Keep the existing `playAmbient()` / `stopAmbient()` methods working exactly as they do now (ambient is separate from BGM). Ambient is for environmental sounds, BGM is for music. They layer together.
