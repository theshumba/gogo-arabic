# Phase 93 — Analytics Dashboard Expansion

## Goal
Expand the analytics system to give players deep insights into their Arabic learning progress with comprehensive dashboards, study calendars, goal setting, and exportable reports.

## New Files

### Service Layer
- `src/services/learningAnalytics.js` — Pure functions for computing learning insights (vocab mastery, struggling words, study time, learning velocity, quiz performance, grammar mastery, recommendations, CEFR time estimation, study reports)

### State Management
- `src/store/slices/extendedAnalyticsSlice.js` — Redux slice for study sessions, weekly/monthly reports, learning goals, and goal progress tracking

### Components
- `src/components/Analytics/ExpandedAnalyticsDashboard.jsx` + `.module.css` — Comprehensive tabbed dashboard (Overview, Vocabulary, Skills, Activity, Reports)
- `src/components/Analytics/StudyCalendar.jsx` + `.module.css` — GitHub-style contribution calendar showing daily study intensity
- `src/components/Analytics/GoalSetting.jsx` + `.module.css` — Personal learning goal configuration with progress rings

### Tests
- `src/services/__tests__/learningAnalytics.test.js` — All pure functions, edge cases, empty state handling
- `src/store/slices/__tests__/extendedAnalyticsSlice.test.js` — All reducers, selectors, goal tracking
- `src/components/Analytics/__tests__/ExpandedAnalyticsDashboard.test.jsx` — Tab rendering, data display
- `src/components/Analytics/__tests__/StudyCalendar.test.jsx` — Calendar grid rendering, intensity calculation

## Dependencies
- recharts v3.8.0 (already installed)
- Existing: analyticsSlice, cefrProgressSlice, statsSlice, vocabularySlice, grammarSlice, readingSlice, writingSlice, conversationSlice, miniGameSlice

## Design
- Dark theme: #1a1a2e background, #FFD700 gold accents
- Chart palette: gold #FFD700, green #4ade80, blue #4A90D9, red #f03131, orange #f8a060
- CSS Modules for all components
- Responsive (mobile-friendly)
- Arabic labels on charts where relevant

## Constraints
- Create ONLY new files — no edits to existing files
- Default exports for components (lazy loading)
- Encouraging goal system, not punitive
- Reports exportable as formatted text (clipboard)
