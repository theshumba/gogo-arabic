Reducers (9 total):
- `recruitCompanion(state, { payload: companionId })` — Set companions[companionId].recruited = true, increment recruitedCount. Skip if already recruited or id not found.
- `setActiveCompanion(state, { payload: { slot, companionId } })` — Validate slot is 'battle' or 'exploration', companion is recruited. Set activeParty[slot] = companionId. If same companion is already in the OTHER slot, clear that slot (a companion can only fill one slot at a time).
- `removeActiveCompanion(state, { payload: slot })` — Set activeParty[slot] = null.
- `giveGift(state, { payload: { companionId, giftId, relationshipGain } })` — Increase relationship by relationshipGain (clamped 0-100), push giftId to giftsReceived, set lastGiftTimestamp to payload.timestamp, increase mood by 10 (clamped 0-100).
- `updateRelationship(state, { payload: { companionId, amount } })` — Add amount to relationship, clamp 0-100.
- `setCompanionMood(state, { payload: { companionId, mood } })` — Set mood, clamp 0-100.
- `recordDialogueLine(state, { payload: { companionId, lineId, timestamp } })` — Push to dialogueHistory, keep last 50 entries.
- `updateCompanionLevel(state, { payload: { companionId, level } })` — Set level (min 1).
- `clearBattleCompanionState(state)` — Reset all companion battleStats to zero. Called on new game or reset.

Selectors (6 total):
- `selectAllCompanions(state)` — state.companions.companions
- `selectCompanion(companionId)` — returns function (state) => state.companions.companions[companionId]
- `selectActiveParty(state)` — state.companions.activeParty
- `selectRecruitedCompanions(state)` — createSelector: filter companions where recruited === true
- `selectCompanionRelationship(companionId)` — returns function (state) => state.companions.companions[companionId]?.relationship ?? 0
- `selectCompanionsByZone(zone)` — returns function that filters by zone assignment from COMPANIONS data

Do NOT use Date.now() in reducers — pass timestamps via action payloads.
