- If companion is unrecruited → show recruitment hint (where to find them, requirement)
- If companion is recruited → show detail view with:
  - Full stats (HP, MP, damage, defense)
  - Teaching specialty description
  - Battle role description
  - Relationship bar
  - "Set as Battle Companion" / "Set as Exploration Companion" buttons
  - "Give Gift" button (opens gift selection from inventory)
  - Recent dialogue history

Gift giving flow:
1. Player clicks "Give Gift" on companion detail
2. Show items from inventory that are in GIFT_CATEGORIES
3. Player selects item → dispatch `giveGift({ companionId, giftId, relationshipGain })` with gain from `getGiftBonus()`
4. Dispatch `removeItem({ itemId, quantity: 1 })` from inventorySlice
5. Show relationship increase animation on RelationshipBar
6. Emit COMPANION_GIFT_GIVEN event

Use Framer Motion for:
- Overlay slide-in (from right, like InventoryUI)
- Card hover effects (scale 1.02)
- Relationship bar fill animation (spring transition)
- Gift giving sparkle effect (layout animation)

Styling: Use inline styles or CSS modules matching existing UI patterns. Pixel font ("Press Start 2P") for headings, system font for body text. Dark overlay (#1a1a2e background) with companion's primary color as accent.

2. Add EventBus listeners for companion battle events:
```javascript
useEffect(() => {
  const handleCompanionTurnStart = ({ companionId }) => {
    setIsCompanionTurn(true);
    setMenuOpen(false);     // Close player menu during companion turn
    setInputDisabled(true); // Disable all player inputs
  };

  const handleCompanionAction = ({ companionId, action }) => {
    setCompanionAction(action);
  };

  const handleCompanionTurnEnd = () => {
    setIsCompanionTurn(false);
    setCompanionAction(null);
  };

  EventBus.on(EVENTS.COMPANION_BATTLE_TURN_START, handleCompanionTurnStart);
  EventBus.on(EVENTS.COMPANION_BATTLE_ACTION, handleCompanionAction);
  EventBus.on(EVENTS.COMPANION_BATTLE_TURN_END, handleCompanionTurnEnd);

  return () => {
    EventBus.off(EVENTS.COMPANION_BATTLE_TURN_START, handleCompanionTurnStart);
    EventBus.off(EVENTS.COMPANION_BATTLE_ACTION, handleCompanionAction);
    EventBus.off(EVENTS.COMPANION_BATTLE_TURN_END, handleCompanionTurnEnd);
  };
}, []);
```
