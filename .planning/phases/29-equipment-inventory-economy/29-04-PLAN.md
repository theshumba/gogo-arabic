**HagglingGame.jsx** — Arabic numeral negotiation mini-game:

Props: `{ itemPrice, itemName, itemNameArabic, shopkeeperId, onSuccess(finalPrice), onCancel }`

State:
- `offerInput` — raw string the player types (can be mixed ٠-٩ and 0-9)
- `offerValue` — normalized integer value
- `attempts` — number of attempts made (max 3)
- `feedback` — { message, messageArabic, type: 'too_low'|'too_high'|'insulting'|'deal'|'neutral' }
- `shopkeeperMood` — 'neutral' | 'thinking' | 'pleased' | 'offended' (affects visual)

Constants:
```javascript
const MAX_ATTEMPTS = 3;
const MIN_DISCOUNT = 0.10; // 10% off minimum
const MAX_DISCOUNT = 0.30; // 30% off maximum
```

Haggling logic:
```javascript
const MIN_PRICE = Math.floor(itemPrice * (1 - MAX_DISCOUNT)); // Best possible price
const SWEET_SPOT = Math.floor(itemPrice * (1 - MIN_DISCOUNT)); // Easy acceptance
const MERCHANT_TARGET = Math.floor(itemPrice * 0.85); // 15% discount target

function evaluateOffer(offer) {
  if (offer <= 0 || offer > itemPrice * 2) {
    return { type: 'insulting', message: "That's insulting!", messageArabic: 'أنت تمزح؟', mood: 'offended' };
  }
  if (offer < MIN_PRICE) {
    return { type: 'too_low', message: 'Way too low!', messageArabic: 'أقل بكثير!', mood: 'offended' };
  }
  if (offer < MERCHANT_TARGET) {
    return { type: 'too_low', message: 'Still too low...', messageArabic: 'لا يزال منخفض...', mood: 'thinking' };
  }
  if (offer <= SWEET_SPOT) {
    return { type: 'deal', message: 'Deal!', messageArabic: 'اتفقنا!', mood: 'pleased' };
  }
  if (offer <= itemPrice) {
    return { type: 'deal', message: 'Gladly!', messageArabic: 'بكل سرور!', mood: 'pleased' };
  }
  return { type: 'too_high', message: "That's more than I asked!", messageArabic: 'هذا أكثر مما طلبت!', mood: 'pleased' };
}
```

Input handling:
- Use `normalizeArabicNumber(offerInput)` from arabicNumbers.js to normalize input

After 3 failed attempts:
- Show "Out of attempts!" message

On successful haggle:

Feedback language:

- Arabic in larger font, English in smaller font below
- Use Arabic cultural phrases for shopkeeper responses

- Focus auto-moves to input on mount
- Escape key cancels haggling
