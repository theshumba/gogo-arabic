**InventoryUI.jsx** — Main inventory overlay component:

Structure: Full-screen overlay with left panel (equipment slots) and right panel (inventory grid).

Props: None (reads from Redux).

State:
- `selectedItem` — currently selected item for tooltip/equip
- `sortBy` — 'type' | 'rarity' | 'arabic' (default 'type')
- `filterRarity` — null | 'common' | 'uncommon' | 'rare' | 'epic' | 'legendary'
- `tooltip` — { itemId, position, isEquipped } for tooltip display

Redux connections:
- `useSelector(selectInventoryItems)` — inventory grid items
- `useSelector(selectEquippedItems)` — equipment slots
- `useSelector(selectAffixesUnlocked)` — learned affixes
- `useSelector(state => state.player.level)` — for level requirements
- `useSelector(state => state.vocabulary)` — for affix bonus calculations
- `useDispatch` — for equipItem, unequipItem, sortInventory

Layout (use CSS Grid):
```
┌─────────────────────────────────────────────────┐
│ Inventory (حقيبة)           [Sort▼] [Filter▼] X │
├──────────────┬──────────────────────────────────┤
│              │                                  │
│  Equipment   │     Inventory Grid (5 cols)      │
│  Slots (8)   │     [item] [item] [item] ...     │
│              │     [item] [item] [item] ...     │
│  [head]      │     ...scrollable...             │
│  [robe]      │                                  │
│  [cloak]     │                                  │
│  [belt]      │     [Sort: Type | Rarity | أبجد]  │
│  [boots]     │     [Filter: All | Common | ...]  │
│  [gloves]    │                                  │
│  [acc1]      │                                  │
│  [acc2]      │                                  │
│              │                                  │
│  Set Bonuses │                                  │
│  [active]    │                                  │
├──────────────┴──────────────────────────────────┤
│  Item count: 42/200                             │
└─────────────────────────────────────────────────┘
```

Behaviors:
1. **Sort controls:** Three buttons — Type (by equipment slot), Rarity (legendary first), Arabic (hijā'ī alphabetical by nameArabic). Dispatch `sortInventory` to Redux.
2. **Filter controls:** Rarity filter buttons with Arabic color names: أبيض/أخضر/أزرق/بنفسجي/ذهبي. "All" button to clear filter.
3. **Item grid:** Each item shows icon placeholder (colored border by rarity), short name, quantity badge. Click to select → show tooltip.
4. **Equip flow:** Click item in grid → ItemTooltip shows "Equip" button → click Equip → dispatch `equipItem({ slot, itemId })`. If slot already occupied, auto-unequip old item first (dispatch `unequipItem` then `equipItem`). Emit `EVENTS.EQUIPMENT_CHANGED` via EventBus after equip.
5. **Unequip flow:** Click equipped item in slot → ItemTooltip shows "Unequip" button → dispatch `unequipItem({ slot })`. Emit `EVENTS.EQUIPMENT_CHANGED`.
6. **Set bonus display:** Below equipment slots, show active set bonuses (e.g., "Scholar's Set 2/4: +20 MP"). Use `getSetBonus()` from itemSets.js.
7. **Item count:** Show "42/200" at bottom. Flash warning when > 180.

Accessibility (INTG-05):
- Wrap in `useFocusTrap(true)` (from existing hook)
- Add `role="dialog"`, `aria-label="Inventory"`, `aria-modal="true"` to overlay
- Each item in grid: `role="button"`, `aria-label="{item.name} - {item.rarity}"`, `tabIndex={0}`
- Equipment slots: `aria-label="{slotName}: {equippedItemName || 'Empty'}"
- Keyboard: Enter/Space to select item, Escape to close overlay

Use Framer Motion for entrance/exit animation (match ShopOverlay pattern). Check `prefers-reduced-motion` and reduce animation duration to 0.15s if active.

**ItemTooltip.jsx** — Stat comparison and lore tooltip:

Props: `{ itemId, currentEquippedId, vocabularyState, onEquip, onUnequip, onClose, isEquipped }`

Shows:

3. **Comparison:** If currentEquippedId exists, show diff using `compareItemStats()`:
   - Green "+5 HP" for improvements
   - Red "-3 MP" for downgrades
   - Gray "0" for unchanged
4. **Affixes:** List Arabic adjective affixes with learned/unlearned status:
   - Learned: "حاد (Sharp) — +5% Damage [✓ Learned]"
   - Unlearned: "مبارك (Blessed) — +10 MP [50% — Learn to unlock!]"
5. **Set info:** If item belongs to a set, show set name and progress (e.g., "Scholar's Set 2/4")
6. **Lore:** Item lore text (Arabic + English) in an expandable section
7. **Actions:** "Equip" button (if viewing from grid) or "Unequip" button (if viewing equipped item)

Stat display format: Use colored text (green for positive, red for negative). Show percentage stats as "x1.05" or "+5%".
