**EquipmentManager.js** — Create in `src/game/systems/equipment/`:

```javascript
export class EquipmentManager {
  constructor(scene, playerSprite) { ... }
  updateSprites() { ... }
  update() { ... }
  destroy() { ... }
}
```

Implementation details:
- Constructor: Store scene, playerSprite references. Create empty `equipmentSprites = {}` object. Bind `EVENTS.EQUIPMENT_CHANGED` listener to `updateSprites()`. Call `updateSprites()` once on construction to render current equipment.

- Depth layers constant (render order, lowest = farthest back):
  ```javascript
  const DEPTH_LAYERS = {
    boots: 0, belt: 5, robe: 10, gloves: 15,
    cloak: 20, headCovering: 25, accessory1: 30, accessory2: 35
  };
  ```

- `updateSprites()`:
  1. Read `store.getState().inventory.equipped`
  2. Destroy all existing equipment sprites
  3. For each equipped slot with an itemId:
     - Look up item in EQUIPMENT_DATA to get the asset key pattern: `equipment_${itemId}`
     - Check `this.scene.textures.exists(assetKey)` — if missing, log warning and skip (graceful degradation, not all items need custom sprites yet)
     - Create sprite at playerSprite position with correct depth (playerSprite.depth + DEPTH_LAYERS[slot])
     - If prefers-reduced-motion is active, skip any equipment glow/shimmer tween
  4. Emit `EVENTS.EQUIPMENT_STATS_UPDATED` so battle system recalculates

- `update()`: Sync all equipment sprite positions with playerSprite position and frame (for animation). Only update if playerSprite has moved since last update (optimization).

- `destroy()`: Remove all sprites, unbind EventBus listener. Called in scene shutdown.

**battleRewardsMiddleware.js** — Create Redux middleware that intercepts battle end actions:

```javascript
export const battleRewardsMiddleware = (store) => (next) => (action) => {
  const result = next(action);

  // Intercept battleSlice endBattle action
  if (action.type === 'battle/endBattle') {
    const { victory, rewards } = action.payload;

    if (victory && rewards) {
      const { xp, gold, items } = rewards;

      // Award XP to player
      if (xp > 0) {
        store.dispatch(addXP(xp));
      }

      // Award gold (dirhams)
      if (gold > 0) {
        store.dispatch(earnDirhams(gold));
      }

      // Award items to inventory
      if (items && items.length > 0) {
        items.forEach(itemReward => {
          const inventoryState = store.getState().inventory;
          if (inventoryState.items.length < 200) {
            store.dispatch(addItem({
              itemId: itemReward.itemId,
              quantity: itemReward.quantity || 1,
            }));

            // Check for new affix words to teach
            const item = EQUIPMENT_DATA[itemReward.itemId];
            if (item?.affixes) {
              const vocabState = store.getState().vocabulary;
              item.affixes.forEach(affix => {
                const fsrsCards = vocabState.fsrsCards || {};
                if (!fsrsCards[affix.wordId]) {
                  // Auto-discover affix word → add to FSRS deck
                  store.dispatch(unlockAffix(affix.wordId));
                  // Emit event for UI toast
                  EventBus.emit(EVENTS.AFFIX_DISCOVERED, {
                    wordId: affix.wordId,
                    itemId: itemReward.itemId,
                  });
                }
              });
            }

            EventBus.emit(EVENTS.INVENTORY_ITEM_ADDED, { itemId: itemReward.itemId });
          } else {
            EventBus.emit(EVENTS.INVENTORY_FULL);
          }
        });
      }
    }
  }

  return result;
};
```

Import requirements:

- `EQUIPMENT_DATA` from `equipment.js`
