**inventorySlice.js** — Create with these specifics:

Initial state:
```javascript
{
  equipped: {
    headCovering: null, robe: null, cloak: null, belt: null,
    boots: null, gloves: null, accessory1: null, accessory2: null
  },
  items: [],           // [{ itemId: string, quantity: number, locked: boolean }] — max 200
  affixesUnlocked: [], // wordIds the player has discovered via equipment
}
```

Reducers (9 total):
- `addItem(state, { payload: { itemId, quantity = 1 } })` — add to items array, stack if existing, cap at 200
- `removeItem(state, { payload: { itemId, quantity = 1 } })` — decrease quantity, remove if 0
- `equipItem(state, { payload: { slot, itemId } })` — validate slot exists, set equipped[slot] = itemId, remove from items if stackable
- `unequipItem(state, { payload: { slot } })` — move equipped[slot] item back to items, set slot to null
- `unlockAffix(state, { payload: wordId })` — push to affixesUnlocked if not present
- `sortInventory(state, { payload: { sortBy } })` — sort items by 'type', 'rarity', or 'arabic' (hijā'ī order)
- `lockItem(state, { payload: itemId })` — set locked=true to prevent selling
- `unlockItem(state, { payload: itemId })` — set locked=false
- `clearInventory(state)` — reset to initialState (for testing/reset)

Selectors (6 total):
- `selectEquippedItems` — returns equipped object
- `selectInventoryItems` — returns items array
- `selectAffixesUnlocked` — returns affixesUnlocked array
- `selectInventoryCount` — returns items.length
- `selectIsInventoryFull` — returns items.length >= 200
- `selectEquipmentStats` — createSelector that computes total equipment bonuses from equipped items + vocabulary state (uses calculateTotalEquipmentStats from itemStats.js). Import EQUIPMENT_DATA to look up items.
