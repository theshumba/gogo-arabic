EDIT 2 — Append the Kenmi loader block at the END of the preload() method, just before the closing brace.
Place it after the existing RPG UI KIT section. Add this block:

```js
    // =========================================================
    // KENMI CUTE FANTASY ASSETS — loaded from catalog
    // =========================================================
    // Register error handler once (fires per failed asset)
    this.load.on('loaderror', (file) => {
      console.warn(`[BootScene] Failed to load asset: ${file.key} @ ${file.url}`);
    });

    for (const entry of KENMI_CATALOG) {
      if (entry.type === 'spritesheet') {
        this.load.spritesheet(entry.key, entry.path, {
          frameWidth: entry.frameWidth,
          frameHeight: entry.frameHeight,
        });
      } else {
        this.load.image(entry.key, entry.path);
      }
    }
```

DO NOT remove or modify any of the existing loading calls (tilesets, player sprites,
NPC sprites, object sprites, UI icons, backgrounds, bdragon panels, RPG UI kit).
Those legacy keys are still referenced by v7.0 code — removing them would break gameplay.

DO NOT add a second loaderror handler if one already exists in the file.
