PART A — DialogueEngine.js: Add learningPath condition evaluation.

In evaluateCondition(), after the vocabulary condition block (around line 87) and before the NOT condition block, add:

    // Check learningPath condition
    if (condition.learningPath) {
      const learningPath = state.player?.learningPath;
      if (learningPath !== condition.learningPath) return false;
    }

This allows any dialogue line, choice, or tree to add { learningPath: 'scholar' } to its condition and only show for players on that path.

PART B — dialogueSchema.js: Register learningPath as a valid condition key.

Find the VALID_CONDITION_TYPES array or conditionSchema object in dialogueSchema.js and add 'learningPath' to it. If the file uses a plain JS comment listing valid keys, add a comment entry for learningPath. Do not break the existing validation logic.

PART C — npcStoryArcs.js: Add learningPath-branched description lines to 8 act start arcs.

For each arc_act_N start arc (written in Plan 45-01), add a 4th line to the lines array that branches per learningPath. Use this pattern — add 3 parallel lines, each conditional:

// Line 4a — Scholar framing
{

  english: "...",
  transliteration: "...",

}

// Line 4c — Historian framing
{
  arabic: "...",            // historical/cultural angle
  english: "...",
  transliteration: "...",
  condition: { learningPath: 'historian' }
}

DialogueEngine.getFilteredChoices already calls evaluateCondition on choices — but lines with conditions need the engine to also filter them. Check DialogueEngine for a getFilteredLines or renderLine method. If lines are not currently filtered by condition, add a filterLines() helper following the same pattern as getFilteredChoices():

  filterLines(lines) {
    if (!lines) return [];
    return lines.filter(line => this.evaluateCondition(line.condition));
  }

And call filterLines in any method that iterates lines (check DialogueOverlay or useDialogue hook for where lines are consumed — the filtering may need to happen in the dialogue data prep step rather than the engine itself; consult the existing code flow before deciding where to add it).
