PART A — Add 12 companion quest objects to quests.json.

Quest ids: "companion_quest_{companion_id_without_prefix}" e.g. "companion_quest_amira", "companion_quest_khalid" etc.

For each companion quest:
  - id: "companion_quest_{name}" (e.g. companion_quest_amira)
  - title: English title referencing the companion's specialty (e.g. "Amira's Chronicle" for grammar specialist)
  - titleArabic: Arabic translation
  - description: 1-sentence story description tied to companion's personality and teachingSpecialty
  - descriptionArabic: Arabic translation
  - zone: companion's home zone (from companions.js)
  - type: "companion_quest"
  - target: 1
  - trackEvent: "companion_quest_complete"
  - autoStart: false
  - prerequisites: use zone completion gate quest ids — same gate as side quests for that zone:
      oasis_village → ["words_of_oasis"]
      ancient_library / sacred_library → ["master_of_letters"]
      desert_marketplace / desert_market → ["merchant_master"]
      farmland → ["natures_scholar"]
      bedouin_camp → ["tales_of_desert"]
      mountain_village / mountain_pass → ["mountain_wisdom"]
      coastal_port / coastal_town → ["port_of_knowledge"]
      royal_palace / ancient_ruins → ["master_of_arabic"]
  - npcGiver: companion id (e.g. "companion_amira")
  - reward: { xp: 200, dirhams: 80, relationshipIncrease: 2 }
  - teachWords: array of 3–5 vocabulary ids related to companion's teachingSpecialty:
      grammar specialists (amira, layla, maryam): ["sentence_w1", "verb_w1", "noun_w1"] — use real ids from vocabulary.json if available, otherwise use plausible ids from the "phrases" or "grammar" categories
      vocabulary specialists (khalid, omar, tariq): ["big_1", "small_w19", "good_w20"] — use common A1 vocab ids
      pronunciation specialists (zahra, ali, samir): ["ahlan", "marhaba", "sabah_al_khayr"] — use greeting ids
      culture specialists (hassan, fatima, nadia): ["ustadh", "write_1", "book_w1"] — use culture/education ids
  - objectives: 2–3 narrative-driven objectives specific to the companion. Example for Amira (grammar):
      [{ id: "earn_trust", description: "Earn Amira's trust by completing the Library quest", descriptionArabic: "اكسب ثقة أميرة بإكمال مهمة المكتبة" },
       { id: "grammar_lesson", description: "Complete Amira's grammar lesson on verb conjugation", descriptionArabic: "أكمل درس أميرة في تصريف الأفعال" },
       { id: "chronicle_entry", description: "Dictate a sentence for Amira's chronicle", descriptionArabic: "أملِ جملة لسجل أميرة" }]

PART B — Add personal_quest dialogue tree to each companion's NPC entry in npcs.json.

Find each companion's entry in npcs.json by id (companion_amira, companion_khalid, etc.) and add a new dialogue tree object to its dialogueTrees array:

{
  "id": "personal_quest_{name}",
  "topic": "Personal Quest",
  "topicArabic": "المهمة الشخصية",
  "priority": 2,
  "condition": {
    "quest": { "id": "companion_quest_{name}", "status": "not_started" },
    "storyFlag": { "key": "{zone_completion_flag}", "value": true }
  },
  "lines": [
    { "arabic": "...", "english": "...", "transliteration": "..." },
    { "arabic": "...", "english": "...", "transliteration": "...", "teachWord": "{teachWords[0]}" }
  ],
  "effects": [
    { "type": "quest_start", "questId": "companion_quest_{name}" }
  ]
}

Also add a companion_quest_complete tree:
{
  "id": "personal_quest_{name}_complete",
  "topic": "Quest Complete",
  "topicArabic": "المهمة مكتملة",
  "priority": 1,
  "condition": { "quest": { "id": "companion_quest_{name}", "status": "active" } },
  "lines": [
    { "arabic": "...", "english": "...", "transliteration": "..." }
  ],
  "effects": [
    { "type": "quest_complete", "questId": "companion_quest_{name}" },

    { "type": "teach_word", "wordId": "{teachWords[1]}" },
    { "type": "teach_word", "wordId": "{teachWords[2]}" }
  ]
}

Each dialogue tree should have 2–3 lines with Arabic, English, and transliteration. The opening line should reflect the companion's personality (formal/casual, catchphrase etc. from companions.js).
