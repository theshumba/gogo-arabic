## Special Considerations

### ReadingExercise
- Heavy RTL styling — many `direction: rtl`, `textAlign: right`, Arabic font family declarations
- Passage text has word-level highlight styling for vocabulary integration
- Create shared `.arabicPassage` class pattern

### AlphabetModule
- Letter grid uses CSS Grid with dynamic column count based on viewport
- Stroke animation uses inline `strokeDashoffset` — keep as CSS custom property
- Practice canvas overlay positioning — keep `style={{ position: absolute, top, left }}`

### WordSearch
- Grid cells need dynamic `gridTemplateColumns` based on puzzle size — keep as inline
- Selected/found cell highlighting uses conditional colors — use `.selected`, `.found` classes
- Word list with strikethrough for found words — `.foundWord { text-decoration: line-through; }`

### MiniGamesHub
- Game cards with hover effects — move to CSS `:hover` pseudo-class
- Difficulty badge colors — use `.easy`, `.medium`, `.hard` modifier classes

### ErrorBoundary components
- These are rarely rendered (error states only)
- Simple migration — mostly static panel styling
- Lowest priority but included for completeness
