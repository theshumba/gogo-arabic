# Plan 66-01: CSS Modules Migration — Grammar & Quiz Components

## Context

Grammar (8 files, 139 inline occurrences) and Quiz (16 files, 122 inline occurrences) are the two highest-density areas — together 261 inline style occurrences across 24 components. These components are frequently re-rendered during active learning sessions, so migrating to CSS Modules reduces runtime style recalculation.

## Migration Pattern

For each component:

1. **Read** the component and catalog all `style={{...}}` occurrences
2. **Create** a `.module.css` file with semantic class names
3. **Replace** inline styles with `className={styles.foo}` references
4. **Preserve** any dynamic styles that depend on props/state as either:
   - CSS custom properties (`style={{ '--progress': percent }}` + `width: var(--progress)`)
   - Conditional classNames (`className={condition ? styles.active : styles.inactive}`)
   - Keep minimal inline for truly dynamic values (e.g., `style={{ left: `${x}px` }}`)

### Example transformation:

**Before:**
```jsx
<div style={{
  background: '#1a1a2e',
  borderRadius: '12px',
  padding: '16px',
  border: '1px solid rgba(255,255,255,0.1)'
}}>
```

**After:**
```jsx
<div className={styles.card}>
```
```css
.card {
  background: #1a1a2e;
  border-radius: 12px;
  padding: 16px;
  border: 1px solid rgba(255, 255, 255, 0.1);
}
```
