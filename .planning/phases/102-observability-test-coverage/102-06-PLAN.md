<objective>
Ship the in-game performance overlay (FPS, frame time, draw calls, heap MB). Reachable only via `?perf=1` URL param or in DEV builds — production bundle excludes the module via dynamic import so the file tree-shakes out (per RESEARCH Pitfall 6).

Update rate is 1Hz (one DOM/text write per second), not per-frame. This is the source of the "≤1ms/frame" budget compliance: most frames pay zero cost; one frame per second pays a small amount.

The overlay is independent of PostHog and the telemetry middleware — it's local-only debug instrumentation that does NOT send any data anywhere.

Purpose: Give the developer a real-time view of perf so the low-end-device flag (Plan 07) can be tuned against real numbers AND so Plan 09's regression check has a manual visual sanity check.

Output: Plan 01's PerfOverlay.test.js turns GREEN; `?perf=1` URL flag shows a small green text overlay in the top-left of the Phaser canvas with live numbers.
