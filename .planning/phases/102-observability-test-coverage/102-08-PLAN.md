Create `e2e/golden-path.spec.js`. Single test labelled `'OBS-08 golden path — boot → title → new game → walk zone → NPC → FSRS review → save+reload'`. Use the existing spec patterns from `e2e/quest-completion.spec.js` and `e2e/review-session.spec.js` for selectors and state seeding.

Structure:
1. **Boot:**
   - `await page.goto('/');`
   - `await expect(page).toHaveTitle(/gogo arabic/i);`
   - `await page.waitForSelector('canvas', { state: 'visible', timeout: 10000 });`

2. **Title -> New Game:**
   - Find the New Game button (verify exact selector from MainMenu.jsx during implementation — likely `getByRole('button', { name: /new game|start/i })`).
   - Click it. Wait for character creation / first scene to load.
   - Complete any required character-creation steps using the minimum viable input (e.g., default name, first option each step) — mirror review-session.spec.js's seeding pattern if it bypasses character creation entirely.

3. **Walk one zone (one tile of movement):**
   - `await page.keyboard.press('ArrowDown');` (or whichever key triggers movement per existing fast-travel.spec.js).
   - Wait briefly for the move animation to settle — prefer `await page.waitForFunction(() => window.__PHASER_GAME__?.scene?.getScene('WorldScene')?.player?.hasMoved)` over `waitForTimeout` per Pitfall 8.
   - Assert via Phaser debug hook that player position changed.

4. **Talk to one NPC:**
   - Press E (or whichever interact key — verify from existing specs).
   - Wait for dialogue overlay to appear (`getByRole('dialog')` or specific data-testid from existing dialogue tests).
   - Close dialogue (Escape or specific close button).

5. **Take one FSRS review:**
   - Reuse the seeding pattern from `e2e/review-session.spec.js` to ensure at least one FSRS-due card exists.
   - Navigate to the review overlay (button click or keyboard shortcut).
   - Submit one answer (rating: 3 or "Good"). Mirror existing review-session.spec.js answer-submission selector.
   - Assert the review overlay closes.

6. **Save + reload restores state:**
   - `const saved = await context.storageState({ indexedDB: true });` — captures IndexedDB at this point.
   - `await page.reload();`
   - `await expect(page.locator('canvas')).toBeVisible({ timeout: 10000 });`
   - Assert post-reload state matches pre-reload: e.g., `await page.waitForFunction(() => window.__PHASER_GAME__?.scene?.getScene('WorldScene')?.player?.x !== undefined && /* matches pre-reload position */)`. If precise position is brittle, settle for a coarser assertion like "player exists in WorldScene + XP/level unchanged from Redux state probe".

7. **End-test cleanup:** none needed; Playwright tears down context.

Test attributes:
- `test.use({ retries: 0 });` at top of file (override config default of 1 — fast failure per Pitfall 8).
- `test.describe.configure({ mode: 'serial' });` (single-threaded execution).
- Maximum test duration: 180 seconds (per OBS-08 <3min CI budget). Add explicit `test.setTimeout(180000)` for safety.

Selector strategy: prefer `getByRole`, `getByTestId`, `getByText`. Avoid CSS selectors that are brittle to refactors. When unsure of an exact selector, leave a `TODO` comment AND add a fallback selector that works in current code so the spec runs.
