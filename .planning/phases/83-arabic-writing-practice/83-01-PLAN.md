# Phase 83 — Arabic Writing Practice (WRITE-01 + WRITE-02)

## Overview
Canvas-based Arabic writing practice where players trace Arabic letters and words.
Touch + mouse support, ghost templates, grid-based IoU stroke validation.

## Key Decisions
- **Grid-based IoU** (8x8) for stroke validation: simple, effective, no ML needed
- **Normalized coordinates** (0-1) for all stroke data: scales to any canvas size
- **Quadratic curves** for smooth line rendering between sampled points
- **Pointer events** (not mouse/touch separately) for unified input handling
- **Default exports** on components for lazy loading compatibility
- **calligraphyPaths.json reuse**: stroke data references existing calligraphy paths where available

## Validation Thresholds
- 50%+ IoU = Pass
- 80%+ IoU = Excellent
- Score displayed as percentage to player

## Architecture
- WritingCanvas is a reusable canvas component (no Redux dependency)
- WritingPracticeOverlay wraps WritingCanvas with Redux-connected scoring/navigation
- writingSlice tracks per-letter, per-word, per-phrase best scores and attempt counts
