# Plan 71-02: Grammar Overlay + Quest System Integration Tests

**Phase**: 71 — Integration Testing
**Requirement**: TEST-02, TEST-03
**Goal**: 10+ grammar integration tests + 10+ quest integration tests covering full lifecycle flows through Redux

## Context

### Grammar System
The grammar system spans grammarSlice → learningProgressMiddleware → skillTreeSlice. Existing tests cover the slice in isolation. Integration tests verify the full pipeline:
- Open lesson → complete exercises → finish quiz → XP awarded → skill tree advances → next lesson unlocks → CEFR gates enforced

### Quest System
The quest system spans questSlice → learningProgressMiddleware → playerSlice (XP/dirhams). Existing E2E tests cover the happy path in Playwright. Integration tests verify:
- Initialize quests → track objectives → complete quest → claim reward → XP/dirhams awarded → prerequisites unlock next quest → skill tree XP awarded

## Test Files

- `src/store/__tests__/grammarIntegration.test.js`
- `src/store/__tests__/questIntegration.test.js`

## Grammar Integration Tests (12 tests)

### Group 1: Lesson Lifecycle (4 tests)

**G1: Start lesson sets currentLessonId**
- Dispatch `startLesson('al-definite')`
- Assert: currentLessonId = 'al-definite'

**G2: Complete lesson records scores and marks complete**
- Dispatch: `startLesson('al-definite')` → `completeLesson({ lessonId: 'al-definite', exerciseScore: 85, quizScore: 90 })`
- Assert: completedLessons includes 'al-definite', lessonScores['al-definite'] = { exerciseScore: 85, quizScore: 90, attempts: 1 }

**G3: Completing lesson twice keeps best scores**
- Complete lesson with scores 85/90, then complete again with 70/95
- Assert: exerciseScore = 85 (kept higher), quizScore = 95 (updated), attempts = 2

**G4: clearCurrentLesson resets after navigation**
- Start lesson, then dispatch `clearCurrentLesson()`
- Assert: currentLessonId = null

### Group 2: Lesson Unlocking Chain (3 tests)

**G5: Completing a lesson auto-unlocks the next**
- Store with learningProgressMiddleware wired
- Dispatch: `completeLesson({ lessonId: 'al-definite', exerciseScore: 80, quizScore: 80 })`
- Middleware dispatches `unlockNextLesson({ completedLessonId: 'al-definite' })`
- Assert: unlockedLessons contains the next lesson in sequence (e.g., 'pronouns-personal')

**G6: bulkUnlockLessons unlocks multiple without XP (placement test scenario)**
- Dispatch: `bulkUnlockLessons(['al-definite', 'pronouns-personal', 'verb-present'])`
- Assert: all three in unlockedLessons, but completedLessons is still empty (unlocked ≠ completed)

**G7: Lesson not in unlockedLessons cannot be started (selector gating)**
- Verify `selectIsLessonUnlocked('advanced-b2-lesson')(state)` = false when lesson not in unlockedLessons

### Group 3: Grammar → Skill Tree XP (3 tests)

**G8: Completing lesson awards 40 Grammar skill tree XP via middleware**
- Store with learningProgressMiddleware
- Record initial grammar tree XP
- Dispatch: `completeLesson({ lessonId: 'al-definite', exerciseScore: 80, quizScore: 80 })`
- Assert: grammar skill tree XP increased by 40

**G9: Multiple lesson completions accumulate XP**
- Complete 3 lessons sequentially
- Assert: grammar tree XP = 3 × 40 = 120

**G10: Re-completing a lesson still awards XP (practice value)**
- Complete 'al-definite' twice
- Assert: grammar tree XP = 80 (2 × 40) — middleware fires on every completeLesson dispatch

### Group 4: CEFR Gating (2 tests)

**G11: B1 lessons locked when grammar tree has < 3 unlocked nodes**
- Create state with 2 grammar tree nodes unlocked
- Call `selectLessonsByCategory(state)` and find a B1 lesson
- Assert: lesson.isCefrLocked = true

**G12: B1 lessons unlock when grammar tree reaches 3+ nodes**
- Create state with 3 grammar tree nodes unlocked
- Call `selectLessonsByCategory(state)` and find a B1 lesson
- Assert: lesson.isCefrLocked = false

## Quest Integration Tests (12 tests)

### Group 1: Quest Initialization (3 tests)

**Q1: initializeQuests creates active quests from autoStart entries**
- Dispatch: `initializeQuests([{ id: 'q1', autoStart: true, prerequisites: [] }, { id: 'q2', autoStart: false, prerequisites: ['q1'] }])`
- Assert: quests['q1'].status = 'active', quests['q2'].status = 'locked', activeQuestId = 'q1'

**Q2: initializeQuests preserves previously saved quest data**
- Preload state with quests['q1'] = { status: 'completed', progress: 10, rewardClaimed: true }
- Dispatch: `initializeQuests([{ id: 'q1', autoStart: true }, { id: 'q2', autoStart: false, prerequisites: ['q1'] }])`
- Assert: quests['q1'].status = 'completed' (preserved), quests['q2'] initialized

**Q3: Auto-selects first active quest on init**
- Dispatch init with 3 quests, first is completed, second is active
- Assert: activeQuestId = second quest

### Group 2: Quest Progress Tracking (3 tests)

**Q4: updateQuestProgress increments progress for active quests**
- Init quests, q1 is active with target: 5
- Dispatch: `updateQuestProgress({ questId: 'q1', amount: 3 })`
- Assert: quests['q1'].progress = 3

**Q5: Progress tracking actions update tracking arrays**
- Dispatch sequence: `visitNpc('npc_yusuf')` → `visitZone('desert')` → `completeDialogue('merchant_talk')` → `recordReviewSession({ accuracy: 85, timestamp: Date.now() })`
- Assert: npcsVisited includes 'npc_yusuf', zonesVisited includes 'desert', dialoguesCompleted includes 'merchant_talk', reviewSessionsCompleted.length = 1

**Q6: updateQuestProgress is no-op for locked/completed quests**
- Init quests with q1 locked
- Dispatch: `updateQuestProgress({ questId: 'q1', amount: 5 })`
- Assert: quests['q1'].progress = 0 (unchanged)

### Group 3: Quest Completion Flow (3 tests)

**Q7: completeQuest marks quest completed and auto-selects next active**
- Init 2 quests (q1 active, q2 active)
- Dispatch: `completeQuest('q1')`
- Assert: quests['q1'].status = 'completed', quests['q1'].completedAt is set, activeQuestId = 'q2'

**Q8: Complete quest → checkPrerequisites unlocks dependent quests**
- Init quests: q1 (active), q2 (locked, prerequisites: ['q1'])
- Dispatch: `completeQuest('q1')` → `checkPrerequisites(questDefs)`
- Assert: quests['q2'].status = 'active'

**Q9: Quest with multiple prerequisites only unlocks when ALL are met**
- Init quests: q1 (active), q2 (active), q3 (locked, prerequisites: ['q1', 'q2'])
- Complete only q1, check prerequisites
- Assert: q3 still locked
- Complete q2, check prerequisites
- Assert: q3 now active

### Group 4: Rewards & Cross-Slice Effects (3 tests)

**Q10: claimReward marks reward as claimed**
- Complete q1, then dispatch `claimReward('q1')`
- Assert: quests['q1'].rewardClaimed = true

**Q11: claimReward is no-op if quest not completed or already claimed**
- Try claiming on active quest: no change
- Claim on completed quest: works
- Claim again: no change (idempotent)

**Q12: Quest completion awards Culture skill tree XP via middleware**
- Store with learningProgressMiddleware
- Record initial culture tree XP
- Dispatch: `completeQuest('q1')`
- Assert: culture skill tree XP increased by 30
