# Plan 71-01: Battle System Integration Tests

**Phase**: 71 — Integration Testing
**Requirement**: TEST-01
**Goal**: 15+ integration tests covering the full battle lifecycle: start → player turn → companion turn → enemy turn → spell cast → victory/defeat → reward dispatch

## Context

The battle system is the most complex untested flow in Gogo Arabic. It spans:
- **battleSlice** (Redux state: HP, MP, turns, effects, streaks, multi-target)
- **BattleStateMachine** (Phaser FSM: IDLE → INTRO → PLAYER_TURN → COMPANION_TURN → ENEMY_TURN → VICTORY/DEFEAT)
- **EnemyAI** (action selection by pattern: aggressive/defensive/balanced/adaptive/boss)
- **CompanionBattleAI** (heal/attack/buff decisions)
- **battleRewardsMiddleware** (endBattle → addXP + addDirhams + addItem + unlockAffix)
- **learningProgressMiddleware** (skill tree XP routing)

Existing unit tests cover individual pieces (slice reducers, middleware dispatch, calculateDamage). Integration tests verify the **full flow** through Redux — dispatching sequences of actions and asserting cumulative state.

## Approach

Pure Redux integration tests — no Phaser mocking needed. We test:
1. Action sequences through the real store (with middleware)
2. State transitions matching expected battle flow
3. Cross-slice effects (battle → player XP, battle → inventory, battle → vocabulary FSRS)

## Test File

`src/store/__tests__/battleIntegration.test.js`

## Test Cases (17 tests)

### Group 1: Battle Initialization (3 tests)

**T1: startBattle initializes all combat state**
- Dispatch `startBattle({ bossId: 'boss_sphinx', bossHP: 100, encounterType: 'boss', zone: 'desert' })`
- Assert: activeBattle = 'boss_sphinx', bossHP = 100, playerHP = 100, currentRound = 0, turnCount = 0, battleStartTimestamp is set, encounterType = 'boss', battleZone = 'desert'

**T2: initMultiTargetBattle creates enemy array**
- Dispatch `startBattle(...)` then `initMultiTargetBattle({ enemyParty: [{ enemyId: 'warrior_1', hp: 50, maxHp: 50, row: 'front' }, { enemyId: 'archer_1', hp: 30, maxHp: 30, row: 'back' }] })`
- Assert: enemies.length = 2, enemies[0].row = 'front', enemies[1].row = 'back', all defeated = false

**T3: initCompanionBattle adds companion to battle**
- Dispatch `startBattle(...)` then `initCompanionBattle({ hp: 80, mp: 40 })`
- Assert: companionHP = 80, companionMaxHP = 80, companionMP = 40, companionMaxMP = 40

### Group 2: Player Turn Flow (4 tests)

**T4: Attack sequence — correct answer deals damage and updates streak**
- Start battle (bossHP: 100)
- Dispatch: `setCurrentTurn('player')` → `recordArabicUsed({ word: 'كتاب', accuracy: 1.0 })` → `recordWordUsed('kitaab')` → `dealDamage({ damage: 15, correct: true })` → `updateComboMeter({ amount: 10 })`
- Assert: bossHP = 85, streak = 1, comboMeter = 10, arabicUsedThisBattle.length = 1

**T5: Attack sequence — incorrect answer damages player and resets combo**
- Start battle, set comboMeter to 30
- Dispatch: `recordArabicUsed({ word: 'بيت', accuracy: 0.2 })` → `dealDamage({ damage: 8, correct: false })` → `resetComboMeter()`
- Assert: playerHP = 92, streak = 0, comboMeter = 0

**T6: Magic cast spends MP and deals damage**
- Start battle (playerMP: 50, bossHP: 100)
- Dispatch: `spendMP(15)` → `dealDamage({ damage: 25, correct: true })`
- Assert: playerMP = 35, bossHP = 75

**T7: Defend reduces next enemy damage by 50%**
- Start battle
- Dispatch: `setPlayerDefending(true)` → `dealDamageToPlayer({ damage: 20 })`
- Note: defending flag is set; actual 50% reduction happens in BattleStateMachine. For Redux-level test, verify the flag is set and HP changes.
- Assert: isPlayerDefending = true, playerHP = 80 (raw damage applied — FSM handles reduction)

### Group 3: Companion Turn (2 tests)

**T8: Companion attack deals damage**

- Dispatch: `setCurrentTurn('companion')` → `dealDamage({ damage: 12, correct: true })`
- Assert: bossHP reduced by 12

**T9: Companion heal restores player HP and spends companion MP**

- Dispatch: `healPlayer({ amount: 25 })` → `spendCompanionMP(10)`

### Group 4: Enemy Turn (2 tests)

**T10: Enemy attack reduces player HP**
- Start battle
- Dispatch: `setCurrentTurn('enemy')` → `dealDamageToPlayer({ damage: 18 })`
- Assert: playerHP = 82, currentTurn = 'enemy'

**T11: Enemy heal restores enemy HP**
- Start battle (bossHP: 100), deal 40 damage first
- Dispatch: `healEnemy({ amount: 15 })`
- Assert: bossHP = 75 (100 - 40 + 15)

### Group 5: Status Effects & Buffs (2 tests)

**T12: Status effects tick and expire**
- Start battle
- Dispatch: `applyStatusEffect({ target: 'enemy', effect: { id: 'burn', remainingTurns: 2 } })`
- Assert: enemyEffects.length = 1, remainingTurns = 2
- Dispatch: `tickStatusEffects()`
- Assert: remainingTurns = 1
- Dispatch: `tickStatusEffects()`
- Assert: enemyEffects.length = 0 (expired)

**T13: Consumable buffs apply and clear**
- Start battle
- Dispatch: `applyBuff({ buffId: 'strength_tea', stat: 'damage', value: 5, duration: 3, source: 'crafting' })`
- Assert: activeBuffs.length = 1
- Dispatch: `clearExpiredBuffs()` (none expired yet)
- Assert: activeBuffs.length = 1

### Group 6: Victory & Rewards (3 tests)

**T14: Victory dispatches endBattle and rewards flow through middleware**
- Create store WITH battleRewardsMiddleware wired
- Start battle, deal enough damage to reach bossHP = 0
- Dispatch: `endBattle({ victory: true, accuracy: 0.85, timeElapsed: 45000, rewards: { xp: 200, dirhams: 50 }, bossId: 'boss_sphinx' })`
- Assert: player.xp increased by 200, player.dirhams increased by 50, bossesDefeated includes 'boss_sphinx'

**T15: Defeat gives reduced rewards**
- Start battle, reduce playerHP to 0
- Dispatch: `endBattle({ victory: false, accuracy: 0.4, timeElapsed: 30000, rewards: { xp: 25, dirhams: 0 } })`
- Assert: player.xp increased by 25, player.dirhams unchanged, bossesDefeated does NOT include boss

**T16: resetBattle clears transient state but preserves history**
- Start battle, do some actions, end battle
- Dispatch: `resetBattle()`
- Assert: activeBattle = null, playerHP = 100, bossHP = 0, streak = 0, BUT bossesDefeated and battleHistory preserved

### Group 7: Multi-Target Battle (1 test)

**T17: Multi-target — defeat individual enemies, victory when all down**
- Start battle + initMultiTargetBattle with 2 enemies (hp: 30 each)
- Dispatch: `dealDamageToEnemy({ enemyIndex: 0, damage: 30 })`
- Assert: enemies[0].defeated = true, enemies[1].defeated = false
- Use selectAllEnemiesDefeated → false
- Dispatch: `dealDamageToEnemy({ enemyIndex: 1, damage: 30 })`
- Assert: enemies[1].defeated = true
- Use selectAllEnemiesDefeated → true
