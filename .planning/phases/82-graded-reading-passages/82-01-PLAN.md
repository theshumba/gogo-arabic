# Phase 82: Graded Reading Passages (READ-01 + READ-02)

## Overview
Add 60+ graded Arabic reading passages with comprehension questions across CEFR A1-B2. Each passage includes Arabic text, English translation, vocabulary highlights, and 3-5 comprehension questions (multiple choice + true/false).

## Files Created
1. `src/data/readingPassages.js` — 60 passage objects (15 per CEFR level)
2. `src/store/slices/readingSlice.js` — Redux slice for reading progress tracking
3. `src/components/Reading/ReadingPassageOverlay.jsx` — Full overlay with browse/read/quiz/complete states
4. `src/components/Reading/ReadingPassageOverlay.module.css` — Dark theme CSS Modules styling
5. `src/components/Reading/VocabTooltip.jsx` — Vocabulary tooltip popup component
6. `src/components/Reading/VocabTooltip.module.css` — Tooltip styling
7. `src/data/__tests__/readingPassages.test.js` — Data integrity tests
8. `src/store/slices/__tests__/readingSlice.test.js` — Slice reducer/selector tests
9. `src/components/Reading/__tests__/ReadingPassageOverlay.test.jsx` — Component render tests

## Passage Design
- **A1** (15): Greetings, introductions, daily life, numbers, colors, family. 3-4 sentences, 20-40 words.
- **A2** (15): Shopping, directions, food, describing people, simple stories. 4-5 sentences, 40-60 words.
- **B1** (15): Travel, culture, history, news-style reports. 5-7 sentences, 60-100 words.
- **B2** (15): Poetry, science, philosophy, literary criticism. 6-8 sentences, 80-120 words.

## Topics Covered
daily_life, food, travel, family, shopping, culture, history, nature, education, work, health, sports, technology, religion, art

## Redux State Shape
```js
{
  completedPassages: { [passageId]: { score, completedAt, wordsEncountered } },
  currentPassageId: null,
  readingStats: { totalRead: 0, averageScore: 0, passagesPerLevel: { A1:0, A2:0, B1:0, B2:0 } }
}
```

## Component States
1. **Browse** — filter by CEFR, see completed/scores
2. **Reading** — RTL Arabic text, vocab tooltips, translation toggle
3. **Questions** — one-at-a-time comprehension with immediate feedback
4. **Complete** — score summary, XP earned, words encountered
