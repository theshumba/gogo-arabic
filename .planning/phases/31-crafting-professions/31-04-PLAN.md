      - Locked: Gray card with lock icon, "Level {X}" requirement text, silhouette only

    - Use `useFocusTrap(true, onClose)` for accessibility

    - `.professionTabs`: horizontal flex, each tab with Arabic name + icon
    - `.recipeGrid`: CSS Grid, responsive columns, gap 12px
    - `.recipeCard`: 120×150px card with rounded corners, rarity color border
    - `.locked`: opacity 0.4, grayscale filter

    - Scrollbar styling matching existing overlays
