  <name>Task 1: Create gathering spot data and GatheringSpotManager</name>
  <files>
    src/data/gatheringSpots.js
    src/game/systems/GatheringSpotManager.js
  </files>
  <action>
    **gatheringSpots.js:**
    - Export `GATHERING_SPOTS` object keyed by spotId
    - Define 5-10 gathering spots per zone (use existing zone IDs from zones.js)
    - Each spot: `{ id, zoneId, x, y, resourceId, spriteKey, respawnInterval (ms), gatherType }`
    - Spot types map to resource categories: herb_patch (plants), ore_vein (minerals), water_source (liquids), animal_trace (animal products), papyrus_stand (paper/writing materials)
    - Default respawnInterval: 14400000 (4 hours). Some rare spots: 28800000 (8 hours)
    - Export `getGatheringSpotsForZone(zoneId)` helper
    - Each spot references a resourceId from resources.js — use 3-5 possible resources per spot type (randomized on respawn)

    **GatheringSpotManager.js** — Follow InteractableManager.js pattern exactly:
    - Constructor: `constructor(scene)` — stores scene reference, empty spots array
    - `create(zoneId)`:
      - Load spots from `getGatheringSpotsForZone(zoneId)`
      - Check craftingSlice.gatheringCooldowns for each spot — if still on cooldown, mark as depleted + gray tint
      - Create sprite at `cfg.x * 64 + 32, cfg.y * 64 + 32` (tile-to-pixel like InteractableManager)
      - Set sprite immovable, add physics overlap with player
      - Each spot has state: 'ready' | 'depleted'
    - `onPlayerNearSpot(spotId)`:
      - If depleted, show "depleted" hint text
      - If ready, show interaction hint with Arabic resource name via EventBus OBJECT_INTERACT
      - Listen for SPACE keydown to trigger gathering
    - `gatherResource(spotId)`:
      - Calculate quality via `calculateGatheringQuality()` from craftingLogic.js
      - Dispatch `addResource({ resourceId, quantity: 1, quality })` to craftingSlice
      - Dispatch `recordGatheringCooldown({ spotId, timestamp: Date.now() })`
      - Emit `EVENTS.CRAFTING_RESOURCE_GATHERED` with resourceId and quality
      - Emit `EVENTS.SFX_CORRECT` for gathering sound
      - Set spot state to 'depleted', apply gray tint (0x888888)
      - Schedule respawn via `scene.time.delayedCall(spot.respawnInterval, () => respawnSpot(spotId))`
    - `respawnSpot(spotId)`:
      - Set state to 'ready', clear tint
      - Optionally randomize which resource spawns (from spot's resource pool)
      - Emit `EVENTS.GATHERING_SPOT_READY`
    - `update()`:
      - On scene resume/reload, check all depleted spots against current time
      - If elapsed >= respawnInterval, call respawnSpot
    - `destroy()`:
      - Clean up sprites and event listeners

    IMPORTANT: Use `scene.time.delayedCall()` for respawn scheduling (not `update()` polling). Only check cooldowns in `update()` for scene resume scenarios. Follow InteractableManager's INTERACT_RANGE (128px) for proximity.
  </action>
