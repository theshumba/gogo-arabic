    - Questions drawn from recipe ingredients (plants, herbs used in the potion)
    - Each correct answer: +1 score, green highlight
    - Each incorrect answer: -0.5 penalty, red highlight, shows correct answer
    - Number of questions = number of ingredients in recipe (3-8)
    - Accuracy = max(0, (correct - 0.5 × incorrect) / total_questions)
    - Difficulty by level:

    - Plant descriptions include: اللون (color), الشكل (shape), الاستخدام (use), الرائحة (smell)

    **PatternMatching.jsx** — Geometric pattern reproduction:

      - Level 8-10: 6×6 grid, 5 shape types, 4 seconds study time
    - Visual: Target grid on left (during study), player grid on right (during reproduction)
    - Study countdown timer with Arabic numerals
    - After submission: side-by-side comparison with correct/incorrect cells highlighted
    - Uses CSS Grid for both grids, shape icons from existing sprite set or CSS shapes
