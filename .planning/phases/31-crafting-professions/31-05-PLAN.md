    **CraftingMiniGame.jsx** — Container component that:
    - Props: `{ professionId, recipeId, onComplete, onCancel }`
    - Maps professionId to mini-game component:
      ```
      calligrapher → CalligraphyTracing
      cook → CookingRecipeOrder
      blacksmith → SmithingRhythm
      herbalist → PlantIdentification (Plan 06)
      weaver → PatternMatching (Plan 06)
      builder → DirectionalPlacement (Plan 06)
      ```
    - On mini-game complete callback with `accuracy` (0-1):
      1. Calculate quality via `calculateCraftQuality(accuracy)`
      2. Calculate XP via `calculateXPGain(recipe.xpGain, accuracy)`
      3. Dispatch `craftItem({ recipeId, quality })` to craftingSlice
      4. Dispatch `addProfessionXP({ professionId, xp })` to craftingSlice
      5. Dispatch `removeResource()` for each ingredient consumed
      6. Dispatch `addItem({ itemId: recipe.result.itemId, quantity: recipe.result.quantity })` to inventorySlice
      7. Emit `EVENTS.CRAFTING_ITEM_CRAFTED` with { recipeId, quality, accuracy }
      8. Emit `EVENTS.SFX_CORRECT` or `EVENTS.SFX_LEVELUP` based on quality
      9. Call `onComplete({ quality, accuracy, xpGained })`
    - Show result screen: quality badge (color-coded), XP gained, item icon
    - Difficulty scaling: Pass profession level to mini-game for difficulty adjustment
    - Framer Motion enter/exit animations

    **CalligraphyTracing.jsx** — Canvas-based Arabic letter tracing:
    - Props: `{ recipeId, professionLevel, onComplete }`
    - Selects a target Arabic letter/word from the recipe's enchantment inscription
    - Renders target letter in light gray on Canvas (200px Amiri font)
    - Player draws on canvas with pointer events (mouse + touch)
    - Drawing uses pointer events API: pointerdown, pointermove, pointerup
    - Player's strokes rendered in green (correct direction) or red (wrong)
    - Accuracy calculated by:
      1. Render target letter to hidden canvas (getImageData)
      2. Compare player's drawn pixels to target pixels within tolerance
      3. Score = overlap pixels / target pixels (0-1)
    - Difficulty by level:
      - Level 1-3: Large tolerance (30px), target outline visible, 3 attempts
      - Level 4-7: Medium tolerance (15px), partial outline, 2 attempts
      - Level 8-10: Small tolerance (8px), no outline, 1 attempt
    - Timer: 30 seconds (level 1-3), 20 seconds (4-7), 15 seconds (8-10)
    - On complete: calls onComplete(accuracy)

    **CSS for both:**
    - Mini-game overlay: centered, max-width 500px, dark background, rounded corners
    - Canvas: 400×400px with border, centered
    - Timer bar: horizontal progress bar at top
    - Clear/retry button below canvas

    **CookingRecipeOrder.jsx** — Ingredient sequence mini-game:
    - Props: `{ recipeId, professionLevel, onComplete }`
    - Shows recipe ingredients in Arabic names, shuffled order
    - Player must click/tap ingredients in the CORRECT order (recipe defines sequence)
    - Each correct selection: ingredient moves to "bowl" area with green flash
    - Each incorrect selection: red shake animation, -10% accuracy penalty
    - Accuracy = (correct_first_try_count / total_ingredients) × 100%
    - Difficulty by level:
      - Level 1-3: 3-4 ingredients, Arabic + English labels, unlimited time
      - Level 4-7: 5-6 ingredients, Arabic-only labels, 45s timer
      - Level 8-10: 7-8 ingredients, Arabic-only labels, 30s timer
    - Visual: Ingredient cards on left (shuffled), bowl/pot area on right, recipe name at top
    - Uses Framer Motion for card animations (entrance stagger, selection slide)

    **SmithingRhythm.jsx** — Rhythm counting mini-game:
    - Props: `{ recipeId, professionLevel, onComplete }`
    - Displays a sequence of Arabic numerals (١, ٢, ٣, ...) that pulse in rhythm
    - Player must click/tap in time with the rhythm count
    - Each "hammer strike" corresponds to a beat — tap within 200ms window = hit, outside = miss
    - Arabic numerals count from ١ to the recipe's required "strikes" (3-10 depending on recipe)
    - Accuracy = hits / total_strikes
    - Difficulty by level:
      - Level 1-3: Slow rhythm (1 beat/second), wide window (300ms), visual pulse indicator
      - Level 4-7: Medium rhythm (1.5 beats/second), medium window (200ms), smaller indicator
      - Level 8-10: Fast rhythm (2 beats/second), narrow window (100ms), no visual indicator
    - Visual: Anvil icon center, Arabic numeral display above, strike zone indicator, timing bar
    - Sound: Emit `EVENTS.SFX_CLICK` on each tap (anvil strike)
    - Uses `requestAnimationFrame` for precise timing

    Both mini-games:
    - Use CSS Modules for styling (no Tailwind, no inline styles for layout)
    - RTL text direction for Arabic content
    - Framer Motion for animations
    - Keyboard accessible (Enter/Space as tap alternative)
