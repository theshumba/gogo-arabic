    **professions.js:**
    - Export `PROFESSIONS` object keyed by profession ID: `calligrapher`, `cook`, `blacksmith`, `herbalist`, `weaver`, `builder`
    - Each profession: `{ id, nameArabic, nameEnglish, descriptionArabic, descriptionEnglish, maxLevel: 10, xpPerLevel: 100, category, teachableBy (companionId or npcId) }`
    - Arabic names: خطاط (Calligrapher), طباخ (Cook), حداد (Blacksmith), عطار (Herbalist), نساج (Weaver), بناء (Builder)
    - Export `PROFESSION_KEYS` array of all 6 keys
    - Each profession has a `skills` array of 10 skill names (Arabic + English) unlocked at each level

    **recipes.js:**
    - Export `RECIPES` object keyed by recipe ID (e.g., `calligraphy_basic_scroll`, `cook_flat_bread`, `blacksmith_iron_dagger`)
    - Create ~50 recipes per profession (300 total), distributed across levels 1-10:
      - Level 1-2: 10 recipes (basic, common ingredients)
      - Level 3-5: 15 recipes (intermediate, uncommon ingredients)
      - Level 6-8: 15 recipes (advanced, rare ingredients)
      - Level 9-10: 10 recipes (master, legendary ingredients)
    - Each recipe: `{ id, professionId, nameArabic, nameEnglish, minLevel, ingredients: [{ resourceId, quantity }], result: { itemId, quantity, quality }, xpGain, category, descriptionArabic, descriptionEnglish, buffEffect? }`
    - Categories by profession: calligrapher=enchantment, cook=food, blacksmith=weapon/armor, herbalist=potion, weaver=clothing, builder=structure
    - Cook and herbalist recipes include `buffEffect: { stat, value, duration }` for battle integration
    - Export helper `getRecipesByProfession(professionId)` and `getRecipesByLevel(professionId, level)`

    **resources.js:**
    - Export `RESOURCES` object keyed by resource ID (e.g., `paper`, `ink`, `flour`, `iron_ore`)
    - ~35 resources per profession (200+ total)
    - Each resource: `{ id, nameArabic, nameEnglish, professions: [professionIds], zones: [zoneIds], rarity, wordId (references vocabulary), gatherType (plant/mineral/water/animal/special), spriteKey }`
    - ALL resources have Arabic names and map to vocabulary wordIds
    - Export helpers `getResourcesByZone(zoneId)` and `getResourcesByProfession(professionId)`

    IMPORTANT: Use culturally respectful Arabic names. No deity references. Ingredients must be historically accurate to Islamic/Arabic civilization (e.g., saffron/زعفران, cardamom/هال, rosewater/ماء ورد, iron/حديد, silk/حرير, papyrus/بردي).

  <action>
    **craftingSlice.js** — Follow magicSlice.js and inventorySlice.js patterns:
    - initialState:
      ```
      {
        professions: {} // { [professionId]: { level: 0, xp: 0, recipesUnlocked: [], craftCount: 0 } }
        resources: []   // [{ resourceId, quantity, quality }]
        discoveredRecipes: []  // recipeIds found via exploration/NPC
        gatheringCooldowns: {} // { [spotId]: lastGatheredTimestamp }
      }
      ```
    - Reducers:
      - `learnProfession(state, { payload: { professionId } })` — Initialize profession at level 0 if not already known
      - `addProfessionXP(state, { payload: { professionId, xp } })` — Add XP, auto-level if threshold reached (100 XP × level)
      - `levelUpProfession(state, { payload: { professionId } })` — Increment level (max 10), reset XP overflow
      - `unlockRecipe(state, { payload: { recipeId, professionId } })` — Add recipe to profession's unlocked list + discoveredRecipes (check minLevel)
      - `addResource(state, { payload: { resourceId, quantity, quality } })` — Stack by resourceId+quality, cap at 999 per type
      - `removeResource(state, { payload: { resourceId, quantity } })` — Subtract quantity, remove if 0
      - `craftItem(state, { payload: { recipeId, quality } })` — Mark craft count increment, XP already handled externally
      - `recordGatheringCooldown(state, { payload: { spotId, timestamp } })` — Track last gathered time
    - Memoized selectors (createSelector):
      - `selectProfessions`, `selectProfessionByKey(professionId)`, `selectProfessionLevel(professionId)`
      - `selectResources`, `selectResourceQuantity(resourceId)`
      - `selectDiscoveredRecipes`, `selectRecipesForProfession(professionId)`
      - `selectGatheringCooldowns`
