  <action>
    **equipment.js** — Add crafted equipment entries:
    - Add 30+ crafted equipment items (5 per profession slot) to EQUIPMENT_DATA
    - Naming convention: `crafted_{profession}_{item}` (e.g., `crafted_blacksmith_iron_sword`, `crafted_weaver_silk_robe`)
    - Crafted items at level 8-10 should have stats matching or exceeding shop-bought legendary items (best-in-slot)
    - All items have Arabic names, lore, and cultural themes
    - Blacksmith: weapons and armor (sword, shield, helmet, gauntlets, greaves)
    - Weaver: clothing (robe, cloak, belt, boots, gloves)
    - Builder: accessories (amulet, ring, charm) — crafted from stone/gems
    - Each crafted item includes `craftedBy: professionId` field for tracking
    - Rarity scales with craft quality: common→legendary matches equipment rarity system

    **battleSlice.js** — Add active buffs support:
    - Add `activeBuffs: []` to initialState: `[{ buffId, stat, value, duration, startTime, source }]`
    - New reducers:
      - `applyBuff(state, { payload: { buffId, stat, value, duration, source } })` — add buff, replace if same buffId exists
      - `removeBuff(state, { payload: { buffId } })` — remove expired buff
      - `clearExpiredBuffs(state)` — remove all buffs where Date.now() > startTime + duration
    - New selector: `selectActiveBuffs` — returns active buffs list
    - New selector: `selectBuffBonuses` — aggregates all active buff stat bonuses into { hp, mp, damage, defense }
    - Buff stat types: hpRegen, mpRegen, damageBoost, defenseBoost, accuracyBoost, xpBoost

    **inventorySlice.js** — Add consumable use and enchantment scroll support:
    - New reducer: `useConsumable(state, { payload: { itemId } })`:
      - Decrements item quantity by 1
      - Returns the item's buffEffect for external dispatch to battleSlice.applyBuff
      - NOTE: The actual buff application is done by the caller (CraftingMiniGame or BattleMenu), not inside this reducer
    - New reducer: `applyEnchantment(state, { payload: { scrollItemId, targetSlot } })`:
      - Consumes the scroll item (quantity -1)
      - Adds an `enchantment` field to the equipped item in the slot
      - Enchantment: `{ inscription (Arabic text), bonus: { stat, value } }`
      - Each equipment slot can have at most 1 enchantment
    - New selector: `selectEnchantedEquipment` — returns equipped items with their enchantments

    **itemStats.js** — Update `calculateTotalEquipmentStats`:
    - Include enchantment bonuses in total stats calculation
    - Include active buff bonuses (from battleSlice) in a separate `calculateTotalBattleStats` function
    - Ensure crafted items' stats are included in the existing calculation
  </action>

    - `grep -c 'crafted_' src/data/equipment.js` outputs ≥30
    - `grep 'activeBuffs' src/store/slices/battleSlice.js` matches
    - `grep 'useConsumable\|applyEnchantment' src/store/slices/inventorySlice.js` matches both
    - Existing tests pass: `npx vitest run` (no regression in equipment/battle tests)
  </verify>
