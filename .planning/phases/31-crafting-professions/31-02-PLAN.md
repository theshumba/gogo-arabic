<feature>
  <name>Crafting Logic Functions</name>
  <files>src/utils/craftingLogic.js, src/utils/__tests__/craftingLogic.test.js</files>
  <behavior>
    **calculateCraftQuality(accuracy: number) → string**
    - accuracy > 0.95 → 'legendary'
    - accuracy > 0.80 → 'epic'
    - accuracy > 0.60 → 'rare'
    - accuracy > 0.40 → 'uncommon'
    - accuracy <= 0.40 → 'common'

    **calculateXPGain(baseXP: number, accuracy: number) → number**
    - accuracy >= 0.95 → baseXP × 1.5 (perfect bonus)
    - accuracy >= 0.80 → baseXP × 1.2 (good bonus)
    - accuracy >= 0.60 → baseXP × 1.0 (standard)
    - accuracy < 0.60 → baseXP × 0.5 (poor penalty)
    - Always return integer (Math.floor)

    **canUseIngredient(resourceId: string, fsrsCards: object) → boolean**
    - Returns true if RESOURCES[resourceId] exists AND fsrsCards[RESOURCES[resourceId].wordId] exists AND fsrsCards[wordId].card.reps > 0
    - Returns false if resource not found, word not in FSRS, or never reviewed

    **getDisplayableIngredients(recipeId: string, fsrsCards: object) → array**
    - Maps recipe ingredients to { resourceId, quantity, canUse, displayName, hint }
    - canUse: true → displayName = resource.nameArabic, hint = null
    - canUse: false → displayName = '???', hint = `Learn "${resource.nameEnglish}" to unlock`

    **hasRequiredResources(recipeId: string, resources: array) → { canCraft: boolean, missing: array }**
    - Checks each ingredient against player's resource inventory
    - Returns missing ingredient list with shortfall amounts

    **calculateProfessionXP(currentXP: number, currentLevel: number) → { current, required, percent }**
    - required = currentLevel × 100 (level 1 = 100 XP, level 10 = 1000 XP)
    - percent = (currentXP / required) × 100
    - Edge: level 0 requires 50 XP to reach level 1

    **calculateGatheringQuality(professionLevel: number) → string**
    - level 0-2: 80% normal, 20% high
    - level 3-5: 60% normal, 30% high, 10% pristine
    - level 6-8: 40% normal, 35% high, 20% pristine, 5% perfect
    - level 9-10: 20% normal, 30% high, 30% pristine, 20% perfect
    - NOTE: This uses a seeded random for testability — accept a `randomSeed` parameter

    Test cases for edge conditions:
    - accuracy = 0 → common quality, 0.5× XP
    - accuracy = 1.0 → legendary quality, 1.5× XP
    - accuracy = 0.95 exactly → legendary (inclusive boundary)
    - Unknown resourceId → canUseIngredient returns false
    - Empty FSRS cards → all ingredients locked
    - Recipe with 0 ingredients → canCraft = true (edge case)
    - Level 0 profession → 50 XP threshold
  </behavior>
