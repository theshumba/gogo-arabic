Create two new Phaser subsystem files:

**src/game/systems/ScreenShake.js** (~40 LOC):
- Class `ScreenShake` with constructor taking `scene` reference
- Method `shake(intensity = 'medium')` that maps intensity to Phaser camera shake params:
  - `'light'`: duration 100ms, intensity 0.003 (quiz correct answer)
  - `'medium'`: duration 200ms, intensity 0.008 (achievement unlock)
  - `'heavy'`: duration 350ms, intensity 0.015 (level up)
- On construction, check `window.matchMedia('(prefers-reduced-motion: reduce)').matches` and store as `this.reduceMotion`
- If `this.reduceMotion` is true, `shake()` returns immediately (no-op)
- Uses `this.scene.cameras.main.shake(duration, intensity)` -- built into Phaser, no dependencies
- Export default class

**src/game/systems/ParticleEffectManager.js** (~120 LOC):
- Class `ParticleEffectManager` with constructor taking `scene` reference
- Store `this.reduceMotion = window.matchMedia('(prefers-reduced-motion: reduce)').matches`
- If `reduceMotion`, all methods are no-ops
- Method `burst(x, y, config)` -- creates a one-shot particle burst at world position (x, y):
  - Creates a Phaser graphics texture dynamically for particles: 4x4 pixel white square, key `'particle-dot'`
  - Only create the texture once (check `scene.textures.exists('particle-dot')` first)
  - Uses `scene.add.particles(x, y, 'particle-dot', { ... })` (Phaser 3.60+ API)
  - Config params with defaults: `{ count: 20, speed: { min: 50, max: 150 }, lifespan: 800, scale: { start: 1, end: 0 }, tint: 0xE2B659 (gold), gravityY: 100, emitting: false }`
  - Call `emitter.explode(count)` to fire the burst
  - Auto-destroy emitter after lifespan + 200ms buffer via `scene.time.delayedCall`
- Method `continuous(x, y, config)` -- creates a looping sparkle that lasts `duration` ms:
  - Same `'particle-dot'` texture
  - Uses `scene.add.particles(x, y, 'particle-dot', { ... })` with emitting: true
  - Config defaults: `{ frequency: 80, speed: { min: 20, max: 60 }, lifespan: 600, scale: { start: 0.8, end: 0 }, tint: 0xE2B659, quantity: 2, duration: 2000 }`
  - The `duration` config controls how long emitting runs, then particle manager auto-stops
  - After `duration + lifespan + 200ms`, destroy the emitter via `scene.time.delayedCall`
- Method `destroy()` -- cleanup (remove any pending timers is nice-to-have)
- Export default class

**src/game/scenes/BootScene.js** -- add particle texture creation in `create()`:
- After `this.scene.start('WorldScene')`, add: generate the `'particle-dot'` texture via graphics if it doesn't exist. Actually, better to generate it lazily in ParticleEffectManager, so NO changes to BootScene needed. Skip this file.

Note: Phaser 3.60+ particle API uses `scene.add.particles(x, y, texture, config)`. The game uses Phaser 3 (imported as `import Phaser from 'phaser'`). Verify the installed Phaser version supports this API. If the project uses Phaser < 3.60, use the older `scene.add.particles(x, y).createEmitter(config)` style instead. Check `package.json` for the Phaser version before writing code.

  - `handleVfxBurst({ x, y, config })` -- if x/y not provided, default to camera center (`this.cameras.main.midPoint.x/y`). Call `this.particleEffects.burst(x, y, config)`

- In `shutdown()`, add:
  - `EventBus.off('vfx-shake', this.handleVfxShake, this);`
  - `EventBus.off('vfx-particles-burst', this.handleVfxBurst, this);`
  - `EventBus.off('vfx-particles-continuous', this.handleVfxContinuous, this);`
