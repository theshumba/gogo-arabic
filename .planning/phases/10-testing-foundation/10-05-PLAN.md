       - Clear localStorage before test: `await page.evaluate(() => localStorage.clear())`
       - Navigate to `/` — should show main menu or character creation
       - If main menu: click "New Game" button
       - On character creation screen: enter player name, select options, click create/continue
       - Verify game loads: canvas element visible, HUD elements present

    3. **Create `e2e/review-session.spec.js`:**
       - Navigate to `/review` or click "Start Review" from dashboard
       - Verify quiz interface loads (question text, answer choices visible)
       - Select an answer (click first available choice)
       - Verify feedback appears (correct/incorrect indicator)
       - Continue through session (may need to handle different quiz types)
       - After session completion: verify results/summary screen shows
       - Verify XP indicator or score is displayed
       - Use `page.waitForSelector` with generous timeouts for async operations

    **Important E2E patterns:**
    - Use `test.beforeEach` to clear localStorage for isolation: `await page.evaluate(() => localStorage.clear())`
    - Use semantic selectors: `page.getByRole('button', { name: /.../ })`, `page.getByText(/.../)`
    - Use `await expect(locator).toBeVisible({ timeout: 10000 })` for async loading
    - Avoid hardcoded waits (`waitForTimeout`) — use `waitForSelector` or `expect().toBeVisible()`
    - Add descriptive test names that explain the user journey
