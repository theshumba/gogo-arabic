    ```javascript
    import { describe, it, expect, beforeEach } from 'vitest';
    import reducer, { action1, action2, selectX } from '../slices/xxxSlice.js';
    ```

    1. `beforeEach` → get initialState via `reducer(undefined, { type: 'unknown' })`
    2. Test each **exported action creator** (reducer case): dispatch action, assert state field changed correctly
    3. Test each **exported selector**: create mock root state `{ sliceName: { ...fields } }`, call selector, assert return value
    4. Test **edge cases**: empty arrays, zero values, boundary conditions
    5. Use factories from Task 1 where state objects are complex (quest, vocabulary)
