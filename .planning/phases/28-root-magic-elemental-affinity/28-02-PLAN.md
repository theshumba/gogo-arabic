**File 1: src/game/systems/magic/RootMagicManager.js**

Create a Phaser system class (not a Phaser.Scene — just a plain class that receives scene reference, same pattern as EnemyAI).

Constructor: `constructor(scene)` — store scene reference, initialize combo tracking.

**Methods:**

1. `castSpell(slot, targetIndex, grammarAccuracy)`:
   - Read state: `store.getState()` for magic.equippedSpells[slot] and battle.playerMP
   - Validate: spell exists, playerMP >= spell.mpCost. If not, emit EVENTS.MAGIC_MP_DEPLETED and return false.
   - Dispatch `spendMP(spell.mpCost)` to battleSlice
   - Dispatch `setLastCastTimestamp(Date.now())` to magicSlice
   - Emit `EVENTS.MAGIC_VFX_START` with { element: spell.element, rootId: spell.rootId, targetIndex }
   - Use `scene.time.delayedCall(800, ...)` for VFX delay, then:
     - Call `_calculateSpellDamage(spell, grammarAccuracy)` to get final damage
     - Dispatch `dealDamage({ damage: finalDamage, correct: true })` to battleSlice (magic always "correct" — accuracy affects multiplier instead)
     - Dispatch `recordRootUse({ rootId: spell.rootId, form: spell.form, accuracy: grammarAccuracy })` to magicSlice
     - Check for combo with previous cast via `_checkComboOpportunity(spell)`
     - Emit `EVENTS.MAGIC_CAST_COMPLETE` with { damage: finalDamage, spell, rootId: spell.rootId }
     - Emit `EVENTS.MAGIC_VFX_END`
   - Return true

2. `_calculateSpellDamage(spell, grammarAccuracy)`:
   - Read rootMastery for spell.rootId from store
   - Read affinity from store
   - Get baseDamage from SPELL_TIERS[spell.form].powerMult * 20 (base 20 damage * form multiplier)
   - Mastery multiplier: 1.0 + (rootLevel * 0.1) — level 1 = 1.1x, level 10 = 2.0x
   - Affinity multiplier: 2.0 if spell.element === affinity.primary, 1.5 if secondary, else 1.0
   - Grammar accuracy multiplier: >=0.95 = 1.2x, >=0.7 = 1.0x, <0.7 = 0.5x (consistent with BattleDamageCalculator pattern)
   - Return Math.floor(baseDamage * masteryMult * affinityMult * grammarMult), minimum 1

3. `_checkComboOpportunity(spell)`:
   - Track last 2 spells cast this battle in an instance array `this.recentCasts`
   - If recentCasts has >=1 entry, call `checkCombo(recentCasts[recentCasts.length-1], spell, store.getState().magic.rootMastery)`
   - If combo found: dispatch `recordCombo(...)` to magicSlice, emit `EVENTS.MAGIC_COMBO_TRIGGERED` with combo data, apply combo.damageMultiplier as bonus
   - Push spell to recentCasts, cap at 5 entries

4. `resetBattleState()`:
   - Clear this.recentCasts
   - Dispatch clearBattleState() to magicSlice

Import from: store.js, magicSlice.js (discoverRoot, recordRootUse, recordCombo, clearBattleState, setLastCastTimestamp, selectEquippedSpells, selectRootMastery, selectAffinity), battleSlice.js (spendMP, dealDamage), eventBusTypes.js (EVENTS), rootMagic.js (SPELL_TIERS), elementCombos.js (checkCombo).

**Sync Direction 1: FSRS card reviewed -> increment root XP**
Listen for action.type === 'vocabulary/updateFsrsCard'. When fired:
- Extract wordId from action.payload
- Call `getWordRoot(wordId)` from rootsData.js to find the root
- If root found AND root is in magic.discoveredRoots:
  - Determine accuracy from the FSRS log rating (rating >= 3 = 0.8 accuracy, rating 2 = 0.5, rating 1 = 0.3)
  - Dispatch `recordRootUse({ rootId: root.root, form: 'I', accuracy })` — 30% weight applied via accuracy scaling
  - This means FSRS contribution: rating 3 = 0.8 * 0.3 = 0.24 effective accuracy -> ~5 XP (partial tier)
  - And in-game casting: 0.95 accuracy * 0.7 = 0.665 -> 10 XP (good tier)
  - Net effect: ~70% weight from in-game, ~30% from FSRS reviews

**Sync Direction 2: Root level-up -> suggest derived words for FSRS**
Listen for action.type === 'magic/recordRootUse'. After dispatching:
- Read updated rootMastery from store
- Compare level to what it was before (store prevState.magic.rootMastery[rootId]?.level)
- If level increased:
  - Get derived words via `getRootWords(rootId)` from rootsData.js
  - For each derived word NOT in vocabulary.fsrsCards, dispatch `addFsrsCard({ wordId, card: createDefaultCard(), source: 'root_mastery_unlock' })`
  - Emit `EVENTS.MAGIC_ROOT_LEVEL_UP` with { rootId, newLevel }
  - Limit to 3 new words per level-up to avoid flooding review queue

**Sync Direction 3: Root level triggers form unlock**
- After root level-up, check if new level >= 3 and Form II not unlocked -> dispatch unlockForm({ rootId, form: 'II' })
- Level >= 5 and Form III not unlocked -> dispatch unlockForm({ rootId, form: 'III' })
- Level >= 7 -> Form IV, Level >= 9 -> Form V
- Emit EVENTS.MAGIC_FORM_UNLOCKED with { rootId, form }

For createDefaultCard(): create a minimal FSRS-compatible card object: `{ due: new Date().toISOString(), stability: 0, difficulty: 0, elapsed_days: 0, scheduled_days: 0, reps: 0, lapses: 0, state: 'New' }`.
