  <action>
Create magicSlice following the existing battleSlice pattern (createSlice + createSelector from RTK).

**Initial state:**
```
{
  discoveredRoots: [],           // Array of root IDs (e.g., 'ك-ت-ب')
  rootMastery: {},               // { 'ك-ت-ب': { timesUsed, formsUnlocked: ['I'], xp, level, element } }
  affinity: {
    primary: null,               // Locked after 50+ choices
    secondary: null,
    discoveryChoices: [],        // [{ choiceId, element, weight, timestamp }]
    choiceCount: 0,
  },
  equippedSpells: [null, null, null, null, null, null],  // 6 hotbar slots
  activeCombos: [],              // Battle-temporary combo tracking
  lastCastTimestamp: null,
}
```

**Reducers (9 total):**
1. `discoverRoot({ rootId, element })` — Add root to discoveredRoots, initialize rootMastery entry with level 1, xp 0, formsUnlocked: ['I']. Skip if already discovered. Validate element exists in ROOT_ELEMENTS import.
2. `recordRootUse({ rootId, form, accuracy })` — Increment timesUsed, add XP based on accuracy (perfect >=0.95: 15 XP, good >=0.7: 10 XP, partial: 5 XP). Level up at 100 XP thresholds (level = floor(xp/100) + 1).
3. `unlockForm({ rootId, form })` — Push form to rootMastery[rootId].formsUnlocked if not present. Only allow if root exists.
4. `recordAffinityChoice({ choiceId, element, weight })` — Push to discoveryChoices, increment choiceCount. When choiceCount >= 50 AND primary is null, compute weighted histogram of element choices, sort by weight sum, lock primary = highest, secondary = second highest.
5. `equipSpell({ slot, rootId, form })` — Validate slot 0-5, root is discovered, form is unlocked. Look up mpCost from SPELL_TIERS import. Set equippedSpells[slot] = { rootId, form, element, mpCost }.
6. `unequipSpell(slot)` — Set equippedSpells[slot] = null.
7. `recordCombo({ comboId, elements, timestamp })` — Push to activeCombos for current battle tracking.
8. `clearBattleState()` — Reset activeCombos and lastCastTimestamp. Called on battle end.
9. `setLastCastTimestamp(timestamp)` — For input buffer staleness validation (Pitfall 5 from research).

**Selectors (8 total):**
1. `selectDiscoveredRoots(state)` — state.magic.discoveredRoots
2. `selectRootMastery(state, rootId)` — state.magic.rootMastery[rootId]
3. `selectAllRootMastery(state)` — state.magic.rootMastery
4. `selectAffinity(state)` — state.magic.affinity
5. `selectEquippedSpells(state)` — state.magic.equippedSpells
6. `selectAffinityBonuses(state)` — createSelector: returns { primaryElement, secondaryElement, primaryMultiplier: 2.0, secondaryMultiplier: 1.5 } or nulls if affinity not locked
7. `selectDiscoveredRootsByElement(state, element)` — createSelector: filters discoveredRoots by element match in rootMastery
8. `selectSpellPower(state, rootId)` — createSelector: computes base power from root level + affinity bonus

Import ROOT_ELEMENTS from `../../data/rootMagic.js` for element validation.
Import SPELL_TIERS from `../../data/rootMagic.js` for MP cost lookup.
Do NOT import from vocabularySlice (that's the middleware's job, not the slice).
Do NOT use Date.now() in reducers — pass timestamps via action payloads.
