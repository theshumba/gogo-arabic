# Plan 65-01: GameLayout Chunk Splitting

## Context

`GameLayout.js` is **1,190 KB** — the largest app chunk. It statically imports 11 overlay/panel components, pulling their entire dependency trees into the GameLayout chunk. Most of these overlays are conditionally rendered (only shown when a specific Redux flag or state is active), so they're perfect candidates for lazy loading.

**Current static imports (candidates for lazy):**
| Component | File Size | Always Visible? |
|-----------|----------|-----------------|
| DialogueOverlay | 689 lines | No — when dialogueOpen |
| QuizOverlay | 15.5 KB | No — when quizOpen |
| QuestLog | 8.8 KB | No — when questLogOpen |
| SignOverlay | 33 lines | No — when signText |
| ObjectInteractionOverlay | 155 lines | No — when objectInteraction |
| CinematicIntro | 2 KB | No — first play only |
| PathChoice | 137 lines | No — onboarding only |
| WelcomeSplash | co-located in TutorialHints | No — first session |
| TutorialHints | 210 lines | No — early game |
| LevelUpModal | 243 lines | No — on level up |
| StreakRewardToast | 108 lines | No — on streak |
| AchievementToast | 4.5 KB | No — on achievement |

**Keep static (always visible on game screen):**
- HUD (13.8 KB) — always rendered
- MiniMap (74 lines) — always rendered
- NotificationToast (138 lines) — always rendered
- PhaserGame — core canvas, always rendered

## Implementation

### Step 1: Extract PauseMenu and ActivitiesMenu

Move the internal `PauseMenu` (lines 123-188) and `ActivitiesMenu` (lines 49-121) components from GameLayout.jsx into their own files:
- `src/components/Router/PauseMenu.jsx` + `.module.css`
- `src/components/Router/ActivitiesMenu.jsx` + `.module.css`

These are self-contained components with their own state. Extract inline styles to CSS Modules.

### Step 2: Convert static imports to lazy

Replace all 12 conditional overlay imports with `React.lazy()`:

```jsx
// KEEP STATIC — always visible
import HUD from '../HUD/HUD.jsx';
import MiniMap from '../HUD/MiniMap.jsx';
import NotificationToast from '../HUD/NotificationToast.jsx';
import { PhaserGame } from '../../game/PhaserGame.jsx';

// CONVERT TO LAZY — conditionally rendered
const DialogueOverlay = lazy(() => import('../NPC/DialogueOverlay.jsx'));
const QuizOverlay = lazy(() => import('../Quiz/QuizOverlay.jsx'));
const QuestLog = lazy(() => import('../Quest/QuestLog.jsx'));
const SignOverlay = lazy(() => import('../World/SignOverlay.jsx'));
const ObjectInteractionOverlay = lazy(() => import('../World/ObjectInteractionOverlay.jsx'));
const TutorialHints = lazy(() => import('../Onboarding/TutorialHints.jsx'));
const WelcomeSplash = lazy(() => import('../Onboarding/WelcomeSplash.jsx'));
const CinematicIntro = lazy(() => import('../Onboarding/CinematicIntro.jsx'));
const PathChoice = lazy(() => import('../Onboarding/PathChoice.jsx'));
const LevelUpModal = lazy(() => import('../UI/LevelUpModal.jsx'));
const StreakRewardToast = lazy(() => import('../Goals/StreakRewardToast.jsx'));
const AchievementToast = lazy(() => import('../Achievements/AchievementToast.jsx'));
const PauseMenu = lazy(() => import('./PauseMenu.jsx'));
const ActivitiesMenu = lazy(() => import('./ActivitiesMenu.jsx'));
```

**Note:** `WelcomeSplash` is currently a named export from `TutorialHints.jsx`. It needs to be extracted to its own file or the lazy import pattern adjusted (lazy only works with default exports).

### Step 3: Wrap all lazy components in Suspense

Every lazy component already conditionally rendered must be wrapped in `<Suspense fallback={null}>`. Group them logically:

```jsx
<Suspense fallback={null}>
  {dialogueOpen && <DialogueOverlay />}
  {quizOpen && <QuizOverlay />}
  {/* ... etc */}
</Suspense>
```

Run `npx vite build` and confirm:

- No circular dependency warnings introduced
- Total bundle size unchanged (just redistributed)
