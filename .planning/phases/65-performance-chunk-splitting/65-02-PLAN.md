# Plan 65-02: Vocabulary Data Chunk Splitting

## Context

`vocabulary-data` is the **largest single chunk at 1,704 KB** (243 KB gzipped). It bundles:
- `vocabulary.json` — 110 KB (250 curated words, mostly A1)
- `vocabulary-final.json` — 912 KB (4,764 words, A1-B2)
- `vocabularyExpanded.js` — 1.0 MB (1,500 B1-B2 words)

All 5,000+ words load on app start, but early-game players only need A1-A2 (~2,200 words). B1-B2 words (~2,800 words) aren't needed until the player reaches higher CEFR levels or takes the placement test.

**Current import chain:**
```
20+ components → vocabularyAll.js → vocabulary-final.json + vocabularyExpanded.js
```

## Implementation

### Step 1: Create vocabularyByLevel.js

New file that splits vocabulary loading by CEFR level:

```javascript
// src/data/vocabularyByLevel.js
import coreVocab from './vocabulary.json';
import finalVocab from './vocabulary-final.json';

// A1-A2 words from both sources — needed from game start
const coreWords = [...coreVocab, ...finalVocab.filter(w =>
  !w.cefrLevel || w.cefrLevel === 'A1' || w.cefrLevel === 'A2'
)];

let extendedWords = null;
let allWordsCache = null;

// Lazy-load B1-B2 words from vocabularyExpanded.js
async function loadExtendedVocabulary() {
  if (extendedWords) return extendedWords;
  const { default: expanded } = await import('./vocabularyExpanded.js');
  const b1b2FromFinal = finalVocab.filter(w =>
    w.cefrLevel === 'B1' || w.cefrLevel === 'B2'
  );
  extendedWords = [...b1b2FromFinal, ...expanded];
  allWordsCache = null; // invalidate merged cache
  return extendedWords;
}

// Synchronous: returns A1-A2 immediately, includes B1-B2 if already loaded
export function getAllVocabularySync() {
  if (allWordsCache) return allWordsCache;
  const all = extendedWords ? [...coreWords, ...extendedWords] : coreWords;
  // Deduplicate by ID, then by Arabic text
  const seen = new Map();
  for (const word of all) {
    const key = word.id || word.arabic;
    if (!seen.has(key)) seen.set(key, word);
  }
  allWordsCache = Array.from(seen.values());
  return allWordsCache;
}

// Async: loads everything, returns complete vocabulary
export async function getAllVocabularyFull() {
  await loadExtendedVocabulary();
  return getAllVocabularySync();
}

export { coreWords, loadExtendedVocabulary };
```

### Step 2: Update vocabularyAll.js barrel

Modify the barrel to use the new split loader while maintaining the same synchronous export signature for backward compatibility:

```javascript
// src/data/vocabularyAll.js — updated barrel
import { getAllVocabularySync, loadExtendedVocabulary } from './vocabularyByLevel.js';

// Trigger background load of B1-B2 words
loadExtendedVocabulary().catch(() => {});

// Export merged vocabulary (starts with A1-A2, expands when B1-B2 loads)
const vocabularyAll = getAllVocabularySync();
export default vocabularyAll;
export { loadExtendedVocabulary, getAllVocabularySync };
```

**Key insight:** The barrel still exports synchronously, so all 20+ consuming components work unchanged. The background `loadExtendedVocabulary()` call fills in B1-B2 words shortly after app start. Components that need guaranteed-complete vocabulary (e.g., placement test) can `await loadExtendedVocabulary()` first.

### Step 3: Update vite.config.js manualChunks

Split the single `vocabulary-data` chunk into two:

```javascript
// Core A1-A2 vocabulary (~700KB) — eager
if (id.includes('src/data/vocabulary-final.json') ||
    id.includes('src/data/vocabularyAll.js') ||
    id.includes('src/data/vocabularyByLevel.js') ||
    id.includes('src/data/vocabulary.json')) {
  return 'vocab-core';
}
// Extended B1-B2 vocabulary (~1,000KB) — lazy loaded
if (id.includes('src/data/vocabularyExpanded.js')) {
  return 'vocab-extended';
}
```

## Risk Mitigation

- **Race condition:** Components reading vocabulary before B1-B2 loads get A1-A2 only — this is fine for early game. Placement test and CEFR components should `await loadExtendedVocabulary()`.
- **Deduplication:** Same logic as current vocabularyAll.js — priority order preserved.
- **No breaking changes:** The default export of vocabularyAll.js remains an array. It starts smaller but grows after async load completes.
