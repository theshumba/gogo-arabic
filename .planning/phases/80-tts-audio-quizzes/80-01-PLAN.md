# Phase 80: TTS Infrastructure & Audio Quiz Types (AUD-01 + AUD-02)

## Objective
Add 2 new audio-based quiz types powered by Web Speech API TTS:
1. **Listening Comprehension** (AUD-01) — TTS reads Arabic, player picks English meaning
2. **Dictation** (AUD-02) — TTS reads Arabic, player types it

## Design Decisions
- **Web Speech API** chosen over Howler/audio files: no per-word recordings needed, works for any Arabic text
- **Graceful fallback**: if TTS unavailable, Arabic text shown with warning banner
- **Rate 0.8**: slightly slower than natural speed for learning context
- **Tashkeel stripping + alef normalization** for Dictation grading: Arabic has many valid spellings
- **`requiresTts: true`** flag in registry entries for future filtering (skip if TTS unavailable)
- **Separate `audioQuizTypes.js`**: keeps integration as a merge step, no existing files modified
