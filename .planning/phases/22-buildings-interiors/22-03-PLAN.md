1. **Dynamic building unlock via story flags (BLDG-11):**
   In `handleInteractable()`, update the door handling to check `unlockFlag` dynamically:
   ```javascript
   } else if (obj.type === 'door') {
     // Dynamic unlock check — door may have been locked at zone load but unlocked via story progress
     let isLocked = obj.locked;
     if (isLocked && obj.unlockFlag) {
       const { selectStoryFlag } = await import('../../store/slices/narrativeSlice.js');
       const flagValue = selectStoryFlag(obj.unlockFlag)(store.getState());
       if (flagValue) {
         isLocked = false;
         // Update the runtime object so glow/tint updates on next frame
         obj.locked = false;
         if (obj.sprite) {
           obj.sprite.clearTint();
         }
       }
     }

     if (isLocked) {
       EventBus.emit(EVENTS.DOOR_LOCKED, {
         message: obj.lockMessage || 'This door is locked.',
         id: obj.id,
       });
     } else if (obj.interiorId) {
       // ... existing DOOR_OPENED with interiorId logic from Plan 01
     } else {
       EventBus.emit(EVENTS.DOOR_OPENED, { id: obj.id });
     }
   }
   ```
   Note: The `await import()` makes handleInteractable async. The function is only called on SPACE press (not every frame), so the dynamic import cost is negligible.

2. **Door glow tween cleanup:**
   In `destroy()`, ensure door glow tweens are properly cleaned up:
   - Track tweens in an array: `this.doorTweens = []` in constructor
   - In `create()`, push each door glow tween into `this.doorTweens`
   - In `destroy()`, iterate `this.doorTweens` and call `.remove()` on each, then clear the array
   This prevents memory leaks from orphaned tweens after zone transitions.

3. **Locked door initial tint:**
   In `create()`, for doors with `locked: true`, apply darker tint: `sprite.setTint(0x888888)`
   For doors with `locked: false` and `interiorId`, apply the pulsing glow tween (from Plan 01 Task 2).
   For doors without interiorId (legacy doors), no glow.
