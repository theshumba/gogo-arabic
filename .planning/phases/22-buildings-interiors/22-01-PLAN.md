Create `src/game/scenes/InteriorScene.js` — a single generic Phaser.Scene that handles ALL building interiors. Follow the WorldScene delegation pattern exactly.

**Constructor:**
- `super('InteriorScene')` — single scene key, reused for all interiors
- Same subsystem properties as WorldScene: domOverlay, playerController, npcManager, interactableManager, mapLoader (null initially)
- No sceneStackManager (only WorldScene manages the stack)
- No zoneTransition, screenShake, particleEffects (interiors are simple)
- Properties: `returnSceneKey`, `interiorId`, `entryPosition`, `interactKey`, `interactCooldown`, `frozen`

**init(data):**
- Receive `{ returnSceneKey, interiorId, entryPosition }` from SceneStackManager.pushScene()
- Store all three properties for exit handling

**create():**
- Import INTERIORS from `../../data/interiors.js` (will be created in Plan 02; for now import and guard with fallback empty object)
- Look up interior config: `const interior = INTERIORS[this.interiorId]`
- If no interior config found, log error and immediately pop back to WorldScene
- Initialize subsystems in same order as WorldScene:
  1. `this.domOverlay = new DOMOverlayManager(this); this.domOverlay.init();`
  2. `this.playerController = new PlayerController(this);`
  3. `this.npcManager = new NPCManager(this);`
  4. `this.interactableManager = new InteractableManager(this);`
  5. `this.mapLoader = new MapLoader(this);`
- Set `this.currentMapW = interior.mapWidth` and `this.currentMapH = interior.mapHeight` (PlayerController reads these from scene)
- Build map: `const wallGroup = this.mapLoader.create(interior, interior.mapWidth, interior.mapHeight);`
- Spawn player at interior spawn point: `this.playerController.create(interior.spawnPoint.x * 64, interior.spawnPoint.y * 64, wallGroup)`
- Spawn NPCs: `this.npcManager.create(interior.npcs || [], player, wallGroup, this.domOverlay)`
- Spawn interactables: `this.interactableManager.create(interior.interactables || [], this.mapLoader.getObjectSprites())`
- Setup camera: `this.playerController.setupCamera(interior.mapWidth * 64, interior.mapHeight * 64)`
- Input: `this.interactKey = this.input.keyboard.addKey(Phaser.Input.Keyboard.KeyCodes.SPACE)`
- EventBus listeners: PLAYER_FREEZE, PLAYER_UNFREEZE (same as WorldScene)
- Dispatch `markBuildingVisited(this.interiorId)` to narrativeSlice via store.dispatch()

**update():**
- If frozen, only update domOverlay and return
- `this.playerController.update()`
- Y-sort all sprites (player + NPCs) by y-position for depth ordering
- `this.npcManager.update(player, this.domOverlay, this.interactKey, this.interactCooldown, this.setInteractCooldown.bind(this))`
- `this.interactableManager.update(player, this.interactKey, this.interactCooldown, this.setInteractCooldown.bind(this))`
- `this.checkExitDoor()` — check BEFORE interactables to prevent conflicts (Pitfall 4 from research)
- `if (this.domOverlay) this.domOverlay.update()`

**checkExitDoor():**
- Find exit door from interactables: `this.interactableManager.interactables.find(obj => obj.isExit)`
- If no exit door, return
- Calculate distance between player and exit door
- If within INTERACT_RANGE (128px) and SPACE just pressed and not on cooldown:
  - Set cooldown (500ms via this.time.delayedCall)
  - Call `this.exitBuilding()`
- Note: This check runs BEFORE interactableManager.update() in the update loop to give exit priority

**exitBuilding():**
- Import audioManager dynamically: `const { audioManager } = await import('../../services/audio.js')`
- Import ZONE_BGM_MAP: `const { ZONE_BGM_MAP } = await import('../../data/audioConfig.js')`
- Determine zone from WorldScene: get the WorldScene via `this.scene.get(this.returnSceneKey)`, read its `currentZone`
- Crossfade back to zone BGM: `audioManager.playBGM(ZONE_BGM_MAP[zone] || 'oasis')`
- Get WorldScene reference and call: `worldScene.sceneStackManager.popScene()`
- After popScene, WorldScene needs to know where to put the player — store entryPosition in WorldScene before pop:
  `worldScene.pendingSpawnPosition = this.entryPosition`

**shutdown():**
- Clean up EventBus listeners (PLAYER_FREEZE, PLAYER_UNFREEZE)
- Destroy all subsystems in reverse order: playerController, interactableManager, npcManager, mapLoader, domOverlay
- Null out all references

**handleFreeze/handleUnfreeze:** Same as WorldScene pattern.

**setInteractCooldown(value):** Same as WorldScene pattern.

**Update `src/game/config.js`:**
- Import InteriorScene: `import { InteriorScene } from './scenes/InteriorScene.js';`
- Add to scene array: `scene: [BootScene, WorldScene, InteriorScene]`

**Update `src/game/scenes/WorldScene.js`:**
- In `create()`, add DOOR_OPENED event handler:
  ```javascript
  EventBus.on(EVENTS.DOOR_OPENED, this.handleDoorOpened, this);
  ```
- Add `handleDoorOpened` method:
  ```javascript
  async handleDoorOpened({ id, interiorId, entryPosition }) {
    if (!interiorId) return; // Legacy door without interior — ignore

    // Crossfade audio to interior ambient
    const { audioManager } = await import('../../services/audio.js');
    const { INTERIOR_BGM } = await import('../../data/audioConfig.js');
    const bgmTrack = INTERIOR_BGM[interiorId] || 'interior';
    audioManager.playBGM(bgmTrack);

    // Launch interior scene via SceneStackManager
    this.sceneStackManager.pushScene('InteriorScene', {
      interiorId,
      entryPosition,
    });

    EventBus.emit(EVENTS.BUILDING_ENTERED, { interiorId });
  }
  ```
- In `create()`, after SceneStackManager initialization, add resume handler to restore player position:
  ```javascript
  this.events.on('resume', () => {
    // Restore player to entry position after exiting a building
    if (this.pendingSpawnPosition) {
      const player = this.playerController.getPlayer();
      if (player) {
        player.setPosition(this.pendingSpawnPosition.x, this.pendingSpawnPosition.y);
      }
      this.pendingSpawnPosition = null;
      EventBus.emit(EVENTS.BUILDING_EXITED);
    }
  });
  ```
- In `shutdown()`, add cleanup: `EventBus.off(EVENTS.DOOR_OPENED, this.handleDoorOpened, this);`
- Add `this.pendingSpawnPosition = null;` to constructor.
