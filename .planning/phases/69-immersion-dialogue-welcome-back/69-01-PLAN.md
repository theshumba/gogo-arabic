    ## Approach: Tag-Based Comprehension Checks

    Use ink's built-in tag system. When a dialogue line has the tag `#comprehension_check`, DialogueOverlay pauses normal line advancement and shows a ComprehensionCheck component. The check data (question, options, correct answer) is passed via ink external functions that set state before the tagged line.

    ### 1. Add event constant to eventBusTypes.js

    Add to the EVENTS object:
    ```js
    COMPREHENSION_CHECK_COMPLETE: 'comprehension_check_complete',
    ```

    ### 2. Add external functions to InkDialogueEngine.js

    In `_bindExternalFunctions()`, add these new bindings:

    ```js
    // Comprehension check data — set by ink before #comprehension_check tagged line
    this._comprehensionData = null;

    this._story.BindExternalFunction('setComprehensionCheck', (question, optionA, optionB, optionC, correctIndex) => {
      this._comprehensionData = {
        question,
        options: [optionA, optionB, optionC],
        correctIndex, // 0, 1, or 2
      };
    });
    ```

    Add a public getter:
    ```js
    getComprehensionData() {
      const data = this._comprehensionData;
      this._comprehensionData = null; // consume once
      return data;
    }
    ```

    Add to `reset()` method:
    ```js
    this._comprehensionData = null;
    ```

    ### 3. Create ComprehensionCheck.jsx

    A simple inline quiz component rendered INSIDE DialogueOverlay's dialogue box area:

    ```jsx
    // Props: { question, options, correctIndex, onComplete }
    // State: selectedIndex (null), answered (false)
    // On select: set selectedIndex, set answered=true
    // Show feedback: correct = green highlight, wrong = red + show correct in green
    // After 1.5s delay OR click "Continue": call onComplete(wasCorrect)
    ```

    Structure:
    - Question text (RTL, Arabic font, gold color #e2b659)
    - 3 option buttons (dark bg, white text, hover gold border)
    - After answer: correct option highlighted green (#4ade80), wrong highlighted red (#ef4444)
    - Feedback text: correct → "!أحسنت" (Well done!), wrong → "The answer is: [correct option]"
    - Continue button appears after answering

    ### 4. Create ComprehensionCheck.module.css

    Dark theme consistent with DialogueOverlay:
    - `.container`: padding 16px, bg #1a1a2e, border-radius 8px, margin-top 8px
    - `.question`: color #e2b659, font-size 1.1rem, direction rtl, margin-bottom 12px
    - `.option`: bg #2b292c, color #fff, border 2px solid transparent, padding 10px 16px, border-radius 6px, cursor pointer, direction rtl, margin-bottom 8px, width 100%
    - `.option:hover`: border-color #e2b659
    - `.correct`: border-color #4ade80, bg rgba(74,222,128,0.15)
    - `.wrong`: border-color #ef4444, bg rgba(239,68,68,0.15)
    - `.disabled`: pointer-events none, opacity 0.7
    - `.feedback`: color #c8c8c8, font-size 0.9rem, margin-top 8px, direction rtl
    - `.continueBtn`: bg #e2b659, color #1a1a2e, padding 8px 20px, border-radius 6px, border none, cursor pointer, font-weight bold, margin-top 12px

    ### 5. Integrate into DialogueOverlay.jsx

    In the ink dialogue rendering section:

    a. Import ComprehensionCheck:
    ```js
    import ComprehensionCheck from './ComprehensionCheck.jsx';
    ```

    b. Add state:
    ```js
    const [comprehensionCheck, setComprehensionCheck] = useState(null);
    ```

    c. After advancing ink lines (in the continue loop or line advancement handler), check if the current line has a `#comprehension_check` tag:

    When processing ink lines, inkjs provides tags via `story.currentTags`. After each `story.Continue()` call, check:
    ```js
    const tags = engine._story?.currentTags || [];
    if (tags.includes('comprehension_check')) {
      const checkData = engine.getComprehensionData();
      if (checkData) {
        setComprehensionCheck(checkData);
        // Pause line advancement — don't auto-advance past this line
      }
    }
    ```

    d. When comprehensionCheck state is set, render ComprehensionCheck instead of the normal "click to advance" behavior:
    ```jsx
    {comprehensionCheck && (
      <ComprehensionCheck
        question={comprehensionCheck.question}
        options={comprehensionCheck.options}
        correctIndex={comprehensionCheck.correctIndex}
        onComplete={(wasCorrect) => {
          if (wasCorrect) {
            // Award small relationship bonus
            dispatch(incrementNpcRelationship({
              npcId: inkDialogueState.npcData?.id,
              amount: 2,
            }));
          }
          setComprehensionCheck(null);
          // Resume dialogue advancement
        }}
      />
    )}
    ```

    e. While comprehensionCheck is active, disable the normal click-to-advance behavior on the dialogue box.

    ### Important Implementation Notes

    - `currentTags` in inkjs is available after each `Continue()` call — it returns tags for the LAST line produced
    - The ink script calls `setComprehensionCheck(...)` BEFORE the tagged line, so data is ready when the tag is detected
    - DialogueOverlay already has a line-by-line advancement system — the comprehension check just pauses it
    - After ComprehensionCheck completes, resume normal dialogue flow (call the existing advance function)
    - The `incrementNpcRelationship` import already exists in DialogueOverlay for gift-giving
