  **New state fields added to initialState:**
  ```javascript
  // --- Phase 32: Multi-target & combo meter ---
  enemies: [],              // [{ enemyId, hp, maxHp, effects: [], row: 'front'|'back', defeated: false }]
  comboMeter: 0,            // 0-100 combo charge (fills with consecutive correct answers)
  maxComboMeter: 100,
  grammarComboState: null,  // { type: 'noun_adj'|'verb_chain'|'sentence', chain: [], multiplier: 1.0 }

  playerRow: 'front',       // Player positioning
  arabicUsedThisBattle: [], // [{ word, accuracy, timestamp, comboType? }] for post-battle review
  ```

  **New reducers:**
  - `initMultiTargetBattle(state, { payload: { enemyParty } })` — populates enemies array from enemyParty: `[{ enemyId, hp, maxHp, effects: [], row: idx < 2 ? 'front' : 'back', defeated: false }]`. Also sets `bossHP` to sum of all enemy HP for backward compat.
  - `dealDamageToEnemy(state, { payload: { enemyIndex, damage } })` — reduces enemies[enemyIndex].hp, marks defeated if hp <= 0. Updates `bossHP` as sum of remaining enemy HP.
  - `applyEnemyEffectMulti(state, { payload: { enemyIndex, effect } })` — applies status effect to specific enemy in enemies array
  - `tickEnemyEffectsMulti(state)` — ticks effects for all enemies
  - `setTargetIndex(state, action)` — sets currently selected target
  - `setPlayerRow(state, action)` — sets player front/back row
  - `updateComboMeter(state, { payload: { amount } })` — adds to comboMeter, caps at maxComboMeter
  - `resetComboMeter(state)` — sets comboMeter to 0
  - `setGrammarComboState(state, { payload })` — sets active grammar combo chain
  - `clearGrammarComboState(state)` — clears grammar combo
  - `recordArabicUsed(state, { payload: { word, accuracy, comboType } })` — pushes to arabicUsedThisBattle with timestamp

  **Update existing reducers:**
  - `startBattle`: also reset enemies, comboMeter, grammarComboState, targetIndex, playerRow, arabicUsedThisBattle
  - `endBattle`: also reset all new fields, include arabicUsedThisBattle in battle history entry
  - `resetBattle`: also reset all new fields

  **New selectors:**
  - `selectEnemies(state)` — returns enemies array
  - `selectActiveEnemies(state)` — returns non-defeated enemies
  - `selectTargetEnemy(state)` — returns enemies[targetIndex]
  - `selectComboMeter(state)` — returns { comboMeter, maxComboMeter }
  - `selectGrammarComboState(state)` — returns grammarComboState
  - `selectArabicUsedThisBattle(state)` — returns arabicUsedThisBattle
  - `selectAllEnemiesDefeated` — createSelector: all enemies have defeated === true

  **Export all new action creators and selectors.** Keep all existing exports intact.
