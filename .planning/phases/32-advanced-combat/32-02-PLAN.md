  <files>src/data/grammarCombos.js</files>
  <action>
  Create src/data/grammarCombos.js with three categories of grammar-based combat combos:

  **1. NOUN_ADJ_COMBOS (إضافة constructions)** — Array of 8 noun+adjective combo templates:
  Each has: { id, noun: { arabic, english }, adjective: { arabic, english }, combined: { arabic, english }, damageMultiplier (1.2-1.5), requiredLesson: 'noun-adj-agreement' (from grammar.js lesson IDs), comboType: 'noun_adjective', cefrLevel: 'A2' }

  Examples:
  - { id: 'na_strong_shield', noun: { arabic: 'درع', english: 'shield' }, adjective: { arabic: 'قوي', english: 'strong' }, combined: { arabic: 'درع قوي', english: 'strong shield' }, damageMultiplier: 1.3, requiredLesson: 'noun-adj-agreement', comboType: 'noun_adjective', cefrLevel: 'A2' }
  - { id: 'na_sharp_sword', noun: { arabic: 'سيف', english: 'sword' }, adjective: { arabic: 'حاد', english: 'sharp' }, combined: { arabic: 'سيف حاد', english: 'sharp sword' }, damageMultiplier: 1.4, requiredLesson: 'noun-adj-agreement', comboType: 'noun_adjective', cefrLevel: 'A2' }
  - 6 more following this pattern with different nouns/adjectives (use combat-relevant words: fire, water, fast, heavy, etc.)

  **2. VERB_CHAIN_PATTERNS** — Array of 5 verb root chain patterns:
  Each has: { id, root: { arabic (3-letter root), english }, forms: [{ formNumber (I, II, IV, etc.), arabic, english, damageMultiplier }], maxChainLength: 3, requiredLesson: 'verb-forms' }

  The chain escalates: Form I = 1.0x, Form II = 1.2x, Form IV = 1.5x. Each additional form in chain adds to multiplier.

  Examples:
  - { id: 'vc_ktb', root: { arabic: 'ك-ت-ب', english: 'write' }, forms: [{ formNumber: 'I', arabic: 'كَتَبَ', english: 'wrote', damageMultiplier: 1.0 }, { formNumber: 'II', arabic: 'كَتَّبَ', english: 'dictated', damageMultiplier: 1.2 }, { formNumber: 'IV', arabic: 'أَكْتَبَ', english: 'had written', damageMultiplier: 1.5 }], maxChainLength: 3, requiredLesson: 'verb-forms' }
  - 4 more with roots: ع-ل-م (know/teach), ف-ت-ح (open), ح-ف-ظ (preserve/memorize), ج-م-ع (gather)

  **3. SENTENCE_TEMPLATES** — Array of 4 ultimate attack sentence templates:
  Each has: { id, template: { arabic, english, structure (e.g., 'VSO') }, slots: [{ role: 'verb'|'subject'|'object', arabic, english, alternatives: [] }], damageMultiplier: 2.5-3.0, requiredLesson: 'sentence-structure', comboType: 'ultimate_sentence', cefrLevel: 'B1' }

  **Helper function `getAvailableCombos(completedLessons, playerLevel)`:**
  - Returns { nounAdj: [...], verbChains: [...], sentences: [...] } filtered by:
    - requiredLesson must be in completedLessons array
    - cefrLevel gating: A1 combos at level 1+, A2 at level 3+, B1 at level 7+
  - If no lessons completed, returns empty arrays for all categories
  </action>

  <action>
  **arenaChallenges.js**: Define arena challenge configuration data.

  `ARENA_MODES` — Object with 3 modes:
  - `survival`: { id: 'survival', name: 'Survival Arena', nameArabic: 'ساحة البقاء', description: 'Survive waves of enemies with increasing Arabic difficulty', maxWaves: 10, unlockLevel: 5 }
  - `boss_rush`: { id: 'boss_rush', name: 'Boss Rush', nameArabic: 'تحدي الرؤساء', description: 'Face all bosses in sequence', maxWaves: null (dynamic), unlockLevel: 10 }
  - `puzzle`: { id: 'puzzle', name: 'Puzzle Battles', nameArabic: 'معارك الألغاز', description: 'Solve Arabic puzzles to defeat enemies', maxWaves: 5, unlockLevel: 8 }

  `WAVE_CONFIGS` — Function `getWaveConfig(waveNumber)` returns:
  - enemyCount: Math.min(4, 1 + Math.floor(waveNumber / 3))
  - hpMultiplier: 1 + (waveNumber * 0.15)
  - arabicDifficulty: waveNumber <= 3 ? 'choice' : waveNumber <= 7 ? 'type' : 'type_hard'
  - timeLimit: Math.max(60000, 120000 - (waveNumber * 5000))
  - bonusObjective: wave 5 = 'no_hints', wave 8 = 'perfect_accuracy', wave 10 = 'speed_clear'

  `BOSS_RUSH_SEQUENCE` — Array of boss IDs in story order (reference existing bosses from enemies.js). Include 5-8 boss IDs. Between each boss, include `interlude: { arabic, english }` narrative text (1-2 sentences each).

  `PUZZLE_BATTLES` — Array of 5 puzzle battle configs:
  Each has: { id, name, nameArabic, puzzleType: 'grammar_pattern'|'vocabulary_match'|'root_extraction', description, requiredKnowledge: ['lesson_id1', 'lesson_id2'], enemyParty: ['puzzle_enemy_X'], victoryCondition: 'solve_3_puzzles'|'complete_pattern' }

  **arenaSlice.js**: Create Redux slice (NOT IndexedDB — lightweight enough for localStorage).

  initialState:
  ```
  {
    activeArena: null, // { mode, currentWave, score, streak, startTime, enemiesDefeated }
    completedChallenges: {}, // { [modeId]: { bestScore, bestWave, completions, lastPlayed } }
    leaderboard: {}, // { [modeId]: [{ score, wavesCompleted, timestamp, accuracy }] } — top 10 per mode
    puzzleProgress: {}, // { [puzzleId]: { solved, attempts } }
    totalArenaWins: 0,
    totalArenaLosses: 0,
    bestStreak: 0,
  }
  ```

  Reducers:
  - `startArenaChallenge(state, { payload: { mode } })` — sets activeArena
  - `completeArenaWave(state, { payload: { score, accuracy, enemiesDefeated } })` — increments wave, adds score
  - `endArenaChallenge(state, { payload: { victory, finalScore } })` — updates completedChallenges, clears activeArena
  - `submitArenaScore(state, { payload: { mode, score, wavesCompleted, accuracy, timestamp } })` — adds to leaderboard, keeps top 10 sorted by score desc
  - `recordPuzzleSolve(state, { payload: { puzzleId, solved } })` — tracks puzzle progress

  Selectors: selectActiveArena, selectArenaLeaderboard(mode), selectCompletedChallenges, selectPuzzleProgress, selectArenaTotalStats

  Do NOT add arenaSlice to store.js yet (Plan 10 handles integration).
  </action>
