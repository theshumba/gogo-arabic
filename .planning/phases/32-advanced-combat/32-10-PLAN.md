  - Accuracy < 0.8: failed flee, enemy gets free turn (emit BATTLE_FLEE_FAILED)

  **New _handleItemUse():**
  - Emit EVENTS.BATTLE_ITEM_MENU_OPEN
  - Wait for item selection from React BattleItemMenu
  - On item selected: apply buff via applyBuff, consume item from inventory
  - Transition to RESOLVE_ACTION

  **_endTurn() changes:**
  - After tickStatusEffects, call CompoundEffectResolver.resolveCompounds on playerEffects and enemyEffects
  - If compound detected, dispatch applyStatusEffect with compound: true (triggers FSRS via middleware)
  - Update comboMeter: +10 for correct answer, +25 for grammar combo, reset on miss

  **_onArabicInputResult() changes (existing method — the normal attack Arabic input handler):**
  - **CRITICAL — Blocker fix:** After processing the Arabic input result, dispatch `recordArabicUsed`:
    ```javascript
    store.dispatch(recordArabicUsed({
      word: currentWord.arabic,
      accuracy: result.accuracy,

      comboType: null, // Normal attack, not a combo
    }));
    ```
  - This ensures EVERY Arabic word typed during battle (attacks, combos, flee attempts) is captured in `arabicUsedThisBattle` for PostBattleReview (Plan 32-09)
