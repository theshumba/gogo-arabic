  <action>
  Extend BattleStateMachine with new states and mechanics. PRESERVE all existing functionality.

  **New STATES to add:**
  - `GRAMMAR_COMBO`: Player is entering grammar combo input
  - `TARGET_SELECT`: Player is selecting enemy target (multi-enemy)
  - `ITEM_USE`: Player is selecting battle item
  - `FLEE_CHALLENGE`: Player is answering Arabic question to flee
  - `COMPOUND_CHECK`: Check for compound effects after status application
  - `ARENA_WAVE_TRANSITION`: Between arena waves

  **Constructor changes:**
  - Import and instantiate GrammarComboDetector with grammar.completedLessons
  - Import and use CompoundEffectResolver
  - Import MultiTargetManager
  - If config has enemyParty.length > 1, use MultiTargetManager for positioning
  - Dispatch initMultiTargetBattle if multi-enemy

  **start() changes:**
  - If enemyParty.length > 1, dispatch initMultiTargetBattle instead of single-enemy startBattle
  - Initialize MultiTargetManager with enemy positions

  **handleAction() changes:**
  - 'combo': transition to GRAMMAR_COMBO (new action type)
  - 'item': transition to ITEM_USE state (was stub)
  - 'flee': transition to FLEE_CHALLENGE (not random anymore — requires Arabic answer)

  **_getAvailableActions() changes:**
  - Add 'combo' action if GrammarComboDetector.getAvailableComboTypes(playerLevel).length > 0
  - 'item' available if player has usable battle items in inventory

  **New _handleGrammarCombo():**
  - Emit EVENTS.BATTLE_GRAMMAR_COMBO event with available combo types
  - Wait for React GrammarComboInput response via EventBus
  - On response: validate via GrammarComboDetector, apply damage multiplier, update comboMeter

  **New _handleFleeChallenge():**
  - Select a vocabulary word for flee question (same as _selectBattleWord but easier)
  - Emit EVENTS.BATTLE_FLEE_CHALLENGE with word data
  - Wait for Arabic input result
  - Accuracy >= 0.8: successful flee (dispatch endBattle with fled: true)
  - Accuracy < 0.8: failed flee, enemy gets free turn (emit BATTLE_FLEE_FAILED)

  **New _handleItemUse():**
  - Emit EVENTS.BATTLE_ITEM_MENU_OPEN
  - Wait for item selection from React BattleItemMenu
  - On item selected: apply buff via applyBuff, consume item from inventory
  - Transition to RESOLVE_ACTION

  **_endTurn() changes:**
  - After tickStatusEffects, call CompoundEffectResolver.resolveCompounds on playerEffects and enemyEffects
  - If compound detected, dispatch applyStatusEffect with compound: true (triggers FSRS via middleware)
  - Update comboMeter: +10 for correct answer, +25 for grammar combo, reset on miss
  - Track arabicUsedThisBattle via recordArabicUsed

  **_applyDamage() changes:**
  - If enemies array exists and length > 1, use dealDamageToEnemy(targetIndex, damage) instead of dealDamage
  - Apply row damage modifier from MultiTargetManager.getRowDamageModifier

  **_checkBattleEnd() changes:**
  - If enemies array exists, check selectAllEnemiesDefeated instead of bossHP <= 0

  **_handleVictory() changes:**
  - Emit EVENTS.BATTLE_POST_REVIEW with arabicUsedThisBattle data

  **BattleMenu update in _getAvailableActions:**
  Add 'combo' to the available actions list.

  **battleSlice.js minor update:**
  - In endBattle reducer: include arabicUsedThisBattle in the battleHistory entry as `arabicReview` field
