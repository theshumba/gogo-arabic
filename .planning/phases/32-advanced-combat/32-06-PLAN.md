  **GrammarComboInput.jsx**: Multi-step Arabic input for grammar-based combos.

  Props: `{ comboType, template, onSubmit, onCancel }`
  - `comboType`: 'noun_adj' | 'verb_chain' | 'sentence'
  - `template`: the matched combo template from grammarCombos.js
  - `onSubmit`: callback with { arabicInput, accuracy, damageMultiplier, comboType }
  - `onCancel`: callback to exit combo mode

  **Mode: noun_adj**
  - Show 2 input fields side-by-side (RTL): noun field + adjective field
  - Label above: "إضافة — Noun + Adjective Combo"
  - Hint text shows English translation of target combo
  - Submit button: "تنفيذ" (Execute)
  - On submit: combine inputs, validate against template, return accuracy

  **Mode: verb_chain**
  - Show current chain progress (e.g., "Chain: كَتَبَ → ???")
  - Single input field for next verb form
  - Display root in Arabic above: "جذر: ك-ت-ب"
  - Show which form is needed next (Form II, IV, etc.)
  - On submit: validate verb form, extend chain, calculate cumulative multiplier

  **Mode: sentence**
  - Show 3 labeled input fields: فاعل (Subject), فعل (Verb), مفعول به (Object)
  - Template displayed above in Arabic with blanks for each slot
  - On submit: validate each slot, calculate partial/full accuracy
  - Full accuracy (3/3 correct) = ultimate attack multiplier (2.5-3.0x)

  All modes:
  - RTL direction, Amiri font for Arabic text
  - Timer bar (20 seconds for noun_adj, 30 seconds for verb_chain, 45 seconds for sentence)
  - ESC key or Cancel button triggers onCancel
  - Framer Motion enter/exit with reduced-motion support
  - Input fields auto-focus in sequence

  **GrammarComboInput.module.css**: CSS Module with:
  - `.comboContainer` — centered, dark background, gold border
  - `.inputField` — RTL, Amiri font, Arabic placeholder
  - `.chainProgress` — horizontal display of chain links
  - `.sentenceSlots` — 3-column grid for subject/verb/object
  - `.comboLabel` — Arabic combo type name, decorative
  - `.timerBar` — same style as BattleArabicInput timer
  </action>
