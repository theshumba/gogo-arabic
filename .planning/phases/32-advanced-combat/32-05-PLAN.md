  **ComboMeter.jsx**: Displays the combo charge meter with Arabic numerals and grammar combo indicator.

  This is SEPARATE from the existing ComboCounter.jsx (which shows streak count). ComboMeter shows the combo charge gauge (0-100) that fills toward ultimate attacks.

  Props: `{ comboMeter, maxComboMeter, grammarComboState, streak }`

  Behavior:
  - Show vertical gauge bar on left side of screen (below player HP area)
  - Fill level = (comboMeter / maxComboMeter) * 100%
  - Color gradient: 0-33% blue, 34-66% gold, 67-99% orange, 100% red+glow
  - Display combo charge as Arabic numerals using helper: `toArabicNumerals(comboMeter)` — converts 0-9 to ٠-٩
  - When grammarComboState is active, show indicator of current combo type:
    - noun_adj: "إضافة" label
    - verb_chain: "تصريف" label + chain count
    - sentence: "جملة" label + filled slots
  - At 100%, show "!جاهز" (Ready!) with pulse animation
  - Framer Motion spring animation on meter changes
  - Respect prefers-reduced-motion

  `toArabicNumerals(num)` helper (inline):
