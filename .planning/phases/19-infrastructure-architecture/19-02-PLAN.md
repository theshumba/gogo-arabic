**Create `src/store/slices/narrativeSlice.js`:**

Follow the exact pattern from the research document (Pattern 3). The slice must include:

**Initial state:**
```javascript
{
  storyFlags: {},           // { flagKey: string|number } — story progression (max 50, DEV-warn)
  npcRelationships: {},     // { npcId: number(0-5) } — trust meter per NPC
  worldObjectStates: {},    // { objectId: 'state-string' } — mutable world state
  choiceHistory: [],        // [{ npcId, choiceId, timestamp }] — dialogue choices log
  visitedBuildings: [],     // [buildingId] — building visit tracking
}
```

**Reducers (7):**
1. `setStoryFlag({ flag, value })` — Sets a story flag. Add DEV-mode `console.warn` when `Object.keys(state.storyFlags).length >= 50` ("Story flag budget: 50 flags max. Consider consolidating.").
2. `setNpcRelationship({ npcId, level })` — Clamp level to 0-5 range with `Math.max(0, Math.min(5, level))`.
3. `incrementNpcRelationship({ npcId, amount })` — Increment/decrement with same 0-5 clamping. Default amount = 1.
4. `setWorldObjectState({ objectId, objectState })` — Set arbitrary string state for a world object.
5. `recordChoice({ npcId, choiceId })` — Push choice with ISO timestamp to history array. Use static timestamp approach: `new Date().toISOString()`.
6. `markBuildingVisited(buildingId)` — Push buildingId if not already in array (dedup).
7. `resetNarrativeProgress()` — Reset entire slice to initialState (for new game).

**Selectors (10):**
Follow the named selector export pattern established in grammarSlice.js (v3.0 Phase 11 convention — all slices must have named selector exports):
- `selectStoryFlags` — returns `state.narrative.storyFlags`
- `selectNpcRelationships` — returns `state.narrative.npcRelationships`
- `selectWorldObjectStates` — returns `state.narrative.worldObjectStates`
- `selectChoiceHistory` — returns `state.narrative.choiceHistory`
- `selectVisitedBuildings` — returns `state.narrative.visitedBuildings`
- `selectStoryFlag(flag)` — parameterized selector factory, returns value or null
- `selectNpcRelationship(npcId)` — parameterized selector factory, returns level or 0
- `selectWorldObjectState(objectId)` — parameterized selector factory, returns state or null
- `selectHasMadeChoice(npcId, choiceId)` — createSelector-based memoized selector
- `selectNarrativeFlagCount` — returns `Object.keys(state.narrative.storyFlags).length` (for budget monitoring)

Export default: `narrativeSlice.reducer`
