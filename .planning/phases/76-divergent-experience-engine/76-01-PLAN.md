# Phase 76: NAR-01 — Divergent Experience Engine

## Summary

Faction-aware experience engine that makes gameplay genuinely different depending on the player's primary faction alignment. When any faction reaches friendly tier (25+ alignment), the system unlocks a unique narrative path with zone-specific story variations, custom entry text (Arabic + English), and a 5-quest chain.

## What Was Built

### 1. Divergent Path Data (`src/data/divergentPaths.js`)
- 6 complete faction paths (scholars, merchants, artisans, travelers, guardians, artists)
- 48 zone variations (8 zones x 6 factions), each with Arabic/English entry text, NPC lists, and hidden interactions
- 30 quests (5 per faction) forming coherent story chains with escalating XP/dirham rewards
- Convenience exports: `ALL_DIVERGENT_QUEST_IDS`, `QUEST_TO_FACTION_MAP`, `DIVERGENT_QUEST_BY_ID`

### 2. Divergent Experience Service (`src/services/divergentExperienceEngine.js`)
Pure function module with:
- `shouldShowDivergentContent(factionState)` — boolean check for any faction at friendly+
- `getActivePathForPlayer(factionState)` — returns active path for primary faction
- `getZoneVariation(factionState, zoneName)` — zone-specific content variation
- `getDivergentEntryText(factionState, zoneName)` — { arabic, english } entry text
- `getAvailableQuests(factionState, questState)` — unlocked chain quests
- `getNextQuestInChain(completedQuestId)` — next quest after completion
- `getDivergentQuestById(questId)` — quest data lookup
- `getFactionForQuest(questId)` — faction ID lookup
- `getAllPathsStatus(factionState)` — overview of all 6 paths

### 3. Middleware (`src/store/middleware/divergentExperienceMiddleware.js`)
- Listens for `faction/adjustAlignment` — sets `divergent_path_{factionId}_unlocked` worldState flag when crossing friendly threshold
- Listens for `quests/completeQuest` — auto-unlocks next quest in chain via `divergent_quest_{questId}_unlocked` flag
- Follows existing middleware pattern (next-first, persist guard, state reads after reduction)

### 4. Tests (`src/services/__tests__/divergentExperienceEngine.test.js`)
- 40+ test cases across 10 describe blocks
- Covers all pure functions, edge cases (null state, tied factions, empty quest state)
- Data integrity tests validating all 30 quests, 48 zone variations, prerequisite chains

## Architecture Decisions
- Pure functions in service layer, side effects only in middleware (matches project pattern)
- No edits to existing files — all new files
- Quest data shape matches existing `quests.json` format
- Arabic text is authentic and culturally appropriate for each faction's domain
