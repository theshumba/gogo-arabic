## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user → toggle | Untrusted click input; only flips a boolean; no data destruction path triggered |
| user → conflict picker | Untrusted slot ownership at conflict resolution; verified by req.userId server-side at next push |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-103-22 | Tampering | Toggle dispatched bypass | accept | Boolean state in client; server still requires authenticated cookie for any /cloudsave/* operation |
| T-103-23 | Information Disclosure | Conflict modal shows other-user data | mitigate | Conflicts only populated by pullOnBoot which fetches /pull (server filters by req.userId) — cross-user injection impossible |
| T-103-24 | Denial of Service | Modal blocks game while open | accept | Modal is dismissable (Escape, choose+Apply); does not block local save path |

</threat_model>
