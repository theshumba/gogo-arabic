**The Problem:**

The TODO at line 229 says "props are multi-item sheets, not 16x16 -- scaling 4x breaks them". The issue is that many Kenmi desert prop PNGs are multi-item sheets (e.g., `desert-rocks.png` contains multiple rock variants in one image, `desert-pots-sacks.png` contains multiple pot/sack variants). These are type `'image'` in the catalog, NOT spritesheets with frame indices. When `scatterDecorations` scales them 4x with `KENMI_SCALE`, the entire multi-item sheet is scaled up, resulting in a huge ugly blob instead of a single rock.

**The Fix:**

For 'image' type props that are multi-item sheets, use Phaser's `setCrop()` to show only one item from the sheet, THEN scale. The approach:

1. Add a `PROP_CROP_REGIONS` constant in MapLoader.js that defines crop rectangles for multi-item sheets. Each entry maps a texture key to an array of `{ x, y, w, h }` regions (in source pixels) representing individual items within the sheet:

```javascript
const PROP_CROP_REGIONS = {
  'kenmi-desert-props-desert-rocks': [
    { x: 0, y: 0, w: 16, h: 16 },   // small rock
    { x: 16, y: 0, w: 16, h: 16 },  // medium rock
    { x: 0, y: 16, w: 16, h: 16 },  // flat rock
  ],
  'kenmi-desert-props-desert-pots-sacks': [
    { x: 0, y: 0, w: 16, h: 16 },   // pot
    { x: 16, y: 0, w: 16, h: 16 },  // sack
    { x: 0, y: 16, w: 16, h: 16 },  // large pot
  ],
  'kenmi-desert-props-desert-rugs': [
    { x: 0, y: 0, w: 16, h: 16 },   // rug 1
```

Currently scatterDecorations uses per-tile probability to decide if a prop goes on a tile. This produces evenly-scattered props but not explicit CLUSTERS of 2-4 items near buildings (DECO-02).

Add a clustering pass AFTER the per-tile scatter loop (but still inside scatterDecorations). This pass adds tight groups of 2-4 props near each building object.

**Clustering algorithm:**

After the main tile-by-tile loop, add a clustering section:

```javascript
// --- Clustering pass: add prop groups of 2-4 near buildings ---
const buildingKeys = (zone.objects || []).filter(obj =>
  obj.key && (
    obj.key.includes('house') || obj.key.includes('tent') ||
    obj.key.includes('temple') || obj.key.includes('pergola') ||
    obj.key.includes('tower') || obj.key.includes('arch') ||
    obj.key.includes('inn') || obj.key.includes('barn') ||
    obj.key.includes('shroom')
  )
);

const CLUSTER_PROPS_DESERT = [
  'kenmi-desert-props-desert-pots-sacks',
  'kenmi-desert-props-desert-rugs',
  'kenmi-desert-props-sleeping-mat',
  'kenmi-desert-props-water-sack-on-stick',
  'kenmi-desert-props-fire-pit',
  'kenmi-desert-props-desert-ladder',
];

const CLUSTER_PROPS_GRASS = [
  'kenmi-base-outdoor-decoration-barrels',
  'kenmi-base-outdoor-decoration-camp-decor',
  'kenmi-base-outdoor-decoration-hay-bales',
  'kenmi-base-outdoor-decoration-benches',
];

const clusterProps = biome === 'grass' ? CLUSTER_PROPS_GRASS : CLUSTER_PROPS_DESERT;

for (let bi = 0; bi < buildingKeys.length; bi++) {
  const bldg = buildingKeys[bi];
  const clusterSize = 2 + Math.floor(tileHash(bldg.x, bldg.y, DECO_SEED + 100) * 3); // 2-4

  for (let ci = 0; ci < clusterSize; ci++) {
    // Offset 1-3 tiles from building in random direction
    const angle = tileHash(bldg.x + ci, bldg.y, DECO_SEED + 101 + ci) * Math.PI * 2;
    const dist = 1.5 + tileHash(bldg.x, bldg.y + ci, DECO_SEED + 102 + ci) * 2;
    const tx = Math.round(bldg.x + Math.cos(angle) * dist);
    const ty = Math.round(bldg.y + Math.sin(angle) * dist);

    // Bounds and occupancy check
    if (tx < 1 || tx >= mapW - 1 || ty < 1 || ty >= mapH - 1) continue;
    if (occupiedTiles.has(`${tx},${ty}`)) continue;
    if (exitTiles.has(`${tx},${ty}`)) continue;
    if (groundData[ty][tx] === WATER) continue;

    const propIdx = Math.floor(tileHash(tx, ty, DECO_SEED + 200 + ci) * clusterProps.length);
    const propKey = clusterProps[propIdx];
    if (!this.scene.textures.exists(propKey)) continue;

    const offsetX = (tileHash(tx, ty, DECO_SEED + 201) - 0.5) * 16;
    const offsetY = (tileHash(tx, ty, DECO_SEED + 202) - 0.5) * 16;
    const px = tx * TILE + TILE / 2 + offsetX;
    const py = ty * TILE + TILE / 2 + offsetY;

    const sprite = this._createDecoSprite(px, py, propKey, tileHash(tx, ty, DECO_SEED + 203));
    if (sprite) {
      this.decoSprites.push(sprite);
      // Mark as occupied so no more props overlap here
      occupiedTiles.add(`${tx},${ty}`);
    }
  }
}
```

This adds 2-4 clustered props around each building — with 4-6 buildings per zone, that is 8-24 additional props. Combined with the scatter pass (20-60+ props), the visual density requirement is well exceeded.
