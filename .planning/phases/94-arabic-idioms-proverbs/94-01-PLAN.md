# Phase 94 — Arabic Idiom & Proverb System

**Status:** Implementation Plan  
**Date:** 2026-03-27  
**Scope:** 100+ Arabic idioms/proverbs with explorer, quiz, and daily rotation system

---

## Executive Summary

Phase 94 introduces an **Arabic Idiom & Proverb Learning System** — a content expansion that teaches learners common Arabic expressions beyond literal vocabulary. The system includes:

- **100+ Curated Idioms/Proverbs** across 10 semantic categories (wisdom, social, nature, humor, work, family, patience, honor, courage, knowledge)
- **IdiomExplorer Component** for browsing, filtering, and marking idioms as learned
- **IdiomQuiz Component** for testing idiom comprehension with multiple-choice questions
- **DailyIdiom Component** for deterministic daily idiom rotation (same date = same idiom for all players)
- **idiomSlice Redux State** for tracking learned idioms, favorites, quiz history
- **Data Integrity Tests** following Phase 79 (loreEntries) patterns

The idiom system integrates with the existing quiz type registry (Phase 59/60) but operates independently to avoid polluting the core quiz ecosystem.

## File 1: `src/data/arabicIdioms.js`

**Purpose:** Core data — 100+ idioms across 10 categories

**Data Structure:**
```javascript
{
  id: string                    // 'idiom_wisdom_001' format
  category: string              // 'wisdom'|'social'|'nature'|'humor'|'work'|'family'|'patience'|'honor'|'courage'|'knowledge'
  arabic: string                // الحكمة هي ... (full idiom in Arabic)
  transliteration: string       // 'al-hikma hiya ...'
  literal: string               // English word-for-word translation
  meaning: string               // What the idiom actually means
  englishEquivalent: string     // Closest English idiom (or "no equivalent")
  usageExample: {
    arabic: string              // Example sentence using the idiom (Arabic)
    english: string             // English translation of example
  }
  cefrLevel: 'A1'|'A2'|'B1'|'B2'  // CEFR difficulty
  origin?: string               // Where it comes from (Quran, hadith, poet, etc.)
  funFact?: string              // Cultural/historical context
}
```

**Data Count & Distribution:**
- 10 categories × 10-12 idioms each = 100-120 idioms total
- CEFR spread: ~20 A1, ~30 A2, ~30 B1, ~20 B2
- Each idiom fully localized (Arabic + English)

   - Tap to expand

2. **Medium Card (size: medium, default)**
   - Arabic idiom (prominent)
   - Literal translation (small, light)
   - Actual meaning (bold, black)

   - "Learn More" link → open IdiomExplorer with this idiom expanded

3. **Large Card (size: large)**
   - Full card with all metadata
   - Origin, fun fact, English equivalent
   - Usage example in both languages
   - Mark as learned / favorite buttons

**Logic:**
- Deterministic selection: `getDailyIdiomId(today, allIdioms)` — same for all players on same date
- On first load, check `state.idiom.lastDailyDate` vs today
- If different day, call `setDailyIdiom({ idiomId, date })` via dispatch
- Cache the result in Redux state (no re-fetch on re-render)

**Redux Integration:**
```javascript
const dailyIdiomId = useSelector(selectDailyIdiomId)
const dailyIdiom = useMemo(
  () => getIdiomById(dailyIdiomId),
  [dailyIdiomId]
)

useEffect(() => {
  const today = new Date().toISOString().split('T')[0]
  const lastDate = useSelector(selectLastDailyDate)
  
  if (lastDate !== today) {
    const idiomId = getDailyIdiomId(today, ARABIC_IDIOMS)
    dispatch(setDailyIdiom({ idiomId, date: today }))
  }
}, [])
```
