# Plan 67-01: Quiz Completion → Daily Goals

## Context

`dailyGoalsMiddleware.js` exports a `recordQuizCompletion(dispatch, passed)` helper that dispatches `updateDailyGoal({ goalType: 'quizzesPassed', amount: 1 })`. This helper is never called anywhere. The `quizzesPassed` daily goal is always stuck at 0.

## Implementation

### Step 1: Wire recordQuizCompletion into useQuiz.js

In the `next()` callback (line ~476), after detecting quiz session end (`nextIdx >= words.length`), add:

```javascript
import { recordQuizCompletion } from '../store/middleware/dailyGoalsMiddleware.js';

// After: const wasPerfect = ...
const passed = quizState.sessionScore > 0 || wasPerfect;
recordQuizCompletion(dispatch, passed);
```

This fires once per quiz session completion. Only counts if the player got at least one answer correct.

### Step 2: Add test

Test that `recordQuizCompletion` dispatches `updateDailyGoal` when passed=true and does nothing when passed=false.
