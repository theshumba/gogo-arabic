# Plan 67-03: Progressive Tashkeel Fading Wiring

## Context

`FadingArabicText` component and `tashkeelFading.js` utilities exist but are unused. `useFormatArabic` has `getTashkeelOpacity(wordId)` but quiz components only call `formatArabic(text)` which does binary strip/show — no progressive fading.

## Implementation

### Step 1: Add renderArabic to useFormatArabic

Add a `renderArabic(text, wordId)` function that returns a `<FadingArabicText>` React element. When showDiacritics is false, return stripped text. When true, return FadingArabicText with the wordId for mastery-based opacity lookup.

### Step 2: Wire into key quiz components

Update the main quiz prompt displays to use `renderArabic(word.arabic, word.id)`:
- ArabicToEnglish — prompt word
- ListenAndChoose — prompt word
- RootIdentifier — prompt word
- EnglishToArabic — choice buttons (each choice has a wordId from options)

### Step 3: Wire into DialogueBox

When dialogue lines contain vocabulary words, use renderArabic for the Arabic text portions.
