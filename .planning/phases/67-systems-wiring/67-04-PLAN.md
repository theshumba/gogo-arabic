# Plan 67-04: NPC Quest Indicators — ALREADY IMPLEMENTED

## Status: COMPLETE (No work needed)

The NPC quest indicator system is fully wired:

1. **NPC.js** — `setQuestMarker(type)` renders `!` (gold, #FFD700) for active/available quests and `?` (green, #00FF00) for turn-in quests, positioned at y-85 above NPC sprites.

2. **NPCManager.js** — `update()` reads `selectNpcQuestMarkers(store.getState())` every frame and calls `npc.setQuestMarker(marker)` for each NPC.

3. **questSlice.js** — `selectNpcQuestMarkers` selector computes markers per NPC:
   - Priority 1: `?` for completed quests with unclaimed rewards
   - Priority 2: `!` for active quests
   - Priority 3: `!` for locked quests with all prerequisites met

No implementation required.
