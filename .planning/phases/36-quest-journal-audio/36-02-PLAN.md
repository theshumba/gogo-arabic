**Part B: audio.js**

Read the existing audioManager singleton carefully. Extend it with:

1. **Bus volume tracking:**
```js
this.busVolumes = {
  bgm: 0.5,
  sfx: 1.0,
  ambient: 0.5,
  voice: 1.0,
};
```

2. **`setBusVolume(bus, volume)` method** — updates the bus volume and adjusts all active sounds on that bus.

3. **`playAmbient(layers)` method:**
   - Stops any currently playing ambient sounds
   - Creates Howl instances for each layer with `loop: true`
   - Stores references in `this.ambientSounds = []`
   - Each layer's volume = `layer.volume * this.busVolumes.ambient`
   - Uses `onloaderror` to silently skip missing files (same pattern as playBGM)

4. **`stopAmbient()` method** — fades out and stops all ambient sounds.

5. **`muffleAmbient(factor)` method** — reduces all ambient volumes by a factor (0-1). Used for building interiors.

6. **`unmuffleAmbient()` method** — restores ambient volumes to their layer defaults.

Keep all existing methods (playBGM, playSFX, etc.) unchanged. This is additive.
