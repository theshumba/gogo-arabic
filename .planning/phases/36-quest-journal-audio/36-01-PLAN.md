<task type="auto">
  <name>Task 1: Create QuestJournal component</name>
  <files>src/components/Quest/QuestJournal.jsx, src/components/Quest/QuestJournal.module.css</files>
  <action>
Create the QuestJournal as a React overlay component following existing overlay patterns (read DailyDashboard.jsx or PlayerProfile.jsx for reference — they use CSS Modules, useFocusTrap, overlay close patterns).

**Structure — 3 tabs:**

1. **Quests tab** — List all quests grouped by zone. Each quest shows:
   - Quest name + Arabic name
   - Status badge (active/complete/locked)
   - Progress bar if in-progress
   - NPC giver name + location
   - Prerequisite chain visualization (simple indented list)

2. **NPCs tab** — Grid of NPC portraits/icons. Each NPC shows:
   - Name (Arabic + English)
   - Met/unmet status (from questSlice.npcsVisited)
   - Current location (zone name)
   - Friendship tier indicator (from npcSlice.friendship via selectFriendshipTier)
   - Click to expand: shows NPC's quests, schedule, dialogue history

3. **Schedule tab** — Time bar visualization for scheduled NPCs:
   - Horizontal bars representing 24-hour day
   - Each NPC with a schedule shows colored time blocks
   - Current time indicator (vertical line)
   - Zone legend showing which colors map to which zones
   - Only shows NPCs the player has met

**Data sources:**
- `questSlice` — quest statuses, npcsVisited
- `npcSlice` — friendship values
- `npcsEnriched` data — NPC names, schedule arrays (from Phase 33)
- `timeSlice` — current game hour for schedule viewer

**Styling:**
- Dark theme (#0A0A0A bg) with red accents (#E63946) — matches project design
- CSS Modules (not inline styles)
- Responsive (min 375px)
- Uses useFocusTrap hook
- Close on ESC or click-outside via useOverlayClose

Read existing overlay components first to match patterns exactly.
