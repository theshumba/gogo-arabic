  <name>Task 1: Add wander, patrol, and walk animation support to NPC.js</name>
  <files>src/game/sprites/NPC.js</files>
  <action>
Add movement pattern methods to NPC.js. Read Companion.js first — it is the reference implementation for `scene.physics.moveToObject()` and directional walk animations.

**1. Walk animation creation (conditional):**
In the constructor or an init method, AFTER idle animations are created, check if the NPC's spritesheet has enough frames for walk animations:
```js
const texture = this.scene.textures.get(this.texture.key);
const frameCount = texture.frameTotal - 1; // subtract __BASE frame
```
If `frameCount >= 16`, create 4 walk animations following the Companion.js pattern:
- `${npcId}-walk-down`: frames 0-3
- `${npcId}-walk-left`: frames 4-7
- `${npcId}-walk-right`: frames 8-11
- `${npcId}-walk-up`: frames 12-15

Guard each with `if (!this.scene.anims.exists(key))` before creating (same pattern as existing idle animations).

Store `this._hasWalkAnims = true` if created, `false` otherwise.

**2. `_playDirectionalWalkAnim()` method** (copy from Companion.js):
```js
_playDirectionalWalkAnim() {
  if (!this._hasWalkAnims) return;
  const vx = this.body.velocity.x;
  const vy = this.body.velocity.y;
  const id = this.npcId;
  if (Math.abs(vx) > Math.abs(vy)) {
    this.anims.play(vx < 0 ? `${id}-walk-left` : `${id}-walk-right`, true);
  } else {
    this.anims.play(vy < 0 ? `${id}-walk-up` : `${id}-walk-down`, true);
  }
}
```

**3. `_playIdleAnim()` method:**
Stop velocity and play the existing idle animation. Use the idle animation key already created in the constructor.

**4. `startWander(radius)` method:**
- Call `this.setImmovable(false)` — CRITICAL (see Research pitfall 1)
- Store spawn position: `this._spawnX = this.x; this._spawnY = this.y;`
- Store radius: `this._wanderRadius = radius || 96;` (1.5 tiles)
- Create a Phaser timer using `this.scene.time.addEvent()`:
  - delay: `3000 + Math.random() * 4000` (wander every 3-7 seconds)
  - loop: true
  - callback: Pick random target within radius of spawn, clamp to map bounds (`this.scene.currentMapW`, `this.scene.currentMapH`), call `this.scene.physics.moveToObject(this, {x: tx, y: ty}, 40)`, call `this._playDirectionalWalkAnim()`, store `this._wanderTarget = {x: tx, y: ty}`.
- Store timer ref: `this._wanderTimer = timer;`

**5. `startPatrol(path, durations)` method:**
- Call `this.setImmovable(false)`
- Store: `this._patrolPath = path; this._patrolDurations = durations; this._patrolIndex = 0;`
- Call `this._advancePatrol()` to start.

**6. `_advancePatrol()` method:**
- Read current step from `this._patrolPath[this._patrolIndex]`
- Direction map: `{ right: {vx:40,vy:0}, left: {vx:-40,vy:0}, up: {vx:0,vy:-40}, down: {vx:0,vy:40}, stand: {vx:0,vy:0} }`
- Set velocity, play walk anim (or idle for 'stand')
- Use `scene.time.delayedCall(duration, () => { advance index, call _advancePatrol() })` for next step
- Store timer ref for cleanup: `this._patrolTimer = timer;`

**7. `stopMovement()` method:**
- Set velocity to 0,0
- Call `this._playIdleAnim()`
- If was wandering: clear `this._wanderTimer` via `.remove()`
- If was patrolling: clear `this._patrolTimer` via `.remove()` if active

**8. `update()` override** (or extend existing if present):
- For wander: check if NPC reached `_wanderTarget` (distance < 8px), if so, stop velocity and play idle. Use `Phaser.Math.Distance.Between(this.x, this.y, target.x, target.y)`.

**9. Cleanup in `destroy()`:**
- Remove wander/patrol timers if active
- Call `super.destroy()` or equivalent existing cleanup

IMPORTANT: Do NOT modify the existing idle animation or interaction behavior. This is purely ADDITIVE.

**1. Movement initialization after spawn:**
After each NPC sprite is created (Plan 01 already stores `npcSprite._scheduleEntry`), check the schedule entry's behavior:

if (npcSprite._scheduleEntry) {
