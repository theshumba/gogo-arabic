  <files>src/game/systems/ScheduleEvaluator.js</files>
  <action>
Create a NEW file `src/game/systems/ScheduleEvaluator.js` with two named exports:

1. `evaluateSchedule(npc, currentHour, currentZone, storyFlags)`:
   - Returns the first matching schedule entry, or `null` if no match.
   - If `npc.schedule` is falsy or empty array, return `null` (no schedule = no evaluation).
   - For each entry: check `entry.zone === currentZone` first.
   - Hour range check MUST handle midnight wrap-around:
     - If `startHour <= endHour`: `currentHour >= startHour && currentHour < endHour`
     - If `startHour > endHour` (wraps midnight): `currentHour >= startHour || currentHour < endHour`
   - Optional `entry.requireFlag` support: if present, check `storyFlags?.[entry.requireFlag]` — skip if falsy.
   - Return the first matching entry (priority = array order).

2. `shouldSpawnNpc(npc, currentHour, currentZone, storyFlags)`:
   - If `npc.schedule` is falsy or empty, return `true` (always spawn).
   - Otherwise return `evaluateSchedule(...) !== null`.

Follow project conventions:
- camelCase file/function names
- Named exports (not default)
- No external dependencies
- JSDoc comments on both functions
- Pure functions — no side effects, no imports beyond what's needed
  </action>
