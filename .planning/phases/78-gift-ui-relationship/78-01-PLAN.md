# Phase 78 — NAR-03: Gift UI & Relationship Milestones

## Objective
Provide players with a full-screen gift-giving overlay so they can select items
from inventory and present them to NPCs, see animated reactions, and unlock
relationship milestone rewards as friendship tiers are crossed.

## Design Decisions
- Dark theme: `#1a1a2e` background, `#FFD700` gold accents
- Tier colors: cold `#666`, cautious `#D4A017`, friendly `#2E8B57`, close `#FFD700`
- CSS Modules with BEM-ish naming inside module scope
- All Arabic text uses `dir="rtl"` and `--font-arabic` / `--font-pixel-arabic`
- Gift preferences hidden until player has given that gift type before, or friendship >= 50
- Reaction text shown for 2 seconds with glow animations
- Milestone popup auto-dismisses after 4 seconds or on click
- Middleware queues milestone notifications via a simple state flag
- Default exports for lazy loading compatibility
