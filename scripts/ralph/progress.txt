## Codebase Patterns

- **Middleware location**: `src/store/middleware/` — all custom middleware here
- **Slice tests**: `src/store/__tests__/` — tests for slices; middleware tests in `src/store/middleware/__tests__/`
- **Store registration**: Add reducer to `rootReducer` in `store.js`, add to `persistConfig.whitelist` for localStorage persistence, add middleware to `.concat(...)` chain

- **Middleware blocking pattern**: return early without calling `next(action)` to silently block; expose `_reset*` functions for test isolation
