## Codebase Patterns

### Quiz Type Registration Pattern
To add a new quiz type:
1. Add entry to `QUIZ_TYPE_REGISTRY` in `src/data/quizTypes.js` — shape: `{ label, cluster, minLevel, cefrMin }`
2. Add `buildChoices` case in `useQuiz.js` (the `buildChoices` closure has access to `fsrsCards` and `vocabulary`)
3. Add grading case in `answer()` callback
4. Add `correctAnswer` case in the correctAnswer block
5. Update `src/data/__tests__/quizTypes.test.js` count assertion
- Non-word-based types (DialectIdentify, RootExpand, CulturalContext, sentence_build) attach data to `word` object via mutation: `word.myField = data`
