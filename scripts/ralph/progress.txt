## Codebase Patterns

- **Middleware pattern**: Always call `next(action)` first, then dispatch side-effects. Pattern from `vocabRateMiddleware.js`.
- **Middleware test pattern**: Mock store with `{ getState: vi.fn(), dispatch: vi.fn() }`, mock `next = vi.fn((action) => action)`. Create middleware with `middleware = myMiddleware(store)(next)`. Check `store.dispatch` calls with `expect.objectContaining`.
- **Skill tree IDs**: `reading`, `writing`, `listening`, `speaking`, `grammar`, `culture` (from `SKILL_TREE_ORDER` in `data/skillTrees.js`).
- **Quiz completion hook**: `achievements/recordQuizTypeResult` — fires after every quiz session with `{ quizType, perfect }`.
- **Battle end hook**: `battle/endBattle` — payload `{ victory, accuracy, timeElapsed, rewards, bossId }`.
- **Conversation hook**: `conversation/completeScenario` — payload `{ scenarioId, score }`.
- **Pronunciation hook**: `phonetics/recordPracticeAttempt` — payload `{ id, score, type }`.
- **addSkillXP action**: `import { addSkillXP } from '../slices/skillTreeSlice.js'` — takes `{ treeId, amount }`.
- **Pre-existing test failures**: 7 test files fail before any changes (IndexedDB, dataset, HUD, antiFrustration, zoneReview, battle integration). Not caused by feature work.
